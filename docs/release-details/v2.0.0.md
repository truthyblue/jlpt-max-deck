# JLPT MAX Deck v2.0.0 — 문법 3,639개·어휘 9,160개·내 기록

v2.0.0은 문법·어휘 범위와 카드 구조가 크게 바뀐 정식 업데이트입니다. N5부터 N1까지
검토된 문법 3,639개를 기본 덱에 추가하고, 어휘를 9,160개로 늘렸습니다. 모든
어휘에는 한국어→일본어 회상 카드를 추가했습니다. 각 급수의 새 카드 순서는 BCCWJ
사용 빈도에 맞췄습니다. 모바일 Anki 답안 화면에는 동의형 `내 기록` 기능도 넣었습니다.

## 검토된 문법 3,639개

문법은 기본 덱에 포함되며 다음 네 가지 학습 카드를 제공합니다.

- 기본 문법 카드 1,085개
- 문법 형태 연습 1,085개
- 지문 빈칸 연습 1,085개
- 문장 배열 연습 384개

## 업데이트할 때 꼭 지킬 것

1. 모든 기기를 동기화하고 컬렉션 백업을 확인합니다.
2. 기존 덱과 학습한 급수를 삭제하지 않습니다.
3. `JLPT-MAX-Deck-2.0.0.apkg`를 기존 덱 위에 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다.
5. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기를 선택합니다.
6. 아래의 빈 카드 정리를 끝내고 모든 기기에서 전체 동기화합니다.

## 새 중요도 순서는 미학습 급수에만 다시 적용

Anki는 기존 카드의 순서와 일정을 보존합니다. v2.0.0을 가져왔다고 해서 이미 있는
카드가 BCCWJ 중요도 순으로 다시 배열되지는 않습니다.

새 순서를 처음부터 쓰고 싶은 급수가 **완전히 미학습 상태**일 때만 그 급수의
`JLPT MAX덱::어휘::N○`와 `JLPT MAX덱::음성::N○`를 함께 삭제한 뒤 v2.0.0을 다시
가져옵니다. 이미 학습한 급수는 정렬만을 위해 삭제하면 안 됩니다. 어휘 덱만
삭제하면 같은 단어의 음성 카드가 남을 수 있으므로 두 덱을 한 쌍으로 다룹니다.

## `五万`과 `～キロ` 빈 카드 정리

`五万`은 생산적인 수 조합이라 독립 어휘에서 제외했습니다. `～キロ`는 살아 있는
`キロ` 노트가 킬로그램과 킬로미터를 함께 설명하므로 중복 노트를 제거했습니다.
학습 기록을 다른 노트로 옮기면 정답 앞면이 바뀔 수 있어 두 노트의 기록은
이전하지 않았습니다.

v1.3.0 기준 업데이트에서는 예전 어휘·음성 카드 4장이 빈 카드로 남습니다.

- AnkiDroid: `⋮ → 확인 → 빈 카드`
- AnkiMobile: `설정 → 빈 카드`
- PC Anki: `도구 → 빈 카드`

빈 카드 도구의 삭제를 사용합니다. 카드 탐색기의 노트 삭제는 사용하지 않습니다.
출발 버전과 개인 컬렉션 상태에 따라 표시 수는 달라질 수 있습니다.

## 모바일 `내 기록`

AnkiMobile과 AnkiDroid의 답안 화면에서 동의한 사용자가 오늘 공부한 흐름을 이어서
확인합니다. 단순히 오늘 숫자 하나만 보여 주는 화면이 아니라 `오늘·습관`,
`최신·분석`, `JLPT 목표·이력`을 나눠서 제공합니다.

- `오늘·습관`: 답안 화면 확인 횟수를 바로 표시하고, 20회가 되면 오늘 학습 완료로
  표시합니다. 20회는 20개 단어를 외웠다는 뜻이 아니라 하루 학습 세션을 진행했다는
  기준입니다.
- 연속 학습은 실제 완료일을 이어 보여 주고, 7일 실제 완료마다 연속 학습 보호를
  하나씩 충전합니다. 보호는 최대 2개까지 모을 수 있습니다.
- `최신`: 이번 주 현황, 최근 7일 흐름, 이번 달 참고 순위와 학습 달력을 보여 줍니다.
  완료·일부 학습·미학습·보호 사용일을 달력에서 구분합니다.
- `분석`: 최근 7일·30일·3개월·1년·전체 기간의 흐름과 영역·급수·학습 유형별 구성을
  확인합니다. 일간·주간·월간 개인 최고와 최장 연속 학습도 이곳에서 돌아봅니다.
- `JLPT 목표·이력`: 목표 급수와 다음 공식 시험 D-day를 정하고, D-100부터 같은 급수의
  100일 랭킹에서 학습량과 꾸준함을 비교합니다. D-50 중간 결산, 시험일 종료,
  결과와 다음 목표까지 이어지며, 이력에서는 개인 최고와 지난 랭킹을 확인합니다.

공부 흐름에 맞춰 오늘 학습 완료, 어제 기록 추월, 7·30·100·365일 연속 학습,
보호 사용·충전, 개인 최고, 100일 랭킹 시작·중간 결산 같은 순간도 한 번씩 알려 줍니다.

- 처음에는 한 번 안내하고, `내 기록 시작하기`를 눌렀을 때만 기록을 시작합니다.
- `사용하지 않기`를 고르면 덱 학습은 계속되며 자동으로 다시 묻지 않습니다.
- 기록은 모바일에 먼저 저장하므로 오프라인에서도 오늘 상태와 학습 흐름을 볼 수 있고,
  연결이 돌아오면 Worker·Turso로 동기화합니다.
- 카드 내용, 정답 여부, Again·Hard·Good·Easy 선택, Anki 복습 이력, 학습 시간과
  실제 JLPT 결과·응시 여부·JLPT 계정 정보는 수집하지 않습니다.

이번 릴리즈 준비에서 내 기록의 카드 bundle, 생성 HTML, 동의·거절·오프라인·재시도
상태와 후보 APKG를 확인했습니다. 실물 iPhone·iPad·Android 검증과 production
Worker·Turso·D1 migration·배포·활성화는 별도 운영 gate입니다. 따라서 공개 뒤 실제
서비스 제공은 이 운영 rollout이 끝난 뒤 시작합니다. 자세한 수집 범위는
[개인정보·저작권·라이선스](../privacy-and-licensing.md)에서 확인합니다.

## 뜻·예문·품사 재검토

어휘 전체를 같은 기준으로 다시 검토했습니다. 한 label에 서로 다른 뜻이 섞이면
뜻을 나누고, 각 뜻에는 그 의미를 대표하는 예문을 연결했습니다. `断る`는
`거절하다`와 `양해를 구하다`를 분리해 예문이 서로 섞이지 않게 했습니다.

## BCCWJ 중요도 정렬

BCCWJ는 여러 종류의 실제 일본어 문서를 균형 있게 모은 말뭉치입니다. 각 급수
안에서 더 자주 쓰이는 어휘를 먼저 학습하도록 이 빈도 정보를 연결했습니다.

- 같은 표기로 바로 연결: 8,172개
- 표기 변형·구성 요소·검토 연결: 934개
- 말뭉치 미관측: 54개

미관측 어휘도 덱에서 빠지지 않습니다. 단지 관측된 중요도 뒤에 배치합니다.
