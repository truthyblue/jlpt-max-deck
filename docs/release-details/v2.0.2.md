# JLPT MAX Deck v2.0.2 — 문법 후리가나와 더 빠른 내 기록

v2.0.2는 문법 카드의 읽기 도움을 보강하고, 모바일 `내 기록`과 선택형 한자
빌더의 문제를 함께 고친 수정판입니다. 첫 기록 복원이 끝난 뒤에는 기기에 저장된
기록으로 화면과 개인 분석을 바로 계산하고, 서버는 뒤에서 빠진 기록만 확인합니다.

> 2026-08-29 교체: 처음 올라간 한자 빌더가 `K000036`에서 멈추는 문제를
> 고쳤습니다. 한자 확장을 만드는 분은 ZIP을 다시 받아 새 폴더에 풀어 주세요.

## 업데이트 방법

1. 모든 기기를 AnkiWeb과 동기화하고 컬렉션을 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.0.2.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 업데이트 뒤 첫 카드를 열고 `내 기록`이 나타날 때까지 기다립니다.

기존 기록은 새 압축 구조로 자동 이전됩니다. 처음 한 번은 서버 기록을 다시
확인할 수 있지만, 이후에는 화면을 열 때마다 서버를 기다리지 않습니다.

한자 확장을 쓰는 경우에는 v2.0.2 한자 빌더 ZIP으로 지원 PDF 2개를 다시 읽어
한자 APKG를 만든 뒤 가져오세요. 기본 덱만 쓰는 경우에는 빌더가 필요하지 않습니다.

## 문법 카드 후리가나

- 문형 예문과 혼동하기 쉬운 표현에 후리가나를 추가했습니다.
- 문법 형태 문제의 완성 문장과 답안 선택지에 후리가나를 추가했습니다.
- 문장 배열 문제의 완성 문장과 지문 빈칸 문제의 제목·완성 지문·선택지에도
  후리가나를 추가했습니다.
- 문제를 푸는 앞면은 그대로 두고, 정답을 확인하는 답면에서만 보여 줍니다.
- 답면 오른쪽 위의 후리가나 버튼으로 표시를 켜고 끌 수 있습니다.
- 지문 문제의 긴 선택지는 모바일에서 읽기 쉽도록 한 줄에 하나씩 배치했습니다.

## 달라진 점

- 최근 90일의 일별 기록과 최근 1년의 월별 기록을 기기에 보관합니다.
- 7일·30일·이번 달·3개월·1년·전체 합계를 유지합니다.
- 각 기간의 영역별·급수별 합계가 기간 총합과 맞게 계산됩니다.
- 이번 달 순위와 서버 확인은 최대 1시간에 한 번만 새로 받습니다.
- 기기 기록이 하나도 없을 때는 동그란 로딩 표시를 보여 주고, 첫 화면·분석·순위에
  필요한 복원 자료를 한 요청으로 받습니다.
- Android 쿠키에서는 다시 받을 수 있는 자료를 빼고 월별 기록을 더 작게
  압축합니다. 이전 v2.0.1·v2.0.2 저장 구조도 자동으로 새 구조로 옮깁니다.
- 내 기록의 탭·기간 선택을 포함한 버튼 터치 반응을 다듬었습니다.
- 한자 빌더에서 `艹/䒑`·`巴/巳`·`兎(兔)`처럼 여러 자형이 한 칸에 함께
  적힌 글자가 줄바꿈되거나 읽기·쓰기 정답 칸을 벗어나던 문제를 고쳤습니다.
