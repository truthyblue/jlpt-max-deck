# JLPT MAX Deck v2.0.2 — 더 빠르고 안정적인 내 기록

v2.0.2는 모바일 `내 기록`을 기기 우선 방식으로 바꾼 수정판입니다. 첫 동기화가
끝난 뒤에는 기기에 저장된 기록으로 화면과 분석을 바로 계산하고, 서버는 뒤에서
빠진 기록만 확인합니다.

## 업데이트 방법

1. 모든 기기를 AnkiWeb과 동기화하고 컬렉션을 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.0.2.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 업데이트 뒤 첫 카드를 열고 `내 기록`이 나타날 때까지 기다립니다.

기존 기록은 새 압축 구조로 자동 이전됩니다. 처음 한 번은 서버 기록을 다시
확인할 수 있지만, 이후에는 화면을 열 때마다 서버를 기다리지 않습니다.

## 달라진 점

- 최근 90일의 일별 기록과 최근 1년의 월별 기록을 기기에 보관합니다.
- 7일·30일·이번 달·3개월·1년·전체 합계를 유지합니다.
- 각 기간의 영역별·급수별 합계가 기간 총합과 맞게 계산됩니다.
- 이번 달 순위와 서버 확인은 최대 1시간에 한 번만 새로 받습니다.
- Android 쿠키를 더 작게 압축하고 이전 저장 구조를 자동으로 옮깁니다.
- 내 기록의 탭·기간 선택을 포함한 버튼 터치 반응을 다듬었습니다.
- 한자 빌더가 `艹/䒑`처럼 여러 자형을 함께 표시하는 한자를 정상 처리합니다.
