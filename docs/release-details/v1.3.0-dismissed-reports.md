# v1.3.0 오류 제보 기각 내역

v1.3.0 공지 대상 중 기각한 제보 113건의 처리 이유입니다. 이번 검토에서 기각한
7건과 사유 저장 기능을 만들기 전에 닫힌 제보 중 기각 106건을 함께 정리했습니다.
같은 이유의 제보는 한 묶음으로 표시하되, 대상 카드별 접수 건수를 모두 적었습니다.
전체 판단 사유는 27개입니다.

기각은 제보를 확인하지 않았다는 뜻이 아닙니다. 현재 내용이 맞거나 공개 배포본에서
문제를 재현하지 못해 수정하지 않은 경우입니다. 새로운 재현 정보가 들어오면 다시
검토합니다. 제보 번호, 원문, 연락처와 기기 식별 정보는 공개하지 않습니다.

## 이번 검토에서 기각한 제보 — 7건

| 대상 카드 | 건수 | 기각 사유 |
| --- | ---: | --- |
| `英語（えいご）` | 1 | `英語`의 표시 읽기와 합성 입력이 모두 `えいご`로 맞으며, 합성 엔진에서 들리는 차이로 판단해 현행 음성을 유지했습니다. |
| `照る（てる）` | 1 | `照る`는 태양이나 달처럼 주어 자체가 빛을 내는 자동사라 대표 뜻은 `빛나다`가 더 정확합니다. `비치다`는 빛이 다른 장소나 대상에 닿는 뜻으로 더 자주 쓰이므로 대표 뜻을 바꾸지 않았습니다. |
| `軟らかい（やわらかい）` | 1 | 물체의 물리적 부드러움을 나타내는 `軟らかい`는 올바른 표기이므로 유지했습니다. |
| `今月（こんげつ）` | 1 | `今月`의 표시 읽기와 합성 입력이 모두 `こんげつ`로 맞아 현행 음성을 유지했습니다. |
| `財布（さいふ）` | 1 | `財布を家に忘れました`를 자연스러운 한국어로 옮긴 의역이므로 `지갑을 집에 두고 왔습니다`를 유지했습니다. |
| `「りんごやバナナなど」 어휘 문제` | 1 | `や`는 예시를 나열하는 조사지만, 이 문장은 사과와 바나나를 과일의 예로 든 문맥이어서 한국어 `사과와 바나나`도 자연스럽고 뜻을 바꾸지 않습니다. |
| `社会学（しゃかいがく）` | 1 | 공개 v1.2.0 APKG에 `社会学` 예문 음성이 포함되고 정상 디코딩되며 실제 음량도 확인됐지만 제보 증상을 재현하지 못했습니다. 현재 확인 가능한 공통 콘텐츠 오류가 없어 기각하고, 다시 접수되면 카드·Anki 버전·출력 장치를 함께 확인합니다. |

소급 정리했습니다. 아래 19개 사유가 25건이고, 이어지는 가나 보조 카드 1개 사유가
