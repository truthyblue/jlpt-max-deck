# v1.3.0 오류 제보 기각 내역

v1.3.0 공지 대상 중 기각한 제보 113건의 처리 이유입니다. 이번 검토에서 기각한
7건과 사유 저장 기능을 만들기 전에 닫힌 제보 중 기각 106건을 함께 정리했습니다.
같은 이유의 제보는 한 묶음으로 표시하되, 대상 카드별 접수 건수를 모두 적었습니다.
`제보 내용`은 원문의 뜻을 바꾸지 않는 범위에서 맞춤법을 다듬고 짧게 요약했습니다.
전체 판단 사유는 27개입니다.

기각은 제보를 확인하지 않았다는 뜻이 아닙니다. 현재 내용이 맞거나 공개 배포본에서
문제를 재현하지 못해 수정하지 않은 경우입니다. 새로운 재현 정보가 들어오면 다시
검토합니다. 제보 번호, 원문, 연락처와 기기 식별 정보는 공개하지 않습니다.
