# JLPT MAX Deck v1.3.0 상세 변경 내역

v1.3.0은 한자 읽기·쓰기 학습을 분리하고, 중복되던 가나 보조 카드를 정리하는
마이너 업데이트입니다. 새 한자 쓰기 노트 유형과 카드 필드가 들어가므로 기존
사용자는 가져오기 때 기존 노트를 `항상` 업데이트하고 전체 동기화해야 합니다.

## 기존 사용자: 먼저 백업하고 `항상`으로 업데이트

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원 PDF
   2개로 한자 APKG를 다시 만든 뒤 가져옵니다.
5. 아래의 가나 보조 카드 정리를 끝낸 후 모든 기기에서 전체 동기화합니다.

한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됩니다. 기존 한자 확장을 그대로
두면 새 읽기·쓰기 분리, 획순 연습과 혼동 힌트가 적용되지 않습니다.

## 기존 사용자: 가나 보조 카드 정리

v1.3.0부터 어휘 노트는 `어휘`와 `음성` 카드만 만듭니다. 앞면에서 히라가나만
묻던 `어휘(가나 보조)` 카드는 더 이상 만들지 않습니다. 기존 컬렉션에는 APKG
가져오기만으로 예전 카드 행이 자동 삭제되지 않을 수 있어 한 번 정리해야 합니다.

- Android·AnkiDroid: 오른쪽 위 `⋮ → 확인 → 빈 카드`
- iPhone·iPad·AnkiMobile: 오른쪽 위 `설정 → 빈 카드`
- Windows·macOS·Linux Anki: `도구 → 빈 카드`

목록에서 `JLPT MAX덱 어휘 / 어휘(가나 보조)`인지 확인한 뒤 **빈 카드 도구의
삭제**를 누릅니다. 기존 컬렉션 상태에 따라 144장 또는 6,018장으로 보일 수
있습니다. 카드 탐색기에서 `노트 삭제`를 누르면 같은 노트의 어휘·음성 카드까지
지워지므로 사용하면 안 됩니다.

Android와 iPhone·iPad에서는 대상 카드에 처음 들어갈 때 이 절차를 안내하는
팝업을 표시합니다. 가나 보조 카드의 별도 복습 일정과 기록은 버리고 원래 한자
카드로 옮기지 않습니다. 원래 한자 카드의 급수, 카드 ID, 복습 일정과 복습 기록은
그대로 유지됩니다.

## 한자 읽기·쓰기 학습

| 구성 | 수량 | 사용자 결과 |
| --- | ---: | --- |
| 대상 한자 | 2,337자 | 지원 PDF의 한자를 안정 ID로 유지 |
| 읽기 노트·카드 | 2,337개 | 음독·훈독별 단어와 공식 읽기 확인 |
| 쓰기 노트·카드 | 2,337개 | 직접 쓰기, 정답 자형과 획순 연습 |
| PNG 대체 자형 | 14개 | SVG 자형이 깨지던 환경에서도 글자를 표시 |
| 획순 SVG | 2,298개 | 카드 안에서 획순을 열고 다시 재생 |

- 기존 한자 카드는 `한자::읽기`로 옮기되 카드 ID와 학습 기록을 유지합니다.
- 새 `한자::쓰기` 카드는 처음부터 새 학습 항목으로 시작합니다.
- 읽기 카드는 현재 어휘의 실제 단어를 음독·훈독별로 묶습니다.
- 현재 어휘에 단어가 없어도 공식 상용한자 읽기는 빠뜨리지 않고 표시합니다.
- 비슷한 한자는 자형을 크게 보여 주고 뜻·음독·훈독을 함께 비교합니다.
- 쓰기 카드는 첫 터치부터 그리기, 전체 지우기, 정답 자형과 획순 재생을
  지원합니다.

## 기본 APKG와 한자 빌더

- `JLPT-MAX-Deck-1.3.0.apkg`는 어휘·음성·종합 실전·참조표만 포함합니다.
- `JLPT-MAX-kanji-builder-1.3.0.zip`은 사용자가 고른 지원 PDF 2개로 개인용
  `JLPT-MAX-kanji-addon-1.3.0.apkg`를 만듭니다.
- 기본 APKG는 13,903노트·19,921카드, 한자 addon은
  4,674노트·4,674카드입니다.
- 두 APKG를 차례로 가져오면 18,577노트·24,595카드가 됩니다.
- 출판사 PDF 원문·페이지 이미지·추출 원문은 저장소, 빌더 ZIP과 공개 APKG에
  포함하지 않습니다.

## 카드 화면·음성·설정

- 한자 읽기·부수·획수, 발음별 단어와 비슷한 한자의 크기·간격을 모바일 폭에
  맞게 정리했습니다. 카드 앞뒤의 머리글 위치도 고정했습니다.
- 단어 고저 악센트의 읽기 글자를 더 크게 보이게 하되 예문 읽기 크기는 그대로
  유지했습니다. 긴 루비와 괄호 읽기가 서로 밀지 않도록 간격도 보정했습니다.
- 글꼴과 표시 설정을 첫 화면 전에 적용하고 학습 세션 동안 글꼴을 고정해 카드가
  깜빡이거나 글자가 이동하는 현상을 줄였습니다.
- 디코딩된 음성의 첫 유효 소리 직전부터 재생해 앞쪽 무음 때문에 늦게 들리는
  느낌을 줄였습니다. 같은 카드에서 다시 재생할 때는 찾은 위치를 재사용합니다.
- 같은 뜻을 보여 주는 여러 예문은 한 영역에 모으고 다른 뜻의 예문과 분리했습니다.
- iPhone·iPad에서는 무음 모드에서도 카드 음성이 재생되는 방식을 기본값으로
  사용합니다. 카드 설정의 **다른 앱 음악과 함께 재생**을 직접 켠 경우에만 다른
  앱의 음악과 섞어 재생하며, 이 선택은 저장됩니다.

## AnkiDroid와 오류 제보

- AnkiDroid 구형 학습 화면에서 카드 저장·오디오·입력 기능이 제한되면 지원되는
  새 학습 화면으로 옮기는 안내를 팝업으로 표시합니다.
- 오류 제보는 계속 익명이 기본값입니다. 답장을 원하는 경우에만 답장 동의 후
  연락처 입력란이 나타납니다.
- 동의한 연락처는 제보와 분리해 암호화하고 수동 답장에만 사용하며 최대 90일 뒤
  삭제합니다. 동의가 없거나 연락처가 없으면 답장 대상으로 처리하지 않습니다.
- 제보 처리 결과와 기각 사유는 제보 원문·연락처·기기 식별값 없이 공개 가능한
  문장으로 기록합니다.

## 검토된 뜻과 예문

뜻 하나에 예문 하나를 기본으로 두되, 같은 뜻을 서로 다른 맥락에서 보여 줄 필요가
있으면 최대 2개까지 한 묶음으로 보여 주도록 기준을 다듬었습니다.

- `掛かる`: `(비용·시간이) 들다`, `(시간이) 걸리다`로 문맥을 명확히 했습니다.
- `沸騰`: `비등`을 `끓다`로 바꾸고 예문 번역도 자연스럽게 고쳤습니다.
- `細かい`: `작다 · 잘다`와 `자세하다`의 뜻·예문을 다시 연결했습니다.
- `冷やす`: `식히다`를 `차게 하다`로 바로잡고 예문 번역을 고쳤습니다.
- `断る`: `미리 알리고 양해를 구하다`로 뜻을 합쳤습니다.
- `改札`: `개찰하다 / 개찰구`로 나눠 예문을 각각 연결했습니다.
- `定員`: 정해진 인원수와 시설·교통수단의 수용 인원을 구분했습니다.
- `遠慮`: `사양하다 / 거리끼다 · (남을 의식해) 삼가다`로 뜻과 번역을 고쳤습니다.
- `直る`, `負う`, `丘陵`은 겹치거나 부자연스러운 예문을 제거했습니다.
- `帯`, `連携`는 서로 다른 뜻의 예문을 분리했습니다.
- `いらっしゃる`는 `가시다`를 직접 보여 주는 예문으로 중복을 교체했습니다.
- `くまなく`은 `샅샅이 / 빠짐없이`를 각각 보여 주는 예문으로 정리했습니다.
- `長い`, `合流`, `積む`, `遥か`, `開拓`, `食い込む`, `中毒`은 같은 뜻의 서로
  다른 맥락을 한 묶음에서 보여 줍니다.

`りんごやバナナ`, `財布`, `今月`, `軟らかい`, `照る`, `英語`와 공개본에서
재현되지 않은 `社会学` 음성 등 이번에 기각한 7건은 현행 내용이 맞거나 공통
오류를 확인하지 못한 이유를 기록했습니다. 이전 기각 25건을 합친
[기각 32건 전체 처리 내역](v1.3.0-dismissed-reports.md)에서 카드별 이유를 볼 수
있습니다. 예전에 기각했던 가나 보조 카드 제보 81건은 설계를 바꿔 v1.3.0에서
해결했으므로 기각 합계에서 제외했습니다.

사전 버튼을 새 창으로 여는 요청 1건은 카드 오류가 아니라 동작 방식 변경이 필요한
기능 요청이어서 다음 릴리스 검토로 남겼습니다.

## 알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 같은 카드 설정이 초기화됐다는 익명 제보 1건이 있었습니다.
JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았습니다. 현재는 기기 저장
공간이 매우 부족할 때 iOS가 카드 화면의 저장값을 정리했을 가능성을 가장 높게
보고 있지만, 당시 상태를 추가로 확인할 수 없어 원인은 확정하지 못했습니다.

같은 현상이 발생하면 `설정 → 일반 → iPhone/iPad 저장 공간`에서 여유 공간을
확인하고 카드 설정을 다시 저장해 주세요. 반복되면 남은 용량, iOS·AnkiMobile
버전과 앱 재실행 전후 중 언제 발생했는지를 오류 제보에 적어 주세요. 카드 화면
설정은 Anki의 학습 기록·카드 데이터와 별도이므로 학습 기록이 초기화되는 현상은
아닙니다.

## 사용 통계와 배포 신뢰성

- 사용 통계를 켠 경우 업데이트 공지 확인·닫기 이벤트가 일시적인 통신 실패 뒤에도
  다시 전송되도록 했고, 대기 중인 같은 이벤트의 중복을 합쳤습니다.
- 업데이트 버전별 활동과 익명 설치 수 추정치를 추가했습니다. 대시보드 조회 키는
  허용된 범위로 제한했습니다.
- 이 변경은 사용 통계를 새로 켜지 않으며, 기존 선택을 그대로 따릅니다.
- 릴리즈 준비 과정은 승인된 콘텐츠·미디어·APKG를 각각 해시로 묶고 중단 지점부터
  재개하도록 바꿨습니다. 사용자가 받는 최종 APKG는 새 설치와 업데이트 검사를
  통과한 같은 파일입니다.
