# JLPT MAX Deck v1.3.0 상세 변경 내역

v1.3.0은 한자 읽기·쓰기 학습을 분리하고 획순 연습을 추가한 마이너
업데이트입니다. 기존 어휘 카드와 학습 기록은 이어지지만, 새 노트 유형과 필드를
적용하려면 가져오기 때 기존 노트를 `항상` 업데이트하고 전체 동기화해야 합니다.

## 기존 덱에서 업데이트하기

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 v1.3.0 빌더와 지원 PDF 2개로 한자 APKG를 다시
   만들어 가져옵니다.
5. 완료 후 모든 기기에서 전체 동기화합니다.

한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됩니다. 기존 한자 확장을 그대로
두면 새 읽기·쓰기 분리, 획순 연습과 혼동 힌트가 적용되지 않습니다.

## 한자 읽기·쓰기 학습

| 구성 | 수량 | 사용자 결과 |
| --- | ---: | --- |
| 대상 한자 | 2,337자 | 지원 PDF의 한자를 안정 ID로 유지 |
| 읽기 노트·카드 | 2,337개 | 음독·훈독별 단어와 공식 읽기 확인 |
| 쓰기 노트·카드 | 2,337개 | 직접 쓰기, 정답 자형과 획순 연습 |
| 벡터 fallback 자형 | 14개 | 지원 자형이 없는 항목도 같은 화면으로 표시 |

읽기 예시는 현재 어휘와 정확히 연결하고, 현재 어휘에 없는 공식 상용한자 읽기는
별도 fallback으로 남깁니다. 모양이 비슷한 한자는 뜻·음독·훈독을 함께 보여 줘
혼동을 줄입니다.

## public 기본 덱과 한자 빌더의 경계

- `JLPT-MAX-Deck-1.3.0.apkg`는 어휘·음성·종합 실전·참조표만 포함합니다.
- `JLPT-MAX-kanji-builder-1.3.0.zip`은 사용자가 고른 지원 PDF 2개로 개인용
  `JLPT-MAX-kanji-addon-1.3.0.apkg`를 만듭니다.
- 두 APKG를 차례로 가져오면 private 전체 덱과 같은 18,577노트·24,739카드
  구성이 됩니다.
- PDF 원문은 저장소·builder ZIP·공개 APKG에 포함하지 않습니다.

## 카드 화면과 음성

- 한자 읽기·부수·획수와 발음별 단어의 크기·간격을 모바일 폭에 맞게
  재배치했습니다.
- 단어 고저 악센트의 읽기 글자를 더 크게 보이게 하되 예문 읽기 크기는 그대로
  유지했습니다.
- 디코딩된 음성 앞쪽의 무음은 재생 시점에 건너뛰어 첫 소리가 늦게 들리는
  현상을 줄였습니다.
- 같은 뜻을 가리키는 여러 예문은 한 영역으로 묶고, 다른 뜻의 예문과는
  분리했습니다.

## AnkiDroid와 오류 제보

- AnkiDroid 구형 학습 화면에서는 지원되는 새 학습 화면으로 옮기는 안내를
  표시합니다. 카드 안의 저장·오디오·상호작용 기능은 지원되는 화면을 기준으로
  동작합니다.
- 오류 제보의 익명 기본값은 그대로입니다. 사용자가 답장을 원할 때만 연락처와
  답장 동의를 함께 보낼 수 있습니다.
- 연락처가 없거나 동의하지 않은 제보는 답장 대상으로 처리하지 않습니다.

## 검토된 콘텐츠 교정

검토가 끝난 뜻·읽기·예문·고저 악센트·문제 후리가나와 pitch override만
반영했습니다. reviewed-authoring 원본 change set과 audit receipt를 현재 content
closure에 묶었고, 현재 pitch ledger와 맞는 입력만 제품에 포함했습니다.

오류 제보로 확인한 아래 항목도 반영했습니다.

| 항목 | 처리 | 사유 |
| --- | --- | --- |
| `進学塾` 쓰임 문제 | `通っている` 후리가나 `とお` → `かよ` | 학교나 학원에 다닌다는 문맥의 `通う`는 `かよう`로 읽습니다. |

사유 저장 기능을 만들기 전에 닫힌 제보 160건도 기존 검토 기록과 실제 반영 내역을
다시 대조해 55개 공개용 처리 사유로 소급 정리했습니다. 같은 원인의 중복 제보는
같은 사유로 묶되, 각 제보 행에는 사유와 `1.3.0` 공지 버전을 따로 저장합니다.

제보 원문과 연락처는 공개하지 않습니다. 해결 또는 현행 유지로 닫은 제보는 공개
가능한 처리 사유와 이 결과를 알릴 버전을 함께 기록하고, 해당 버전 공지에서 익명으로
요약합니다.

## 전체 덱과 업데이트 검증

- private 전체 APKG: 18,577노트·24,739카드
- public 기본 APKG: 13,903노트·20,065카드
- public 기본 미디어: 18,437개
- 한자 addon: 4,674노트·4,674카드
- fresh profile import: 1회 통과
- v1.2.1 → v1.3.0 update import: 1회 통과
- 최종 APKG 생성: 1회
- TTS 합성: 0회
- 기존 MP3 base 전체 복제: 0회
- 변경 MP3 encode와 delta entry: 각 3개
- finalize와 public prepare의 private build/import: 0회

기존 어휘·실전 문제·참조표의 안정 ID와 학습 기록은 유지됩니다. 한자 쓰기
노트는 v1.3.0에서 새로 추가되므로 처음 가져올 때 새 학습 항목으로 시작합니다.

실물 iPhone·iPad와 Android의 모든 조합에서는 이번 정식판을 따로 전수
검증하지 않았습니다. 실제 배포 APKG의 fresh/update import, builder 구조,
해시와 모바일 폭 HTML 렌더링을 확인했습니다.
