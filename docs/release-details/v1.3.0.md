# JLPT MAX Deck v1.3.0 — 한자 쓰기 카드 추가

v1.3.0은 **한자 쓰기 카드 2,337장**을 추가하고 한자 읽기 카드·음성·예문·모바일
설정을 다듬은 업데이트입니다. 중복되던 가나 보조 카드는 더 이상 만들지 않습니다.

## 기존 사용자: 먼저 백업하고 `항상`으로 업데이트

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원 PDF
   2개로 한자 APKG를 다시 만든 뒤 가져옵니다.
5. 아래의 가나 보조 카드 정리를 끝낸 후 모든 기기에서 전체 동기화합니다.

앞으로 JLPT MAX 덱을 업데이트할 때는 출발 버전과 관계없이 **기존 노트 업데이트를
`항상`**으로 선택합니다. 직접 고친 공식 노트 필드는 덮어쓸 수 있으므로 그런
수정이 있다면 먼저 백업하세요. 한자 확장을 쓰지 않으면 기본 APKG만 가져오면
됩니다.

## 업데이트 뒤 가나 보조 카드 144장 정리

v1.2.1에서 v1.3.0을 실제로 가져오면 기존 `어휘(가나 보조)` 카드 144장은
물리적으로 남지만, Anki의 **빈 카드** 검사에 144장 모두 잡힙니다. 해당 카드는
앞면이 비었다는 화면만 표시합니다.

- Android·AnkiDroid: 오른쪽 위 `⋮ → 확인 → 빈 카드`
- iPhone·iPad·AnkiMobile: 오른쪽 위 `설정 → 빈 카드`
- Windows·macOS·Linux Anki: `도구 → 빈 카드`

목록에서 `JLPT MAX덱 어휘 / 어휘(가나 보조)`인지 확인한 뒤 **빈 카드 도구의
삭제**를 누릅니다. 이 작업은 가나 보조 카드와 그 카드의 복습 기록만 지우고 같은
노트의 어휘·음성 카드는 남깁니다. 카드 탐색기에서 `노트 삭제`를 누르면 같은
노트의 다른 카드까지 지워지므로 사용하면 안 됩니다. 더 오래된 버전이나 컬렉션
상태에 따라 표시 수는 달라질 수 있습니다.

Android와 iPhone·iPad에서는 대상 카드에 처음 들어갈 때 이 절차를 안내합니다.

![가나 보조 카드 정리 안내](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kana-cleanup-notice.png)

## 한자 읽기 카드에 발음별 단어·혼동 힌트 추가

기존 한자 카드 2,337장은 같은 카드 ID·일정·복습 기록을 유지한 채 새 읽기
화면으로 바뀝니다. 실제 단어를 음독·훈독별로 묶고 현재 어휘에 없는 공식
상용한자 읽기도 표시합니다. 모양이 비슷한 한자는 뜻·음독·훈독을 함께 비교합니다.

일반 APKG 가져오기는 기존 카드의 덱 위치를 바꾸지 않습니다. 기존 카드는
`일상무따::상권·하권`이나 사용자가 옮겨 둔 덱에 그대로 남고, 새
`한자::읽기::상권·하권`은 비어 있을 수 있습니다. 새 폴더 구조를 쓰려면 카드
탐색기에서 기존 상권·하권 카드를 각각 `한자::읽기::상권·하권`으로 직접 옮기세요.
사용자가 따로 배치한 카드는 원하는 경우에만 옮기면 됩니다.

## 기본 APKG와 한자 빌더

- `JLPT-MAX-Deck-1.3.0.apkg`는 어휘·음성·종합 실전·참조표만 포함합니다.
- `JLPT-MAX-kanji-builder-1.3.0.zip`은 사용자가 고른 지원 PDF 2개로 개인용
  `JLPT-MAX-kanji-addon-1.3.0.apkg`를 만듭니다.
- 기본 APKG는 13,903노트·19,921카드, 한자 addon은
  4,674노트·4,674카드입니다.
- 두 APKG를 차례로 가져오면 18,577노트·24,595카드가 됩니다.
- 출판사 PDF 원문·페이지 이미지·추출 원문은 저장소, 빌더 ZIP과 공개 APKG에
  포함하지 않습니다.

## 음성이 약간 느리게 재생되던 문제 수정

일부 카드에서 음성 앞쪽의 짧은 무음 때문에 재생이 약간 늦게 시작되는 느낌이
있었습니다. 디코딩된 음성의 첫 유효 소리 직전부터 재생하고, 같은 카드에서 다시
재생할 때는 찾은 위치를 재사용하도록 고쳤습니다. 원본 음성 18,434개는 이전
승인본과 byte 단위로 같습니다.

## iPhone·iPad 무음 모드 재생을 기본값으로 변경

v1.3.0부터 iPhone·iPad의 기본 재생 방식을 바꿨습니다. 이전 버전에서는 다른 앱
음악과 카드 음성이 함께 재생되는 대신 무음 모드에서 카드 음성이 나오지 않을 수

필요하면 카드 설정의 **다른 앱 음악과 함께 재생**을 켜면 됩니다. 이 옵션을 켜면
무음 모드에서는 카드 음성이 나오지 않을 수 있으며 선택값은 저장됩니다.

## 검토된 뜻·읽기·예문 오류 교정

뜻 하나에 예문 하나를 기본으로 두되, 같은 뜻을 서로 다른 맥락에서 보여 줄 필요가
있으면 최대 2개까지 한 묶음으로 보여 주도록 기준을 다듬었습니다.

- `掛かる`: `(비용·시간이) 들다`, `(시간이) 걸리다`로 문맥을 명확히 했습니다.
- `沸騰`: `비등`을 `끓다`로 바꾸고 예문 번역도 자연스럽게 고쳤습니다.
- `細かい`: `작다 · 잘다`와 `자세하다`의 뜻·예문을 다시 연결했습니다.
- `冷やす`: `식히다`를 `차게 하다`로 바로잡고 예문 번역을 고쳤습니다.
- `断る`: `미리 알리고 양해를 구하다`로 뜻을 합쳤습니다.
- `改札`: `개찰하다 / 개찰구`로 나눠 예문을 각각 연결했습니다.
- `定員`: 정해진 인원수와 시설·교통수단의 수용 인원을 구분했습니다.
- `遠慮`: `사양하다 / 거리끼다 · (남을 의식해) 삼가다`로 뜻과 번역을 고쳤습니다.
- `直る`, `負う`, `丘陵`은 겹치거나 부자연스러운 예문을 제거했습니다.
- `帯`, `連携`는 서로 다른 뜻의 예문을 분리했습니다.
- `いらっしゃる`는 `가시다`를 직접 보여 주는 예문으로 중복을 교체했습니다.
- `くまなく`은 `샅샅이 / 빠짐없이`를 각각 보여 주는 예문으로 정리했습니다.
- `長い`, `合流`, `積む`, `遥か`, `開拓`, `食い込む`, `中毒`은 같은 뜻의 서로
  다른 맥락을 한 묶음에서 보여 줍니다.

## 알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 같은 카드 설정이 초기화됐다는 익명 제보 1건이 있었습니다.
JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았습니다. 현재는 기기 저장
공간이 매우 부족할 때 iOS가 카드 화면의 저장값을 정리했을 가능성을 가장 높게
보고 있지만, 당시 상태를 추가로 확인할 수 없어 원인은 확정하지 못했습니다.

같은 현상이 발생하면 `설정 → 일반 → iPhone/iPad 저장 공간`에서 여유 공간을
확인하고 카드 설정을 다시 저장해 주세요. 반복되면 남은 용량, iOS·AnkiMobile
버전과 앱 재실행 전후 중 언제 발생했는지를 오류 제보에 적어 주세요. 카드 화면
설정은 Anki의 학습 기록·카드 데이터와 별도이므로 학습 기록이 초기화되는 현상은
아닙니다.

## 사용 통계와 배포 신뢰성

- 사용 통계를 켠 경우 업데이트 공지 확인·닫기 이벤트가 일시적인 통신 실패 뒤에도
  다시 전송되도록 했고, 대기 중인 같은 이벤트의 중복을 합쳤습니다.
- 업데이트 버전별 활동과 익명 설치 수 추정치를 추가했습니다. 대시보드 조회 키는
  허용된 범위로 제한했습니다.
- 이 변경은 사용 통계를 새로 켜지 않으며, 기존 선택을 그대로 따릅니다.
- 릴리즈 준비 과정은 승인된 콘텐츠·미디어·APKG를 각각 해시로 묶고 중단 지점부터
  재개하도록 바꿨습니다. 사용자가 받는 최종 APKG는 새 설치와 업데이트 검사를
  통과한 같은 파일입니다.
