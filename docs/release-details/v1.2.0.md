# JLPT MAX Deck v1.2.0 뜻·예문 상세 변경 내역

> 상태: 해시가 고정된 v1.2.0 공개 후보 기준입니다. 외부 공개 전 최종 승인을 기다리고 있습니다.

이 문서는 이전 버전과 비교해 학습자 화면에서 실제로 달라지는 항목만 정리합니다. 유지 판정과 내부 검토 정보는 싣지 않습니다.

## 읽는 법

- `·`는 한 뜻 묶음 안에서 함께 익힐 표현입니다.
- `/`는 따로 구분해서 익힐 뜻입니다.
- 예문 옆 뜻 칩은 해당 예문이 보여 주는 뜻 하나만 표시합니다.
