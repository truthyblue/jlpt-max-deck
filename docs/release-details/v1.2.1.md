# JLPT MAX Deck v1.2.1-pre.2 상세 변경 내역

## 릴리스 경계

이번 파일은 정식 v1.2.1이 아니라 `v1.2.1-pre.2` 검토용입니다. APKG 내부 버전은
업데이트 호환성을 위해 `1.2.1`로 유지하고, 다운로드 파일명에는
`JLPT-MAX-Deck-1.2.1-pre.2.apkg`를 사용합니다.

## v1.2.0에서 유지한 것

| 항목 | 결과 |
| --- | ---: |
| 뜻 표시 순서에 맞춰 예문 순서를 바꾼 어휘 | 102개 |

뜻 문구 자체와 예문 문장·번역·음성은 이 변경에서 바꾸지 않았습니다.

## pre2에서 바꾼 카드 표시

### 한자 버튼

한자 버튼을 직접 만든 클릭 스크립트에서 기본 HTML `details/summary`로
복원했습니다. 그래서 Mac Anki의 WebKit이 처리하는 기본 열기·닫기 동작을
사용합니다. 카드의 사전 버튼과 한자 버튼은 같은 높이와 폭을 쓰도록 맞췄고,
화살표는 닫힘·펼침 모두 같은 11×11px 칸을 사용합니다. 펼칠 때는 같은
화살표를 180도 돌린 뒤 글꼴의 위아래 여백 차이를 3px 보정하므로 `한자`
글자의 가로 위치가 밀리지 않고 두 화살표의 표시 영역도 맞습니다.
한자 패널을 열었을 때 본문이 보이는지도 확인했습니다.

### 후리가나와 고저표

후리가나는 본문 글자의 폭을 차지하는 별도 상자처럼 처리하지 않습니다. 예를
들어 `携帯電話`의 본문과 고저 곡선은 기존 위치를 유지하고, 좁은 모라 칸의
`けい`·`たい` 같은 라벨만 그 칸 안에서 줄여 표시합니다. 긴 후리가나가 옆
단어를 밀어내는 경우에는 실제로 겹칠 때만 겹친 만큼 간격을 넣습니다.

WebKit에서 `<ruby><rt>`를 다루는 방식이 다른 경우에는 후리가나를 카드 전용
표시 상자로 바꿔 같은 위치에 놓습니다. 글꼴 전환 중에는 글꼴이 준비될 때까지
카드를 숨겼다가 한 번에 보여 줍니다. 이 때문에 `財` 카드로 이동할 때 굵은
글꼴이 일반 글꼴로 깜빡이는 현상과 고저표의 초기 위치 튐을 함께 줄였습니다.

## 콘텐츠 교정

| 제보 | 수정 |
| --- | --- |
| `猛` 선택지 후리가나 | `たけし` → `もう` |
| `縁` 뜻 간격 | `① 인연 연  ② 가장자리 연·테두리 연` → `① 인연 연 ② 가장자리 연 · 테두리 연` |
| `木曜日` 문제 해설 | 정답 ②의 해설이 보기 ②를 설명하도록 순서 교정 |

이 세 교정은 기존 노트·카드 ID를 바꾸지 않는 카드 생성 단계의 보정입니다.
