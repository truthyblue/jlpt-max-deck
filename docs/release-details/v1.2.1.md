# JLPT MAX Deck v1.2.1-pre.1 상세 변경 내역

## 변경 범위

v1.2.0과 v1.2.1 공개 기본 덱의 같은 GUID 13,903개를 비교했습니다.

| 항목 | 결과 |
| --- | ---: |
| 뜻 표시 순서에 맞춰 예문 순서를 바꾼 어휘 | 102개 |
| 슬래시 뜻을 흰색 영역으로 나눠 표시한 어휘 | 651개 |
| 두 변경의 합집합 | 697개 |
| 추가·삭제된 노트 | 0개 |
| 바뀐 음성 | 0개 |

102개와 651개에는 두 조건에 모두 해당하는 어휘가 있어 합계가 697개입니다.
뜻 문구 자체와 예문 문장·번역·음성은 바꾸지 않았습니다.

## 대표 예시: 取る

- 뜻: `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다`
- v1.2.1 예문 뜻 순서:
  `잡다 → 집다 → 들다 → 빼앗다 → 얻다 → 없애다`
- 흰색 예문 영역:
  `잡다 · 집다 · 들다`, `빼앗다`, `얻다`, `없애다`의 4개

## 업데이트 호환성

Anki 25.09.2에서 v1.2.0 공개 APKG를 가져온 폐기 가능한 컬렉션에 v1.2.1 공개
APKG를 다음 설정으로 가져왔습니다.

- 학습 진행 상태 가져오기: 끄기
- 기존 노트 업데이트: 새 버전일 때
- 노트 유형 병합: 켜기

가져오기 뒤 컬렉션을 닫았다가 다시 열어 확인한 결과입니다.

- 공유 노트 13,903개 중 필드 불일치 0개
- 새 노트 0개, 중복 0개, 충돌 0개
- 카드 템플릿과 CSS가 새 v1.2.1 기본 덱과 일치
- 기존 노트와 노트 유형 ID 유지
- 검사용 카드의 due·interval·reps·lapses·flag·data 유지
- 카드 표시, 익명 통계와 오류 제보의 버전이 `1.2.1-pre.1`로 일치

프리릴리스 동안 `site/latest-release.json`과 공식 사이트는 v1.2.0으로
유지하므로 기존 카드에 v1.2.1-pre.1 업데이트 안내가 나타나지 않습니다.
