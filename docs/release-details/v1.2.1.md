# JLPT MAX Deck v1.2.1 상세 변경 내역

v1.2.1은 카드를 넘길 때 글꼴과 글자가 움직이는 현상을 줄이고, 뜻과 예문을
같은 순서로 맞춘 안정화 업데이트입니다.

## v1.2.0에서 업데이트하기

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.2.1.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 새 버전일 때**,
   **노트 유형 병합 → 켜기**를 선택합니다.

한자 확장 내용은 그대로이므로 v1.2.0에서 만든 확장을 다시 만들 필요가 없습니다.

## 뜻과 예문

| 바뀐 점 | 수량 | 사용자가 보는 변화 |
| --- | ---: | --- |
| 뜻 표시 순서에 맞춰 예문 순서 조정 | 102개 | 위에서 본 뜻과 아래 예문을 같은 순서로 읽을 수 있음 |
| `/`로 나뉜 뜻의 예문을 영역별로 구분 | 651개 | 서로 다른 뜻의 예문을 흰색 영역으로 나눠 볼 수 있음 |
| 두 변경의 합집합 | 697개 | 두 조건에 모두 해당하는 어휘는 한 번만 셈 |

`取る`는 `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다` 순서로 뜻이 나오고,
예문도 같은 순서로 나옵니다. 뜻 문구, 예문 문장, 번역과 음성은 바꾸지 않았습니다.

## 카드 화면

### 글꼴 깜빡임

Mac Anki에서 새 카드로 넘어갈 때 일본어가 굵게 보였다가 선택한 글꼴로 바뀌는
순간을 줄였습니다. 고저 악센트 선도 처음 나타날 때 덜 움직입니다. 설정에서
명조체와 고딕체를 바꿀 때는 카드 전체가 사라지지 않고 글꼴만 바로 바뀝니다.

### 후리가나와 고저 악센트

긴 후리가나가 옆 글자를 밀어내지 않습니다. 후리가나끼리 실제로 닿을 때만
필요한 만큼 간격을 벌립니다. 문장과 고저 악센트 선은 원래 자리를 유지하므로
길이가 긴 읽기도 더 안정적으로 볼 수 있습니다.

### 한자 버튼

한자 버튼과 사전 버튼의 높이와 폭을 맞췄습니다. 한자 내용을 열고 닫을 때
화살표와 `한자` 글자가 옆으로 밀리지 않으며, 펼친 내용도 정상적으로 보입니다.

![Mac Anki에서 한자 버튼과 사전 버튼을 나란히 표시한 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-kanji-disclosure-closed.png)

## 모바일 익명 통계 설정

iPhone·iPad와 Android 카드에서 `익명 통계` 설정과 동의 창이 정상적으로 열립니다.
공유를 껐다 다시 켜거나 덱을 업데이트해도 같은 기기를 새 설치로 중복 집계하지
않습니다. 앱 데이터 삭제나 재설치 때만 새 설치로 집계됩니다.
