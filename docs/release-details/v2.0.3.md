# JLPT MAX Deck v2.0.3 — 내 기록 자동 복구와 공지 화면 수정

v2.0.3은 모바일 `내 기록`의 자동 복구와 연결 재시도를 보강하고, JLPT 목표 카드와
개인 최고 기록 알림, 문법 카드 공지 화면을 고친 수정판입니다.

## 업데이트 방법

1. 모든 기기를 AnkiWeb과 동기화하고 컬렉션을 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.0.3.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 업데이트 뒤 첫 카드를 열고 `내 기록`을 확인합니다.

기존 학습 일정과 복습 기록은 유지됩니다. 한자 확장을 쓰는 경우에는 v2.0.3
한자 빌더로 지원 PDF 2개를 다시 읽어 한자 APKG를 만든 뒤 가져오세요.

## 달라진 점

- 기기에 기록이 남아 있는데 서버 응답이 비어 있으면 기록과 JLPT 목표를 자동으로
  다시 확인합니다.
- 잠깐 연결이 불안정한 경우에는 바로 실패로 표시하지 않고 한 번 자동으로 다시
  시도합니다.
- 일반 연결 오류와 실제 기록 복구 실패를 구분해 안내합니다.
- JLPT 목표의 상세 일정이 늦게 도착해도 목표 카드는 기존 초록색 흐름을 유지합니다.
- 하루 개인 최고 기록 알림은 같은 날 한 번만 카드 가운데에 보여 줍니다.
- 문법 카드의 업데이트 공지도 어두운 배경, 둥근 창과 버튼 스타일을 사용합니다.
