- 실제 v2.0.0 후보 콘텐츠와 생성 카드에서 다시 확인했습니다.
- 수정하지 않은 건은 “제보가 틀렸다”로 끝내지 않고 현재 내용을 유지하는 이유를
  남겼습니다.

  처리 시각은 바꾸지 않았습니다.
