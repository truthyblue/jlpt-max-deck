# Anki 시작·학습·업데이트 가이드

[README](../README.md) · [웹 시작 가이드](https://truthyblue.github.io/jlpt-max-deck/getting-started.html) ·
[덱 학습법](https://truthyblue.github.io/jlpt-max-deck/study-guide.html) ·
[업데이트](https://truthyblue.github.io/jlpt-max-deck/update.html) · [문제 해결](troubleshooting.md)

## 내 상황에 맞는 안내

- **Anki가 처음이에요**: 앞으로 공부할 기기에 앱을 설치한 뒤 기본 덱을 가져옵니다.
- **Anki를 이미 사용 중이에요**: 여러 기기의 동기화를 먼저 끝내고 같은 컬렉션에
  기본 덱을 추가합니다.
- **JLPT MAX덱을 업데이트할게요**: 기존 덱을 지우기 전에
  [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)의 버전별 절차를 확인합니다.

Anki에 익숙해도 덱마다 시작하는 때와 공부 방법이 다릅니다. 가져오기를 마쳤다면
[덱 학습법](https://truthyblue.github.io/jlpt-max-deck/study-guide.html)도 확인하세요.

## 처음 설치

1. 공부할 기기에 맞는 [공식 Anki 앱](https://truthyblue.github.io/jlpt-max-deck/install-anki.html)을
   설치합니다. 휴대폰으로 공부할 예정이라면 휴대폰에 바로 설치하는 방식을
   권장합니다.
2. [JLPT-MAX-Deck-2.0.3.apkg](https://github.com/truthyblue/jlpt-max-deck/releases/download/v2.0.3/JLPT-MAX-Deck-2.0.3.apkg)를
   같은 기기에서 받습니다.
3. Anki Desktop에서는 **파일 → 가져오기**, 모바일에서는 다운로드한 APKG의
   **열기** 또는 **공유**를 사용합니다.
4. 약 1.12GB의 미디어 처리가 끝날 때까지
   앱을 종료하거나 기기를 잠그지 않습니다.
5. 최상위 `JLPT MAX덱`을 확인합니다.

AnkiWeb 웹사이트는 APKG를 직접 가져오는 앱이 아닙니다. 한 기기에서만 학습한다면
계정이나 동기화 없이도 시작할 수 있습니다.

## 가져오기 확인

첫 카드를 열기 전에 기본 덱 수량을 확인합니다.

| 구성 | 노트 | 카드 | 미디어 |
| --- | ---: | ---: | ---: |
| 기본 덱: 문법·어휘·음성·실전 문제·참조표 | 20,650 | 38,970 | 24,978 |

기본 덱에 `일상무따`가 없는 것은 정상입니다. 한자 덱은 원하는 경우에만 따로
만들어 같은 컬렉션에 추가합니다.

## FSRS 확인

FSRS는 새 컬렉션에서도 항상 자동으로 켜지는 설정이 아닙니다. Desktop은 덱 옆
톱니바퀴에서 **옵션**, iPhone·iPad는 덱 화면의 톱니바퀴에서 **학습 옵션**,
Android는 덱 메뉴에서 **덱 옵션**을 엽니다.

- FSRS: 켜기
- 원하는 보존율: 0.90
- 카드 일정 다시 계산: 끄기

FSRS는 덱별이 아니라 컬렉션 전체에 적용됩니다. 이미 Anki를 쓰고 있다면 현재
설정을 먼저 확인하세요. 꺼져 있다면 다른 덱에도 적용된다는 점을 확인한 뒤 켭니다. APKG는
FSRS용 보존율을 포함하지만 FSRS 자체를 켜거나 끄지 않습니다.

## 첫 카드와 답 버튼

`JLPT MAX덱::어휘::N5`를 누릅니다. 앞면의 단어를 보고 읽기와 핵심 뜻을 함께
떠올린 뒤 답을 엽니다.

- `Again`: 읽기나 뜻 중 하나라도 틀렸거나 떠올리지 못함
- `Hard`: 맞혔지만 오래 걸리거나 확신이 부족함
- `Good`: 읽기와 핵심 뜻을 제대로 떠올림
- `Easy`: 이미 확실히 알아 즉시 떠올림

`Hard`는 오답 버튼이 아닙니다. 틀린 카드는 `Again`을 누릅니다.

## 덱 학습 순서

### 어휘

N2 시험을 본다면 `N5 → N4 → N3 → N2`, N4 시험을 본다면 `N5 → N4`
순서로 공부합니다. 지금 공부하는 급수의 새 카드가 0장이 되면 다음 급수로
넘어가고, 앞서 공부한 급수의 복습은 계속합니다.

복습을 먼저 끝낸 뒤 새 카드를 하루 20장
봅니다. 부담되면 10장, 복습이 밀리면
0장으로 줄입니다. 이미 아는 카드가 많아 `Easy`로 빠르게 끝나고 복습량도 낮다면
새 카드를 늘려도 됩니다.

필터 덱은 선택 기능입니다. 처음이라면 급수별 어휘 덱을 차례로 누르는
기본 방식으로 시작하세요. 앞서 공부한 급수의 복습과 현재 급수의 새 카드를
하나의 `어휘 통합 학습` 덱에서 보고 싶을 때만
[필터 덱 설정](https://truthyblue.github.io/jlpt-max-deck/study-guide.html#filtered)을 따라하세요.

`어휘::N5::수량 표현`, `날짜`, `월`, `요일`은 N5 기초 연습입니다. `참조표`는
매일 외우는 덱이 아니라 필요할 때 찾아보는 보조 자료입니다.

### 일상무따 한자

원하는 경우에만 추가합니다. 1권이 상권이고 2권이 하권입니다. N3 어휘를
시작할 때 1권(상권)을, N2 어휘를 시작할 때 2권(하권)을 함께 시작하세요.
이미 N1을 공부하고 있다면 2권을 지금 시작하면 됩니다. 기본은 어휘 20장과
한자 20장입니다. 부담되면 한자부터 10장으로 줄이세요.

### 종합 실전

시험 볼 급수까지 어휘를 모두 한 번 본 뒤 시작합니다. N4 시험을 본다면
`종합 실전::어휘::N4`만, N2 시험을 본다면 `종합 실전::어휘::N2`만 누르세요.
실전 문제는 N5부터 차례대로 풀 필요가 없습니다. 새 문제는 하루 20개씩 보고,
문제 유형은 `무작위 노트` 순서로 섞습니다. 찍어서 맞힌 문제는 `Again`을 누릅니다.

### 음성

소리만 듣고 단어를 떠올리는 연습에 사용합니다. 이미 공부 중이라면 지금 새 카드
설정을 유지하세요. 처음 시작한다면 하루
5–10장부터 봅니다.

## 새 버전으로 업데이트

업데이트 전 모든 기기의 동기화를 끝내거나 백업을 확인합니다. 기존 덱을 삭제하지
않고 현재 v2.0.3 APKG를 가져옵니다.

AnkiDroid v2.0.0에서 카드가 정상적으로 열리면 이 절차로 v2.0.1을 가져올 때 기록
저장 구조가 자동으로 바뀝니다. 이미 `500` 또는
`Protocol message contained an invalid tag` 오류가 뜬다면 먼저 AnkiWeb과
완전히 동기화하고 백업한 뒤 앱 데이터를 지우거나 앱을 다시 설치하고 v2.0.1을
가져옵니다. 동기화하지 않은 기록은 앱 데이터 삭제·재설치 때 사라질 수 있습니다.

- 학습 진행 상태 가져오기: 끄기
- 기존 노트 업데이트: 항상
- 노트 유형 업데이트: 항상
- 노트 유형 병합: 켜기
- 개인 덱 옵션: 보존

앞으로 모든 JLPT MAX 덱 업데이트에서 기존 노트 업데이트는 `항상`을 선택합니다.
출발 버전에 따라 옵션을 다르게 고를 필요가 없습니다. `항상`은 직접 수정한 공식
노트 필드도 덮어쓸 수 있으므로 그런 수정이 있다면 먼저 백업하거나 별도 프로필에서
확인합니다.

v2.0.0의 BCCWJ 중요도 순서는 이미 있는 카드의 순서와 일정을 자동으로 바꾸지
않습니다. 완전히 미학습 상태인 급수에서 새 순서를 처음부터 쓰고 싶을 때만 그
급수의 `JLPT MAX덱::어휘::N○`와 `JLPT MAX덱::음성::N○`를 함께 삭제한 뒤 다시
가져옵니다. 이미 학습한 급수는 정렬만을 위해 삭제하지 않습니다.

v1.2.1 이하에서 업데이트했다면 Anki의 빈 카드 메뉴에서
`JLPT MAX덱 어휘 / 어휘(가나 보조)`만 골라 삭제합니다. v1.3.0을 사용한 적이
있다면 `五万`과 `～キロ`가 남아 있을 수 있습니다. 이 둘은 빈 카드가 아니므로
카드 탐색기에서 각 어휘를 검색해 해당 노트를 삭제합니다. 보이지 않으면
건너뜁니다.

기존 한자 확장은 현재 v2.0.3 빌더로 다시 만듭니다. 새 확장은 한자
2,337개에 읽기와 쓰기 노트를 각각 만들어
4,674장의 카드를 제공합니다. 기본 덱과 새
한자 확장 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

일반 APKG 가져오기는 기존 한자 카드의 덱 위치를 바꾸지 않습니다. 기존 카드는
`일상무따::상권·하권`이나 사용자가 옮겨 둔 덱에 남고,
`한자::읽기::상권·하권`은 비어 있을 수 있습니다. 새 폴더 구조를 쓰려면 카드
탐색기에서 기존 상권·하권 카드를 읽기 상권·하권으로 직접 옮기세요. 사용자가 따로
배치한 카드는 원하는 경우에만 옮깁니다.

업데이트 뒤 교체된 음성의 예전 파일이 미사용 상태로 남을 수 있습니다. 새 카드와
음성이 정상인지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki에서
`도구 → 미디어 검사`를 열어 미사용 파일 목록을 확인하고 삭제한 다음 다시
동기화합니다. 다른 덱의 미사용 파일도 함께 표시될 수 있으므로 목록을 먼저
확인하세요. 삭제한 파일은 운영체제 휴지통에서 복구할 수 있습니다.

업데이트해도 개인 설정은 그대로 남으므로 실전 설정만 확인합니다. 음성 덱의 새
카드 수를 포함한 나머지 옵션은 지금 설정을 그대로 둡니다.

- `JLPT MAX덱 · 실전` → 신규 카드 수집: `무작위 노트`

## 여러 기기에서 이어서 학습

한 기기만 쓰더라도 분실이나 고장에 대비해 컬렉션을 AnkiWeb에 보관할 수 있습니다.
처음 사용자는 덱을 가져온 기기에서 한 번 학습한 뒤 동기화하세요. 여러 기기에서
이어 공부한다면 그 기기의 컬렉션을 AnkiWeb에 업로드하고 다른 기기에서
내려받습니다. 처음 동기화할 때는 미디어 파일이 많으므로 안정적인 Wi-Fi를
사용하세요.
