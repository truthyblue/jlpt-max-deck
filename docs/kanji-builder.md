# 일상무따 한자 확장 만들기

이 도구는 지원 PDF 2개를 사용자 컴퓨터에서 읽어
`JLPT MAX덱::일상무따` 한자 2,337개를 읽기·쓰기 카드로 구성한 개인용 APKG를
만듭니다. 완성된 APKG는 같은 버전의 기본 덱을 가져온 Anki 컬렉션에 추가합니다.

기본 덱에는 한자 읽기·쓰기 note family가 들어 있지 않습니다. 공개 빌더 자산은
두 family의 뜻 없는 skeleton을 보관하고, PDF에서 뜻과 필요한 자형을 채운 뒤 두
family를 함께 내보냅니다.

출판사 자료의 한글 뜻과 일부 인쇄 자형이 들어간 완성 APKG는 배포하지 않습니다.
ZIP 안의 제작용 자산에는 한글 뜻이 비어 있으며, 아래 실행 파일이 사용자 PDF에서
필요한 부분을 채워 완성본을 만듭니다.

## 준비물

- 길벗 《일본어 상용한자 무작정 따라하기》 1권과 2권의 지원 소책자 PDF
  - 1권 공식 자료: https://www.gilbut.co.kr/book/view?bookcode=BN003617
  - 2권 공식 자료: https://www.gilbut.co.kr/book/view?bookcode=BN003669
- macOS 또는 Windows x64 컴퓨터
- 처음 실행할 때 필요한 프로그램을 받을 인터넷 연결

PowerShell이나 터미널을 열 필요가 없고 Python도 직접 설치하지 않습니다. 실행
파일이 빌더 전용 폴더에 필요한 프로그램을 자동으로 준비합니다.

## Windows

1. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 `모두 압축 풀기`를 선택합니다.
   ZIP 미리보기 안에서 바로 실행하지 마세요.
2. 압축을 푼 폴더에서 `Windows에서 한자 확장 만들기.cmd`를 더블클릭합니다.
3. 첫 번째 PDF 선택창에서 1권(상권), 두 번째 선택창에서 2권(하권)을 고릅니다.
4. 완료될 때까지 열린 창을 닫지 않습니다.

## macOS

1. ZIP 파일을 더블클릭해 압축을 풉니다.
2. 압축을 푼 폴더에서 `Mac에서 한자 확장 만들기.command`를 더블클릭합니다.
3. 첫 번째 PDF 선택창에서 1권(상권), 두 번째 선택창에서 2권(하권)을 고릅니다.
4. 완료될 때까지 열린 창을 닫지 않습니다.

처음 실행할 때만 빌드 도구와 Python을 자동으로 받으므로 시간이 걸릴 수 있습니다.
PDF와 그 페이지 이미지, 생성한 APKG는 외부로 전송되지 않습니다. 빌더나 PDF가
있는 폴더 이름에 한글이나 띄어쓰기가 있어도 됩니다.

성공하면 완성된 폴더가 자동으로 열립니다. 그 안의 한자 확장 APKG를 기본 덱
다음에 Anki로 가져오세요. 정확한 파일명은 완료 안내와 빌드 리포트에 표시됩니다.

`assets` 폴더의 파일은 제작용 자산입니다. 직접 설치하거나 열지 마세요. 빌더는
PDF 해시·페이지 수·표의 2,337개 위치를 모두 확인한 뒤에만 완성 APKG를 냅니다.

오류가 나면 빌더 폴더의 `kanji-builder.log`를 확인하세요. 전체 로그나 PDF를
공개 issue에 첨부하지 말고 개인 경로를 지운 오류 문구만 알려주세요.
