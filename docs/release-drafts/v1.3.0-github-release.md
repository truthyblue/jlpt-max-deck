# JLPT MAX Deck v1.3.0

v1.3.0은 한자 2,337자를 읽기와 쓰기로 나누고, 획순 연습과 헷갈리는 한자
힌트를 추가한 마이너 업데이트입니다. 중복되던 가나 보조 카드는 없앴습니다.
카드 화면·음성·예문·오류 제보와 검토된 콘텐츠 교정도 함께 반영했습니다.

## 기존 덱에서 업데이트하기

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원 PDF
   2개로 한자 APKG를 다시 만든 뒤 가져옵니다.
5. 아래의 가나 보조 카드 정리를 끝낸 뒤 모든 기기에서 전체 동기화합니다.

`새 버전일 때`가 아니라 `항상`을 골라야 새 필드와 카드 화면이 기존 노트에도
들어갑니다. 한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됩니다.

## 기존 사용자: 가나 보조 카드 한 번 정리하기

v1.3.0부터 어휘 노트는 `어휘`와 `음성` 카드만 만듭니다. 앞면에서 히라가나만
묻던 `어휘(가나 보조)` 카드는 더 이상 만들지 않습니다. 업데이트 가져오기만으로
예전 카드 행이 자동 삭제되지 않을 수 있어 다음 메뉴를 한 번 실행해야 합니다.

- Android·AnkiDroid: `⋮ → 확인 → 빈 카드`
- iPhone·iPad·AnkiMobile: `설정 → 빈 카드`
- Windows·macOS·Linux Anki: `도구 → 빈 카드`

`JLPT MAX덱 어휘 / 어휘(가나 보조)`인지 확인한 뒤 **빈 카드 도구의 삭제**를
누릅니다. 144장 또는 6,018장으로 보일 수 있습니다. 카드 탐색기의 `노트 삭제`는
같은 노트의 어휘·음성 카드도 지우므로 사용하면 안 됩니다.

가나 보조 카드의 별도 일정과 복습 기록은 버리고 원래 한자 카드로 옮기지
않습니다. 원래 한자 카드의 급수, 카드 ID, 일정과 복습 기록은 그대로 유지됩니다.
Android와 iPhone·iPad에서는 대상 카드에 처음 들어갈 때 정리 안내도 표시합니다.

## 한자를 읽기와 쓰기로 나눠 공부하기

- 한자 2,337자마다 읽기 카드와 쓰기 카드를 따로 만듭니다.
- 기존 한자 카드는 `한자::읽기`로 옮기되 카드 ID와 학습 기록을 유지합니다.
- 새 `한자::쓰기` 카드는 새 학습 항목으로 시작합니다.
- 읽기 카드는 실제 단어를 음독·훈독별로 묶고, 현재 어휘에 없는 공식 상용한자
  읽기도 빠뜨리지 않습니다.
- 쓰기 카드는 직접 쓰기, 전체 지우기, 정답 자형과 획순 재생을 지원합니다.
- 모양이 비슷한 한자는 뜻·음독·훈독을 한 화면에서 비교합니다.
- 획순 SVG 2,298개와 SVG가 깨지는 환경을 위한 PNG 자형 14개를 넣었습니다.

## 기본 APKG와 한자 빌더

- public 기본 APKG: 13,903노트·19,921카드·미디어 18,437개
- 한자 addon: 4,674노트·4,674카드
- 두 APKG를 합친 전체: 18,577노트·24,595카드

기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는 빌더가
사용자의 지원 PDF 2개로 개인용 APKG를 만들어 합칩니다. 출판사 PDF 원문,
페이지 이미지와 추출 원문은 저장소나 배포 파일에 포함하지 않습니다.

## 카드 화면·음성·설정

- 한자 읽기·부수·획수, 발음별 단어와 비슷한 한자의 크기·간격을 모바일 폭에
  맞게 다듬고 카드 앞뒤의 머리글 위치를 고정했습니다.
- 단어 고저 악센트의 읽기 글자를 키우고, 긴 루비와 괄호 읽기가 서로 밀지
  않도록 간격을 보정했습니다.
- 글꼴과 표시 설정을 첫 화면 전에 적용하고 학습 중 글꼴을 고정해 깜빡임과
  글자 이동을 줄였습니다.
- 디코딩된 음성의 첫 유효 소리 직전부터 재생해 앞쪽 무음을 건너뜁니다.
- 같은 뜻의 여러 예문은 한 영역에 모으고 다른 뜻의 예문과 분리했습니다.
- iPhone·iPad는 무음 모드에서도 카드 음성을 재생합니다. 카드 설정에서
  **다른 앱 음악과 함께 재생**을 직접 켠 경우에만 다른 앱 음악과 섞어
  재생하며, 이 선택은 저장됩니다.

## AnkiDroid와 오류 제보

- AnkiDroid 구형 학습 화면에서 카드 저장·오디오·입력이 제한되면 지원되는 새
  학습 화면으로 옮기는 안내를 표시합니다.
- 오류 제보는 계속 익명이 기본입니다. 답장을 원하는 경우에만 답장 동의 뒤
  연락처 입력란이 나타납니다.
- 동의한 연락처는 제보와 분리해 암호화하고 수동 답장에만 쓰며 최대 90일 뒤
  삭제합니다. 공개 처리 기록에는 원문·연락처·기기 식별값을 넣지 않습니다.

## 검토된 뜻·예문과 오류 교정

- `掛かる`, `沸騰`, `細かい`, `冷やす`, `断る`, `改札`, `定員`, `遠慮`의
  뜻과 예문 연결을 다시 검토했습니다.
- `長い`, `直る`, `改札`, `帯`, `合流`, `いらっしゃる`, `積む`, `負う`,
  `遥か`, `開拓`, `食い込む`, `連携`, `丘陵`, `くまなく`, `中毒`의 겹치거나
  부족한 예문을 정리했습니다.
- `届ける` 루비 경계, 잘못 생성된 `何つ`를 `幾つ`로, 씨앗 `種`의 읽기를
  `たね`로 고쳤습니다.
- `進学塾` 예문의 `通っている`를 `かよっている`로, `噛み癖`를
  `かみぐせ`로 고쳤습니다.
- `条件`·`設定`·`了承`의 읽기와 `打診` 예문 번역을 고쳤습니다.
- 이미지 한자 4건은 PNG로 바꾸고, iOS 재생 제보 6건은 새 기본 재생 방식으로
  해결했습니다.
- 현행 표기가 맞거나 공개본에서 재현되지 않은 7건은 이유를 기록했습니다.
  이전 기각 25건을 합친 [기각 32건 전체 처리 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.3.0/docs/release-details/v1.3.0-dismissed-reports.md)도 공개합니다.
- 예전에 기각했던 가나 보조 카드 제보 81건은 v1.3.0에서 카드 유형을 없애
  해결했으므로 기각 합계에서 뺐습니다.
- 사전 버튼을 새 창으로 여는 요청 1건은 기능 변경이 필요해 다음 릴리스 검토로
  남겼습니다.

## 알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 같은 카드 설정이 초기화됐다는 익명 제보 1건이 있었습니다.
JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았습니다. 저장 공간이 매우
부족할 때 iOS가 카드 화면의 저장값을 정리했을 가능성을 보고 있지만, 당시 상태를
추가 확인할 수 없어 원인은 확정하지 못했습니다.

같은 현상이 생기면 `설정 → 일반 → iPhone/iPad 저장 공간`의 여유 공간을
확인하고 카드 설정을 다시 저장해 주세요. 반복되면 남은 용량, iOS·AnkiMobile
버전과 앱 재실행 전후 중 언제 발생했는지를 오류 제보에 적어 주세요. 카드 화면
설정은 학습 기록·카드 데이터와 별도라서 학습 기록이 초기화되는 현상은 아닙니다.

## 사용 통계와 배포 신뢰성

- 사용 통계를 켠 경우 업데이트 공지 확인·닫기 이벤트가 통신 실패 뒤 다시
  전송되고, 대기 중인 같은 이벤트는 한 건으로 합쳐집니다.
- 업데이트 버전별 활동과 익명 설치 수 추정치를 추가하고 대시보드 조회 범위를
  제한했습니다. 사용 통계를 새로 켜지는 않으며 기존 선택을 그대로 따릅니다.
- 콘텐츠·미디어·APKG를 해시로 묶고, 중단된 릴리즈 준비를 같은 지점에서 이어갈
  수 있게 했습니다. 사용자가 받는 APKG는 새 설치와 업데이트 검사를 통과한
  바로 그 파일입니다.

## 실제 후보 파일 검증

- 빈 profile 새 가져오기 1회 통과
- v1.2.1 → v1.3.0 업데이트 가져오기 1회 통과
- 기존 공통 카드 22,258개의 카드 ID·일정·복습 기록 유지 확인
- 기존 노트 16,240개 갱신, 새 한자 쓰기 2,337개 추가
- 가나 보조 카드 144개 제거 대상 확인
- 원본 음성 18,434개는 이전 승인본과 byte 단위로 동일
- 전체 릴리즈 과정에서 private APKG 생성 1회, TTS 새 합성 0회

실물 iPhone·iPad와 Android의 모든 기기·앱 버전 조합은 이번 정식판에서 따로
전수 검증하지 않았습니다. 실제 배포 APKG의 새 설치·업데이트, 공개 기본 덱과
한자 빌더 구조, 해시와 390×844 모바일 폭 렌더링을 확인했습니다.

자세한 수량과 검증 범위는 [v1.3.0 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.3.0/docs/release-details/v1.3.0.md)에서 볼 수 있습니다.
