# JLPT MAX Deck v1.3.0

한자 2,337자를 읽기와 쓰기로 따로 공부할 수 있게 하고, 획순 연습과 자주
헷갈리는 한자 힌트를 추가했습니다. 어휘 카드의 읽기·고저 악센트 표시, 음성
시작, 같은 뜻의 예문 묶음과 오류 제보 답장 기능도 함께 다듬었습니다.

## 기존 덱에서 업데이트하기

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원 PDF
   2개로 한자 APKG를 다시 만든 뒤 가져옵니다.
5. 가져오기가 끝나면 모든 기기에서 전체 동기화합니다.

v1.3.0은 한자 읽기·쓰기 노트 유형과 하위 덱이 추가되는 마이너 업데이트입니다.
`새 버전일 때`가 아니라 `항상`을 선택해야 기존 카드의 필드와 화면도 함께
바뀝니다. 한자 확장을 쓰지 않는 사용자는 기본 APKG만 가져오면 됩니다.

## 한자를 읽기와 쓰기로 나눠 공부하기

- 한자 2,337자마다 읽기 카드와 쓰기 카드를 따로 만듭니다.
- 읽기 카드는 음독·훈독별 실제 단어를 묶어 보여 주고, 현재 어휘에 없는 공식
  상용한자 읽기도 빠뜨리지 않습니다.
- 쓰기 카드는 직접 따라 쓸 수 있는 칸, 정답 자형과 획순 확인 기능을 제공합니다.
- 모양이 비슷한 한자는 뜻과 읽기를 함께 보여 줘 헷갈리는 지점을 비교할 수
  있습니다.

![v1.2.1과 v1.3.0의 한자 읽기 카드 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-reading-before-after.png)

public 기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는
빌더가 만든 개인용 APKG를 가져와 합칩니다. 지원 PDF 원문은 저장소나 배포
파일에 포함되지 않습니다.

## 카드 화면·음성·오류 제보

- 한자 읽기 정보의 글자 크기와 간격을 다듬고, 단어 고저 악센트의 읽기가
  좁은 화면에서도 더 또렷하게 보이도록 했습니다.
- 재생할 때 디코딩 뒤에 남은 앞쪽 무음을 건너뛰어 소리가 늦게 시작되는 느낌을
  줄였습니다.
- iOS에서는 무음 모드에서도 카드 음성이 재생되도록 오디오 세션 기본값을
  바꿨습니다. 같은 증상이 다시 접수되면 기기와 카드별로 재조사합니다.
- 같은 뜻을 보여 주는 예문은 한 묶음으로 모아, 뜻과 예문의 관계를 더 쉽게
  읽을 수 있습니다.
- AnkiDroid 구형 학습 화면에서 일부 기능이 동작하지 않으면 지원되는 새 학습
  화면으로 옮기는 안내를 보여 줍니다.
- 오류 제보는 계속 익명으로 보낼 수 있습니다. 답장을 원할 때만 연락처와 답장
  동의를 선택해서 보낼 수 있습니다.

## 검토된 교정과 호환성

- 제보와 전수 검토를 거친 뜻·읽기·예문·고저 악센트·문제 후리가나를
  교정했습니다.
- 이번 제보 검토에서는 `届ける`, `幾つ`, `種`, `通っている`, `噛み癖`,
  `条件`·`設定`, 이미지 한자와 iOS 음성 문제 등 14건을 해결했습니다.
- 번역·표기·합성 입력이 맞는 6건은 이유를 기록하고 현행을 유지했으며,
  사전 버튼 새 창 요청 1건은 다음 릴리스 검토로 남겼습니다.
- 기존 어휘·실전 문제·참조표의 안정 ID와 학습 기록은 유지됩니다.
- fresh profile 가져오기 1회와 v1.2.1에서 v1.3.0으로 업데이트 가져오기 1회를
  각각 통과했습니다.

## 덱 구성

- public 기본 APKG: 13,903노트·20,065카드·미디어 18,437개
- 한자 빌더 결과: 2,337자, 읽기·쓰기 합계 4,674노트·4,674카드
- 두 APKG를 합친 전체: 18,577노트·24,739카드
- private 전체 APKG도 같은 18,577노트·24,739카드 구성을 확인했습니다.

실물 iPhone·iPad와 Android의 모든 조합에서는 이번 정식판을 따로 전수
검증하지 않았습니다. 실제 배포 파일의 fresh/update import와 모바일 폭 HTML
렌더링을 확인했습니다.

자세한 변경 수량과 검증 범위는 [v1.3.0 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.3.0/docs/release-details/v1.3.0.md)에서
볼 수 있습니다.
