# JLPT MAX Deck v2.1.3 — 제보된 뜻·예문·읽기 수정

제보된 단어 뜻·예문·읽기와 실전 문제 해설을 고치고, 중복 카드를 정리했습니다.

## 바뀐 내용

- 제보된 단어 뜻·예문·읽기를 고쳤습니다. 横道는 よこみち 「옆길」, 却下는 「거절」로 바꾸고 새 예문을 넣었으며, 草의 「ㅋㅋㅋ」 뜻처럼 맞지 않는 뜻과 예문을 뺐습니다.
- 문법·실전 문제의 숫자 읽기(十時·一分·三本 등)를 바로잡고, 보기 순서가 섞이면 맞지 않던 실전 해설의 「N번」 표기를 없앴습니다.
- 단어 카드 한자 칸의 훈음을 사전식으로, 모양 풀이를 KanjiVG 등 공개 원천으로 바꾸고 출처를 NOTICE에 밝혔습니다.
- N2 문법의 중복 문형 2개(～できるものなら, ～末に)와 중복 단어 3개(かんごし, おんなの人, どうぞ、よろしく)를 정리했습니다.
- 「내 기록」 안내 창의 버튼이 큰 글씨에서도 보이고, 저장이 막힌 기기에서도 창이 닫히도록 고쳤습니다.
- AnkiDroid에서 「100일 랭킹, 절반 왔어요」 같은 알림이 카드를 넘길 때마다 다시 뜨던 문제를 고쳤습니다. 같은 알림은 한 번만 뜹니다.
- PC Anki에서는 업데이트 알림 창을 띄우지 않고 카드 아래 링크로만 알립니다.
- 바뀐 예문·단어 음성 4개만 새로 만들고 나머지 음성은 그대로 유지합니다.

- 새 설치와 v2.1.2 업데이트, 기존 학습 기록 보존 검증 통과
- v2.1.2에서 업데이트한 뒤 중복 단어 카드 9장이 빈 카드로 잡히고, 깃발이 유지됨
- 배포 ZIP과 공식 PDF 2개로 한자 카드 4,674장 생성·가져오기 검증 통과

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오면 표시가 풀립니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.3 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 가져온 뒤 빈 카드에서 `かんごし`, `おんなの人`, `どうぞ、よろしく` 카드를 삭제합니다.
6. 한자 덱은 다시 만들지 않아도 됩니다. 한자 카드에 v2.1.3 알림이 뜨면 「이 버전 알림 그만 보기」를 누르세요.
7. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
