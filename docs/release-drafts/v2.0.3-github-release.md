# JLPT MAX Deck v2.0.3 — 내 기록 자동 복구와 공지 화면 수정

v2.0.3은 모바일 `내 기록`의 자동 복구와 연결 재시도를 보강하고, JLPT 목표 카드와
개인 최고 기록 알림, 문법 카드 공지 화면을 고친 수정판입니다.

- 기기에 남은 기록과 JLPT 목표를 서버에서 자동으로 다시 확인합니다.
- 잠깐 연결이 불안정하면 바로 실패로 표시하지 않고 한 번 더 시도합니다.
- JLPT 목표의 상세 일정이 늦게 도착해도 목표 카드는 기존 초록색 흐름을 유지합니다.
- 하루 개인 최고 기록 알림은 같은 날 한 번만 카드 가운데에 표시합니다.
- 문법 카드의 업데이트 공지도 다른 카드와 같은 배경·창·버튼 스타일을 사용합니다.

![AnkiDroid에서 복구된 JLPT 목표와 학습 기록을 보여 주는 내 기록 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.3/site/assets/releases/v2.0.3/gallery-v2.0.3-study-records-recovery.png)

## 업데이트

모든 기기를 동기화하고 백업한 뒤 기존 덱을 지우지 않고
`JLPT-MAX-Deck-2.0.3.apkg`를 가져오세요. 학습 진행 상태 가져오기는 끄고,
기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.

한자 확장을 쓰는 경우에는 v2.0.3 한자 빌더 ZIP으로 지원 PDF 2개를 다시 읽어
한자 APKG를 만든 뒤 가져오세요.

자세한 내용은 [v2.0.3 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v2.0.3.md)에서 확인할 수 있습니다.

## 검증

- 새 설치 통과
- v2.0.2 업데이트와 기존 학습 상태 보존 통과

- 실제 문법 카드 공지 화면과 내 기록의 JLPT 목표 카드 확인
