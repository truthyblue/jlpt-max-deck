# JLPT MAX Deck v2.1.2 — 단어 음성·읽기·기록 집계 수정

단어 음성 9,159개의 속도와 리듬을 통일하고, 제보된 읽기·해설과 내 기록 집계를 고쳤습니다.

## 바뀐 내용

- Android 분석은 화면을 열 때 서버에서 조회합니다. 전송 완료된 과거 분류를 기기에 계속 쌓지 않도록 바꿨으며, iPhone·iPad는 기존 기기 내 분석을 유지합니다.
- 단어 음성을 속도 0.90·리듬 변화량 0.35로 정리하고, 표시 악센트와 끝소리에 맞춰 다시 만들었습니다.
- 일부 문법 후리가나와 어휘 문제의 선택지 해설을 바로잡았습니다.
- 대명사 「これ」의 단어 악센트 표시를 평판형으로 바로잡았습니다. 이번 교정은 표시만 바꾸며 음원은 유지합니다.
- 내 기록에서 답변이 중복 집계되던 문제를 고치고, 기기에 저장된 연속 학습 보호 기록을 유지합니다.
- 기기 저장 오류 뒤 다시 시도해도 동기화 오류 표시가 남던 문제를 고쳤습니다.
- 카드 전환 중 이전 요청이 늦게 끝나도 새 학습 기록과 최근 동기화 성공 상태가 유지되도록 고쳤습니다.
- 목표 설정의 저장 결과와 한자 쓰기 조작을 다듬고, 함께 익힐 글자 표시와 획순 자료를 보완했습니다.

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 v2.1.2 기본 덱을 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
4. 한자 덱을 쓰는 경우에는 v2.1.2 빌더로 확장 덱을 다시 만들어 가져옵니다.
5. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
