익명 사용 통계 공유에 동의한 모바일 설치의 v1.2.0 업데이트 이후 이용 현황을
정리했음. 활성 설치는 업데이트 이후 학습한 무작위 설치 ID 수이고, 학습 횟수는
답안 화면을 표시한 횟수임.

## 한눈에 보기

- 업데이트 이후 활성 설치: **[집계값]**
- 업데이트 이후 총 학습 횟수: **[집계값]**
- 설치당 학습 중앙값: **[집계값]**
- 플랫폼 비율: **[Android 비율] / [iOS 비율]**

## v1.2.0 전환

- 덱 버전별 설치 수: **[요약]**
- 업데이트 이후 일별 v1.2.0 전환 추이: **[요약]**

## 설치별 학습 횟수와 이용 추이

설치별 학습 횟수와 활동일을 구간별 분포로 공개함.

- 설치별 학습 횟수 분포: **[요약]**
- 설치별 활동일 분포: **[요약]**
- 일별 활성 설치·학습 횟수: **[요약]**

## 학습 구성

- 어휘·음성·종합 실전·참조표·한자별 학습 횟수: **[요약]**
- JLPT 급수별 학습 횟수: **[요약]**
- 종합 실전 문제 유형과 N5 하위 덱 구성: **[요약]**

집계 항목은 무작위 설치 ID, 플랫폼, 덱 버전, 학습 영역, JLPT 급수와 날짜별 답안
표시 횟수임. 덱 개선에 도움을 주고 싶다면 모바일 답안 아래 **익명 통계 → 사용
통계 공유하기**에서 언제든 켜고 끌 수 있음. 오류 제보는 모바일 카드의 **오류
제보** 버튼에서 보낼 수 있음.
