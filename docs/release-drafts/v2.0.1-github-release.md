# JLPT MAX Deck v2.0.1 — AnkiDroid 긴급 수정

v2.0.1은 v2.0.0의 문법 3,605개·어휘 9,160개·한국어→일본어 회상 카드와
모바일 `내 기록`을 그대로 담고, AnkiDroid에서 기록 데이터가 커지면 가져오기나
카드 표시가 실패할 수 있던 문제를 고친 긴급 수정판입니다.

다시 받을 수 있는 통계 화면 캐시는 Android 쿠키에서 기기 내부 저장소로 옮겼습니다.
쿠키에는 아직 보내지 않은 학습 기록처럼 꼭 보존해야 하는 값 한 벌만 남깁니다.
카드가 열리는 v2.0.0 사용자는 v2.0.1을 가져오면 기존 값을 자동으로 옮깁니다.

## AnkiDroid v2.0.0 사용자

- 카드와 가져오기 화면이 정상적으로 열리면 모든 기기를 동기화하고 백업한 뒤,
  기존 덱을 지우지 않고 v2.0.1을 가져오세요. 이전 기록은 자동으로 옮겨집니다.
- 카드나 가져오기에서 이미 `500` 또는 `Protocol message contained an invalid tag`
  오류가 뜨면 카드 코드가 시작되기 전이라 자동 복구할 수 없습니다. 먼저 AnkiWeb과
  완전히 동기화하고 백업한 뒤 AnkiDroid 앱 데이터를 지우거나 앱을 다시 설치하고,
  v2.0.1을 가져오세요. **동기화하지 않은 학습 기록은 앱 데이터 삭제·재설치 때
  사라질 수 있습니다.**
- v2.0.0 공개 파일은 철회했습니다. 새로 설치할 때는 v2.0.1만 사용하세요.

Android 16의 새 가상 기기와 순정 AnkiDroid 2.24.0에서도 전체 파일을 직접
가져와 20,650개 노트가 모두 추가되는 것을 확인했습니다.

![순정 AnkiDroid 2.24.0에서 JLPT MAX Deck v2.0.1의 20,650개 노트를 가져온 결과](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.1/site/assets/releases/v2.0.1/ankidroid-2.0.1-import-success.png)

## v1.3.0 이하 기존 사용자 필수 순서

1. 모든 기기를 동기화하고 컬렉션을 백업합니다.
2. 기존 덱과 학습한 급수를 삭제하지 않고 `JLPT-MAX-Deck-2.0.1.apkg`를
   가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기를 선택합니다.
5. 아래의 빈 카드 정리를 끝낸 뒤 모든 기기에서 전체 동기화합니다.

## 새 어휘 순서를 원할 때

기존 카드의 순서와 일정은 가져오기만으로 다시 배열되지 않습니다. 어떤 급수가
완전히 미학습 상태이고 새 BCCWJ 중요도 순서를 처음부터 쓰고 싶을 때만 그 급수의
`JLPT MAX덱::어휘::N○`와 `JLPT MAX덱::음성::N○`를 함께 삭제한 뒤 다시
가져오세요. 이미 학습한 급수는 정렬만을 위해 삭제하면 안 됩니다.

## 빈 카드 4장 정리

독립 어휘에서 제외한 `五万`과 중복을 정리한 `～キロ`의 예전 어휘·음성 카드가
빈 카드로 남습니다. v2.0.0에서 v2.0.1로 올리는 사용자는 이 정리가 필요 없습니다.

- AnkiDroid: `⋮ → 확인 → 빈 카드`
- AnkiMobile: `설정 → 빈 카드`
- PC Anki: `도구 → 빈 카드`

빈 카드 도구의 삭제를 사용하세요. 카드 탐색기의 노트 삭제는 사용하면 안 됩니다.
출발 버전과 컬렉션 상태에 따라 표시 수는 달라질 수 있습니다.

## 모바일 `내 기록`

AnkiMobile과 AnkiDroid 답안 화면에서 동의한 사용자가 오늘 공부한 흐름을 이어서
확인합니다. 단순히 오늘 숫자 하나만 보여 주는 화면이 아니라 `오늘·습관`,
`최신·분석`, `JLPT 목표·이력`을 나눠서 제공합니다.

- `오늘·습관`: 답안 화면 확인 횟수를 바로 표시하고, 20회가 되면 오늘 학습 완료로
  표시합니다. 20회는 20개 단어를 외웠다는 뜻이 아니라 하루 학습 세션을 진행했다는
  기준입니다.
- 연속 학습은 실제 완료일을 이어 보여 주고, 7일 실제 완료마다 연속 학습 보호를
  하나씩 충전합니다. 보호는 최대 2개까지 모을 수 있습니다.
- `최신`: 이번 주 현황, 최근 7일 흐름, 이번 달 참고 순위와 학습 달력을 보여 줍니다.
  완료·일부 학습·미학습·보호 사용일을 달력에서 구분합니다.
- `분석`: 최근 7일·30일·3개월·1년·전체 기간의 흐름과 영역·급수·학습 유형별 구성을
  확인합니다. 일간·주간·월간 개인 최고와 최장 연속 학습도 이곳에서 돌아봅니다.
- `JLPT 목표·이력`: 목표 급수와 다음 공식 시험 D-day를 정하고, D-100부터 같은 급수의
  100일 랭킹에서 학습량과 꾸준함을 비교합니다. D-50 중간 결산, 시험일 종료,
  결과와 다음 목표까지 이어지며, 이력에서는 개인 최고와 지난 랭킹을 확인합니다.

공부 흐름에 맞춰 오늘 학습 완료, 어제 기록 추월, 7·30·100·365일 연속 학습,
보호 사용·충전, 개인 최고, 100일 랭킹 시작·중간 결산 같은 순간도 한 번씩 알려 줍니다.

- 첫 안내에서 `내 기록 시작하기`를 눌렀을 때만 기록을 시작합니다.
- `사용하지 않기`를 고르면 덱 학습은 계속되고 자동으로 다시 묻지 않습니다.
- 기록은 모바일에 먼저 저장하므로 인터넷 연결이 없어도 오늘 상태와 학습 흐름을
  볼 수 있습니다.
- 카드 내용, 정답 여부, 답 버튼 선택, Anki 복습 이력, 학습 시간과 실제 JLPT 결과·응시
  여부·JLPT 계정 정보는 수집하지 않습니다.

기기 간 동기화는 서비스 준비가 끝난 뒤 제공합니다. 수집 범위는 [개인정보·저작권·라이선스](https://github.com/truthyblue/jlpt-max-deck/blob/v2.0.1/docs/privacy-and-licensing.md)를 확인하세요.

## 한자 쓰기 조작 추가

일시정지, 이전 획, 다음 획, 처음부터, 속도와 구간 개요를 추가했습니다. 한자 구성
요소와 외부 참고 링크도 읽기·쓰기 카드에서 확인할 수 있습니다. 기존 한자 카드의
학습 기록은 유지됩니다. iPad에서 Apple Pencil로 따라쓸 때 길게 누르기 선택·복사
메뉴가 끼어들어 필기가 끊기던 문제도 막았습니다.
