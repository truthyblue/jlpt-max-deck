# JLPT MAX Deck v1.2.0

> 중요: v1.1.1에서 업데이트할 때 **기존 노트 업데이트 → 항상**을 선택하고,
> 가져온 뒤 모든 기기에서 전체 동기화하세요. **학습 진행 상태 가져오기 → 끄기**,
> **노트 유형 병합 → 켜기**입니다.

| 지금 사용하는 버전 | 기존 노트 업데이트 | 이유 |
| --- | --- | --- |
| v1.1.x | **항상** | 고저 악센트 필드와 새 카드 템플릿을 적용합니다. |
| v1.0.x | **항상** | v1.1.x의 뜻·예문 변경과 v1.2.0의 새 필드를 함께 적용합니다. |

## 주요 변경

- 어휘 6,018개와 예문 7,065개의 고저 악센트 표시를 추가했습니다. 설정에서 끌 수
  있습니다.
- 일본어 글꼴을 명조·고딕 중에서 선택하고 후리가나·해석·자동재생·배속을 한
  패널에서 조절할 수 있습니다.
- 새 카드를 복습 카드 사이에 섞어 보여 주도록 기본 preset을 바꿨습니다.
- 좁은 모바일 화면의 오류 제보·사용 통계 팝업과 한자 펼치기 동작을 개선했습니다.
- 학습자 뜻 표시 249개를 다듬고 새 예문 182개를 추가했습니다.

![v1.1.1과 v1.2.0의 모바일 카드 설정 및 고저 악센트 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/gallery-v1.2.0-pitch-settings.webp)

단어별 뜻 변경 전·후와 새 예문 전체는
[v1.2.0 뜻·예문 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v1.2.0.md)에서
확인할 수 있습니다.

기존 한자 확장은 다시 만들지 않아도 계속 사용할 수 있습니다. 한자 카드에도 새
일본어 글꼴 설정과 최신 연결 어휘 표시를 반영하고 싶을 때만
`JLPT-MAX-kanji-builder-1.2.0.zip`으로 다시 만들어 같은 가져오기 옵션을
적용하세요. 노트 16,240개·카드 22,402개와 기존 GUID·학습 기록·스케줄은
유지됩니다.

업데이트 뒤 교체된 음성의 예전 파일이 미사용 상태로 남을 수 있습니다. 새 카드와
음성이 정상인지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki에서
**도구 → 미디어 검사**를 열어 미사용 파일 목록을 확인하고 삭제한 다음 다시
동기화하세요. 다른 덱의 미사용 파일도 함께 표시될 수 있으므로 목록을 먼저
확인해야 합니다. 삭제한 파일은 운영체제 휴지통에서 복구할 수 있습니다.
