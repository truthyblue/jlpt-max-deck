# JLPT MAX Deck v1.2.0

> 중요: v1.1.1에서 업데이트할 때 **기존 노트 업데이트 → 항상**을 선택하고,
> 가져온 뒤 모든 기기에서 전체 동기화하세요. **학습 진행 상태 가져오기 → 끄기**,
> **노트 유형 병합 → 켜기**입니다.

| 지금 사용하는 버전 | 기존 노트 업데이트 | 이유 |
| --- | --- | --- |
| v1.1.x | **항상** | 고저 악센트 필드와 새 카드 템플릿을 적용합니다. |
| v1.0.x | **항상** | v1.1.x의 뜻·예문 변경과 v1.2.0의 새 필드를 함께 적용합니다. |

## 주요 변경

- 어휘 6,018개와 예문 7,065개의 고저 악센트 표시를 추가했습니다. 설정에서 끌 수
  있습니다.
- 검토한 발음·모라 근거를 고저선과 음성 합성 입력에 함께 반영해 표시와 실제
  음성을 맞췄습니다. 제보된 `敬語（けいご）`, `録画（ろくが）`, `上がる（あがる）`,
  `最小限（さいしょうげん）`, `売買（ばいばい）`, `郊外（こうがい）` 6건도 생성
  APKG에서 교정된 음성을 확인했습니다.
- 학습자 뜻 표시 249개를 다듬고 새 예문 182개를 추가했으며, 신고된 실전 문제·
  문장과 `変わる` 예문, `持つ` 품사, `六本` 발음, `とお` 조수사 문제의
  `十つ` 표기도 `十`으로 교정했습니다.
- 어휘·음성·실전 문제의 답안 설정 패널에서 일본어 글꼴과 후리가나·해석·
  자동재생·배속을 조절할 수 있습니다. 선택한 글꼴은 참조표와 한자 카드를
  포함한 전체 덱에 적용됩니다.
- 앞면만으로 뜻을 구분하기 어려운 `そば`, `開く`, `避ける`, `紅葉`, `なる`
  5개 표제어의 10개 카드에 짧은 빈칸 문맥을 추가했습니다.
- 좁은 모바일 화면에서 오류 제보·사용 통계 팝업이 잘리지 않도록 보정했습니다.
- 모바일 Anki에서 한자 펼침·접힘을 직접 제어합니다. v1.1.0의 다크 모드 대비
  보정에 이어 이미지 한자 14자를 원본부터 빌더 출력까지 투명한 path-only SVG로
  통일해 Windows Anki 표시 경로도 보완했습니다.
- 업데이트 알림 상태를 쿠키와 `localStorage`에 함께 저장하고, 이번 학습 동안
  바로 닫는 **×** 버튼을 추가했습니다. **7일간 숨기기**와 **이 버전 알림 다시
  보지 않기**는 v1.1.1부터 제공된 기능입니다.
- 새 카드를 복습 카드 사이에 섞어 보여 주도록 기본 preset을 바꿨습니다.

뜻·예문 변경의 대표 예시:

- **독립 뜻 구분 · 濃い:** `짙다` → `(색·안개가) 짙다 / (맛·농도가) 진하다`
- **뜻 문구 보강 · 取り上げる:** `집어 들다 / 다루다 / 빼앗다` →
  `집어 들다 / 채택하다·다루다 / 빼앗다`
- **새 예문 · 磨く — 갈고닦다:** `職人は長年かけて技を磨いた。` — 장인은 오랜
  세월 기술을 갈고닦았다.
- **기존 예문 교정 · 示す — 가리키다:** `矢印は駅の方向を示す。` —
  `화살표는 역의 방향을 나타낸다.` → `화살표는 역 방향을 가리킨다.`

## 오류 제보 처리 결과

8월 14일까지 접수된 실제 제보 27건을 생성 카드·v1.2.0 후보·Anki 환경에서 다시
확인했습니다.

- **v1.2.0 반영 · 18건:** 실전 문제의 보기·해설 번호, 카드 앞면 표기와
  문장·음성 불일치, 한자 보이기·감추기 버튼과 상단 후리가나 바로 켜기·끄기,
  `六本` 발음, `十つ` → `十`을 바로잡았습니다. `敬語`, `録画`, `上がる`,
  `最小限`, `売買`, `郊外` 6건의 음성도 생성 APKG에서 교정해 확인했습니다.
- **이전 반영·v1.2.0 보강 · 4건:** 다크 모드 대비 보정은 v1.1.0 한자 빌더부터
  반영됐습니다. 중복 1건을 포함해 제보된 3개 카드는 v1.2.0 Anki Desktop에서
  정상 확인했고, 이번에는 Windows 표시 경로까지 맞추기 위해 이미지 한자 14자를
  투명한 path-only SVG로 통일했습니다. 기존 한자 확장은 v1.2.0 빌더로 다시
  만들면 이 보강이 적용됩니다.
- **추가 확인·검토 · 4건:** iOS 스피커 재생 3건은 기기 재현을 계속 확인합니다.
  `定員` 뜻 1건은 ‘규정 인원 / 수용 인원’의 두 용법을 유지할지 ‘정원’으로
  합칠지 검토 중입니다.
- **현재 표기 · 1건:** `好調`은 ‘호조인 상태’ 용법을 구분하는 현재 뜻 표기가
  적합합니다.

오류 제보는 모바일 카드의 오류 제보 버튼에서 누구나 보낼 수 있습니다. 제보 결과는
익명으로 묶어 처리 상태와 건수만 공개합니다.

## 익명 통계 요약

![최근 30일 JLPT MAX 익명 이용 현황](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.2.0/gallery-v1.2.0-usage-summary.png)

집계 기준은 통계 공유에 동의한 모바일 설치입니다. 활성 설치는 최근 30일 동안
학습한 무작위 설치 ID 수이고, 학습 횟수는 답안 화면 표시 횟수입니다. 플랫폼·덱
버전·학습 영역·JLPT 급수별 집계를 함께 보여 줍니다. 모바일 답안 아래 **익명 통계
→ 사용 통계 공유하기**에서 언제든 켜거나 끌 수 있습니다.

버전 전환·일별 이용 추이·설치별 학습 횟수·학습 구성은 별도 통계 글로 공유할
예정입니다.

단어별 뜻 변경 전·후와 새 예문 전체는
[v1.2.0 뜻·예문 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v1.2.0.md)에서
확인할 수 있습니다.

기본 덱을 가져온 뒤 한자 확장도 `JLPT-MAX-kanji-builder-1.2.0.zip`으로 다시
만들어 같은 가져오기 옵션을 적용하세요. 그러면 Windows Anki 야간 모드의 투명
SVG 렌더링과 새 일본어 글꼴, 최신 연결 어휘 표시가 함께 적용됩니다. 노트
16,240개·카드 22,402개와 기존 GUID·학습 기록·스케줄은 유지됩니다.

업데이트 뒤 교체된 음성의 예전 파일이 미사용 상태로 남을 수 있습니다. 새 카드와
음성이 정상인지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki에서
**도구 → 미디어 검사**를 열어 미사용 파일 목록을 확인하고 삭제한 다음 다시
동기화하세요. 다른 덱의 미사용 파일도 함께 표시될 수 있으므로 목록을 먼저
확인해야 합니다. 삭제한 파일은 운영체제 휴지통에서 복구할 수 있습니다.
