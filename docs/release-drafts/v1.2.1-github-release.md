# JLPT MAX Deck v1.2.1

단어 고저 악센트의 끝 방향을 표시하고, 카드를 넘길 때 일본어 글꼴이 번쩍
바뀌거나 글자가 움직이는 현상을 줄였습니다. 뜻과 예문도 같은 순서로 맞춘
안정화 업데이트입니다.

## v1.2.0에서 업데이트하기

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.2.1.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 새 버전일 때**,
   **노트 유형 병합 → 켜기**를 선택합니다.

한자 확장 내용은 v1.2.0과 같아서 다시 만들 필요가 없습니다.
v1.2.1 시험판을 사용 중이면 정식판 알림을 받을 수 없으므로, 이 페이지에서
정식 APKG를 직접 받아 같은 방법으로 가져오세요.

## 뜻과 예문을 바로 연결해서 보기

- 어휘 102개는 카드 위쪽의 뜻과 아래쪽 예문이 같은 순서로 나옵니다.
- 뜻이 `/`로 나뉘는 어휘 651개는 서로 다른 뜻의 예문을 흰색 영역으로
  나눠 보여 줍니다. 어떤 예문이 어느 뜻에 속하는지 더 쉽게 구분할 수 있습니다.
- 예를 들어 `取る`는 `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다` 순서로
  뜻을 보고, 바로 아래에서도 같은 순서로 예문을 읽을 수 있습니다.

![v1.2.0과 v1.2.1의 뜻 묶음별 예문 표시 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-meaning-groups-before-after.png)

## 단어 끝의 악센트까지 구분하기

- 단어 고저 악센트 선 끝에 화살표를 추가했습니다. 단어 뒤에서도 높게
  이어지는지, 낮게 떨어지는지 바로 구분할 수 있습니다.
- 단어 안의 선 모양이 같아 보이더라도, 단어 뒤에서 높게 이어지는 경우와
  끝에서 낮아지는 경우를 화살표로 구별할 수 있습니다.
- 긴 단어는 좁은 악센트 칸 안에서 히라가나 폭을 조정해, 선과 글자가 덜
  겹칩니다.

![v1.2.0과 v1.2.1의 단어 고저 악센트 끝 방향 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-pitch-boundary-before-after.png)

## 카드를 넘길 때 덜 깜빡이게

- Mac Anki에서 새 카드로 넘어갈 때 일본어가 굵게 보였다가 선택한 글꼴로
  바뀌는 순간을 줄였습니다. 고저 악센트 선도 처음 나타날 때 덜 움직입니다.
- 설정에서 명조체와 고딕체를 바꿀 때 카드 전체가 잠깐 사라지지 않고,
  화면을 그대로 보면서 글꼴만 바뀝니다.
- 긴 후리가나가 옆 글자를 밀어내지 않습니다. 실제로 글자끼리 닿을 때만
  간격을 벌려 문장과 고저 악센트 선의 자리를 유지합니다.
- 한자 버튼과 사전 버튼의 크기를 맞췄습니다. 한자 내용을 열고 닫아도
  화살표와 `한자` 글자가 옆으로 밀리지 않습니다.
- 활용·학습·익명 통계처럼 펼쳐 보는 항목의 화살표 모양과 움직임을
  통일했습니다.

![Mac Anki에서 한자 버튼과 사전 버튼을 나란히 표시한 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-kanji-disclosure-closed.png)

![한자 버튼을 연 뒤의 상세 내용](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-kanji-disclosure-open.png)

## 익명 통계의 일부 동작 수정

- 기존 익명 통계 기능은 그대로 사용됩니다. 이번에는 공유를 껐다 다시 켰을 때
  같은 기기를 새 설치로 중복 집계하지 않도록 고쳤습니다.
- 앱 데이터 삭제나 재설치 때만 새 설치로 집계됩니다.
- 좁은 화면에서 익명 통계 창을 좌우로 밀지 않아도 내용을 읽을 수 있습니다.

## 제보로 고친 내용

- `猛` 선택지의 읽기를 `たけし`에서 `もう`로 고쳤습니다.
- `縁`의 뜻을 `① 인연 연 ② 가장자리 연 · 테두리 연`처럼 읽기 쉽게
  띄어 썼습니다.
- `木曜日` 문제에서 정답 ②와 해설 ②가 서로 맞도록 고쳤습니다.

## 덱 구성과 학습 기록

- 기본 덱은 13,903노트·20,065카드입니다.
- 전체 구성은 16,240노트·22,402카드입니다.
- 기존 학습 기록과 일정은 그대로 이어집니다.
- 음성 18,435개는 그대로 사용했고 새로 합성한 음성은 없습니다.
- v1.2.0 덱에 가져와 새 노트 0개·중복 0개·충돌 0개를 확인했습니다.
