# JLPT MAX Deck v1.2.1-pre.2

> 이 버전은 먼저 써볼 사람을 위한 **프리릴리스**입니다. 카드 안의 업데이트
> 안내와 공식 사이트의 최신 버전은 아직 v1.2.0으로 유지됩니다.

## v1.2.0에서 가져오기

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.2.1-pre.2.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 새 버전일 때**,
   **노트 유형 병합 → 켜기**를 선택합니다.

한자 확장 내용은 v1.2.0과 같아서 다시 만들 필요가 없습니다.

## 바뀐 점

### 뜻과 예문

- 뜻 1·2·3의 표시 순서와 예문 순서가 어긋난 어휘 102개의 예문을 뜻 표시
  순서대로 맞췄습니다.
- 슬래시(`/`)로 나뉜 뜻이 여러 개인 어휘 651개는 뜻 묶음별로 예문을 흰색
  영역에 나눠 보여 줍니다. 묶음용 칩은 따로 추가하지 않았습니다.
- 예를 들어 `取る`는 `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다` 순서에
  맞춰 예문도 `잡다 → 집다 → 들다 → 빼앗다 → 얻다 → 없애다` 순서로
  표시됩니다.

### 카드 표시와 Mac WebKit

- 한자 버튼은 임의로 만든 버튼 동작을 제거하고 기본 `details/summary` 동작으로
  되돌렸습니다. Mac Anki에서 사전 버튼과 한자 버튼의 높이·너비를 같게
  표시합니다. 닫힘·펼침 화살표는 같은 11×11px 칸을 쓰고 같은 화살표를
  회전한 뒤 글꼴의 위아래 여백 차이를 3px 보정해 `한자` 글자가 밀리지 않게
  했습니다. 한자 내용을 열고 닫는 동작도 같은 카드 안에서 확인했습니다.
- 긴 후리가나는 문장이나 한자 본문의 폭을 늘리지 않게 했습니다. 후리가나끼리
  실제로 부딪힐 때만 필요한 만큼 간격을 추가합니다.
- 고저표는 문장·한자·후리가나·곡선의 폭을 바꾸지 않습니다. 모라 칸이 좁을
  때만 그 칸 안의 히라가나 글자를 눌러 표시합니다.
- 일본어 글꼴을 바꿀 때 글꼴이 적용되기 전 카드를 잠깐 숨겨서 굵은 글꼴에서
  일반 글꼴로 깜빡이는 현상을 줄였습니다. Mac/iOS WebKit의 후리가나 처리
  차이도 카드가 알아서 보정합니다.

### 제보로 확인한 콘텐츠

- `猛` 선택지의 후리가나를 `たけし`에서 `もう`로 고쳤습니다.
- `縁`의 뜻을 `① 인연 연 ② 가장자리 연 · 테두리 연`처럼 읽기 쉽게
  표시합니다.
- `木曜日` 문제에서 정답 ②와 해설 ②의 번호가 서로 맞도록 고쳤습니다.

### 프리릴리스 식별

- 카드 아래 버전 표시는 `v1.2.1-pre.2`입니다. 익명 사용 통계와 오류 제보도
  `1.2.1-pre.2`로 기록되어 정식 v1.2.1과 구분됩니다.
- 프리릴리스 버전을 인식하지 못해 iOS·Android 카드에서 숨겨지던 `익명 통계`
  설정을 다시 표시하고, 동의 창과 답변 집계가 정상 시작되도록 고쳤습니다.
- 익명 통계 공유를 꺼도 기존 설치 식별자는 기기에 남습니다. 다시 켜거나 덱을
  업데이트하고 앱을 껐다 켜도 같은 설치로 집계되며, 앱 데이터 삭제나 재설치 때만
  새 식별자가 만들어집니다.

## 확인한 범위

- 오류 제보 전용 테스트 덱에 선택한 9개 제보를 9노트·14카드로 넣어 확인했습니다.
- 빠른 테스트 282개, pyright, 전체 APKG 생성·가져오기 호환성 검사를 통과했습니다.
- 음성 18,435개는 기존 AivisSpeech 1.2.0 결과를 그대로 재사용했고 새로 합성한
  음성은 0개입니다.
- 노트·카드 ID, 덱 구조, 학습 일정 호환성은 v1.2.0과 같습니다.
