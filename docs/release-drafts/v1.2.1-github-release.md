# JLPT MAX Deck v1.2.1 (Pre-release)

> 이 버전은 먼저 써볼 사람을 위한 **프리릴리스**입니다. 카드 안의 업데이트
> 안내와 공식 사이트의 최신 버전은 아직 v1.2.0으로 유지됩니다.

## v1.2.0에서 업데이트

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.2.1.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 새 버전일 때**,
   **노트 유형 병합 → 켜기**를 선택합니다.

한자 확장 내용은 v1.2.0과 같아서 다시 만들 필요가 없습니다.

## 바뀐 점

- 뜻 1·2·3의 표시 순서와 예문 순서가 어긋난 어휘 102개의 예문을 뜻 표시
  순서대로 맞췄습니다.
- 슬래시(`/`)로 나뉜 뜻이 여러 개인 어휘 651개는 뜻 묶음별로 예문을 흰색
  영역에 나눠 보여 줍니다. 묶음용 칩은 따로 추가하지 않았습니다.
- 예를 들어 `取る`는 `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다` 순서에
  맞춰 예문도 `잡다 → 집다 → 들다 → 빼앗다 → 얻다 → 없애다` 순서로
  표시됩니다.
- 카드 아래 버전 표시는 `v1.2.1`입니다.

![v1.2.0과 v1.2.1의 뜻 묶음별 예문 표시 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-meaning-groups-before-after.png)

전체 수량, 음성, 덱 구조와 학습 기록 호환성은 v1.2.0과 같습니다. 자세한 범위와
검증 결과는 [v1.2.1 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.2.1/docs/release-details/v1.2.1.md)에서
확인할 수 있습니다.
