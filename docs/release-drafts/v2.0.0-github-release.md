# JLPT MAX Deck v2.0.0 — 어휘 9,160개와 한국어 회상

v2.0.0은 검토된 어휘를 6,018개에서 **9,160개**로 늘리고, 모든 어휘에
**한국어→일본어 회상 카드**를 추가한 큰 업데이트입니다. 새 카드 순서는 각 급수
안에서 BCCWJ 중요도에 맞췄습니다.

## 기존 사용자 필수 순서

1. 모든 기기를 동기화하고 컬렉션을 백업합니다.
2. 기존 덱과 학습한 급수를 삭제하지 않고 `JLPT-MAX-Deck-2.0.0.apkg`를
   가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기를 선택합니다.
5. 아래의 빈 카드 정리를 끝낸 뒤 모든 기기에서 전체 동기화합니다.

## 새 어휘 순서를 원할 때

기존 카드의 순서와 일정은 가져오기만으로 다시 배열되지 않습니다. 어떤 급수가
완전히 미학습 상태이고 새 BCCWJ 중요도 순서를 처음부터 쓰고 싶을 때만 그 급수의
`JLPT MAX덱::어휘::N○`와 `JLPT MAX덱::음성::N○`를 함께 삭제한 뒤 다시
가져오세요. 이미 학습한 급수는 정렬만을 위해 삭제하면 안 됩니다.

## 빈 카드 4장 정리

독립 어휘에서 제외한 `五万`과 중복을 정리한 `～キロ`의 예전 어휘·음성 카드가
빈 카드로 남습니다.

- AnkiDroid: `⋮ → 확인 → 빈 카드`
- AnkiMobile: `설정 → 빈 카드`
- PC Anki: `도구 → 빈 카드`

빈 카드 도구의 삭제를 사용하세요. 카드 탐색기의 노트 삭제는 사용하면 안 됩니다.
출발 버전과 컬렉션 상태에 따라 표시 수는 달라질 수 있습니다.

## 어휘 9,160개 · 예문 10,463개

- 모든 어휘에 검토된 대표 예문과 단어·예문 음성을 연결했습니다.
- 뜻 하나에 서로 다른 쓰임이 섞이면 뜻과 예문을 나눴습니다.
- 각 급수 안에서 BCCWJ 사용 빈도와 검토된 표기 연결 순으로 새 카드를
  배치했습니다.

## 한국어→일본어 회상 9,160장

한국어 뜻과 예문을 보고 일본어 표기와 읽기를 떠올립니다. 기존 어휘·음성 카드는
그대로이고, 새 회상 카드는 처음부터 학습합니다.

![여러 뜻이 표시된 한국어→일본어 회상 카드 앞면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.0/site/assets/releases/v2.0.0/gallery-v2.0.0-korean-recall.png)

## 한자 쓰기 조작 추가

일시정지, 이전 획, 다음 획, 처음부터, 속도와 구간 개요를 추가했습니다. 한자 구성
요소와 외부 참고 링크도 읽기·쓰기 카드에서 확인할 수 있습니다. 기존 한자 카드의
학습 기록은 유지됩니다.

![한자 쓰기 화면 전후 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.0/site/assets/releases/v2.0.0/gallery-v2.0.0-kanji-controls-before-after.png)

- 후리가나·해석·표시 설정과 음성 설정을 나눠 저장합니다.
- 음성 카드 첫 표시 자동재생, 합성 한자 크기와 Android 잘림, 검은 배경의 투명
  한자 이미지, 사전 버튼 새 창 열기를 고쳤습니다.
- 오류 제보 49건 중 35건을 수정으로 해결하고 14건은 현행 내용 유지 이유를
