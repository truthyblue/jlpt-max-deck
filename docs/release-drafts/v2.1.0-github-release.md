# JLPT MAX Deck v2.1.0 — 어휘 뜻·예문 전수 재검토

v2.1.0은 어휘 9,160개의 뜻과 예문을 전부 다시 점검한 업데이트입니다.
실제로 공부하는 어휘 9,159개 가운데 뜻 또는 예문이 달라지는 2,963개를 고쳤고,
각 뜻에 맞는 대표 예문을 연결했습니다.

- 뜻이 달라진 어휘 2,662개
- 예문 또는 루비가 달라진 어휘 2,397개
- 최종 예문 10,997개
- 미해결 항목 0개

서로 바꿔 말할 수 있는 뜻은 `·`으로 묶고, 따로 외워야 하는 용법은 `/`로
나눴습니다. 너무 넓은 뜻에는 대상이나 문형을 붙이고, 자주 쓰는 기본 뜻부터
학습하기 쉽게 배열했습니다.

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.1.0.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 가져온 뒤 빈 카드 도구에서 `笠` 카드 3장을 삭제합니다.
6. 한자 덱을 쓰는 경우 v2.1.0 한자 빌더로 다시 만듭니다.
7. 모든 기기에서 다시 전체 동기화합니다.

기존 학습 일정과 복습 기록은 유지됩니다. 카드 탐색기에서 `笠` 노트를 직접
지우지 말고 Anki의 빈 카드 도구를 사용하세요.

자세한 내용은 [v2.1.0 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v2.1.0.md)에서 확인할 수 있습니다.

## 그 밖의 개선

- 새 버전 안내에서 기본 덱을 바로 받고 가져오기 옵션을 함께 확인할 수 있습니다.
- 내 기록의 JLPT 목표 선택과 오프라인 재시도를 다듬었습니다.
- 오류 제보 화면, Android 분석 기록, iPad의 빠른 Pencil 필기를 고쳤습니다.
- 한자 빌더가 출판사 PDF의 한국어 낱말 띄어쓰기를 보존하도록 고쳤습니다.

## 검증

- 새 설치 통과
- v2.0.3 업데이트와 기존 학습 상태 보존 통과
- `笠` 빈 카드 3장 정리와 재가져오기 통과
- 공개 기본 덱과 한자 빌더 분리 검증 통과
- 실제 어휘 카드 2장을 390×844에서 확인
