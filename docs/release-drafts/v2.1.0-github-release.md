# JLPT MAX Deck v2.1.0 — 어휘 뜻·예문 전수 재검토

v2.1.0은 어휘 9,160개의 뜻과 예문을 전부 다시 점검한 업데이트입니다.
실제로 공부하는 어휘 9,159개 가운데 뜻 또는 예문이 달라지는 2,963개를 고쳤고,
각 뜻에 맞는 대표 예문을 연결했습니다.

- 뜻이 달라진 어휘 2,662개
- 예문 또는 루비가 달라진 어휘 2,397개
- 최종 예문 10,997개
- 미해결 항목 0개

서로 바꿔 말할 수 있는 뜻은 `·`으로 묶고, 따로 외워야 하는 용법은 `/`로
나눴습니다. 너무 넓은 뜻에는 대상이나 문형을 붙이고, 자주 쓰는 기본 뜻부터
학습하기 쉽게 배열했습니다.

### 뜻 사이 구분점 누락 수정

최근 추가한 3천여 어휘 중 일부에서 뜻 사이의 가운데점(`·`)이 빠져, 여러 뜻이 하나의 표현처럼 붙어 보이던 문제를 고쳤습니다. 뜻을 다시 검토하면서 같은 쓰임의 표현은 `·`으로, 따로 외워야 하는 용법은 `/`로 구분했습니다.

### 겹치는 뜻은 짧게 — 越える

- 전: 넘다 / 초과하다
- 후: **넘다**

![越える: 넘다](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-koeru.png)

짧게 줄인 다른 사례입니다.

- `繰り返し`: 반복 / 거듭 → **반복**
- `重なる`: 겹치다 / 거듭되다 → **겹치다**
- `値する`: ~할 가치가 있다 · ~할 만하다 → **~할 가치가 있다**

### 같은 쓰임은 한 묶음으로 — 濃い

- 전: (색·안개가) 짙다 / (맛·농도가) 진하다
- 후: **짙다 · 진하다**

![濃い: 짙다 · 진하다](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-koi.png)

### 다른 용법은 따로 — 叩く

- 전: 두드리다 / 비판하다
- 후: **치다 · 두드리다 / 비판하다**

![叩く: 치다 · 두드리다 / 비판하다](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-tataku.png)

### 막연한 뜻에는 사용 조건 — する

- 전: 하다 / 나다
- 후: **하다 / (냄새나 소리가) 나다 / ~로 하다(Nにする)**

![する: 하다 / (냄새나 소리가) 나다 / ~로 하다(Nにする)](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-suru.png)

### 빠진 주요 뜻은 보완 — 種

- 전: 씨
- 후: **씨 / 원인 / 소재 · 이야깃거리**

![種: 씨 / 원인 / 소재 · 이야깃거리](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-tane.png)

## 카드 화면과 모바일 기록

2.0.3에서 불편했던 카드 화면과 내 기록을 다듬었습니다.
아래는 v2.1.0 화면 미리보기입니다. 학습 기록·순위·필기는 설명용 예시입니다.

### iPhone·iPad 문법 후리가나 표시 수정

2.0.3에서 iPhone·iPad의 문법 카드 후리가나가 한자 위가 아니라 본문 옆에 나란히 표시되던 문제를 고쳤습니다. 이제 문법 답안에서도 한자 바로 위에 읽기가 표시됩니다.

![기본 문법 답안 · 후리가나를 켠 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-grammar.png)

### JLPT 목표를 처음부터 쉽게

JLPT 목표를 처음 정하거나 바꿀 때 N1~N5 중 원하는 급수를 바로 고를 수 있도록 선택 화면을 정리했습니다.

![급수를 고르기 전 · 예시 기록](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-target.png)

### 연결이 끊겨도 다시 고를 수 있게

연결 문제로 목표 설정을 마치지 못했을 때 상태를 알리고 다시 시도할 수 있도록 했습니다. 연결이 끊겨도 기기에 저장된 학습 기록은 계속 볼 수 있습니다.

![오프라인 목표 선택 안내 · 예시 기록](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-target-offline.png)

### 연속 학습 보호가 뭔지 한눈에

보호가 언제 쓰이는지, 몇 개 남았는지, 다음 보호까지 며칠 필요한지를 한 화면에 모았습니다.

![연속 학습·보호 상세 · 예시 기록](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-streak.png)

### Android 분석 기록 표시 수정

2.0.3에서 Android의 기간별·영역별·급수별 분석 기록이 일부 빠져 보일 수 있던 문제를 고쳤습니다. 보고 싶은 기록과 기간을 고르는 탭도 알아보기 쉽게 정리했습니다.

![분석 화면을 아래로 스크롤한 모습 · 예시 기록](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-analysis-detail.png)

### 오류 제보도 더 분명하게

문제를 어떻게 설명할지 막막하지 않도록 유형별 작성 예시를 넣고, 기능 제안 항목을 추가했습니다. 보내기 전에 함께 전송되는 정보도 확인할 수 있습니다.

![의견 보내기 화면 · 입력 예시이며 실제로 전송하지 않음](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-report.png)

### 새 버전 안내에서 바로 다운로드

이제 카드의 새 버전 안내에서 기본 덱을 바로 받을 수 있습니다. 기존 학습 기록을 유지하려면 어떤 가져오기 옵션을 골라야 하는지도 함께 안내합니다.

![새 업데이트 안내 화면 · 버전 전환 예시](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-update.png)

### 필요한 안내를 순서대로

업데이트 후에는 필요한 카드 정리와 내 기록 시작 방법을 차례로 안내합니다. 지금 해야 할 일을 하나씩 확인할 수 있습니다.

![내 기록 시작 안내](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-onboarding.png)

### 한자 앞면은 문제에 집중

한자 문제를 풀 때 필요하지 않은 표시 설정을 앞면에서 빼고, 학습 현황과 문제에 집중할 수 있도록 했습니다.

![한자 카드 앞면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-kanji-front.png)

iPad에서 Apple Pencil로 빠르게 쓸 때 획이 끊기거나 빠지던 문제를 고쳤습니다. 획순 자료 때문에 카드가 처음 열릴 때 생기던 부담도 줄였습니다.

![쓰기 카드 · 브라우저에서 입력한 필기 예시](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-writing.png)

### 비슷한 한자의 읽기를 더 보기 쉽게

좁은 화면에서 비슷한 한자의 읽기가 한 글자씩 세로로 끊겨 보이던 문제를 고쳤습니다. 음독·훈독을 구분하면서 읽을 수 있도록 표시 공간을 넓혔습니다.

![한자 뒷면 · 비슷한 한자의 읽기 배치](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-kanji-readings.png)

### 한자 빌더의 낱말 띄어쓰기

한자 빌더로 만든 카드에서 한국어 낱말 중간에 불필요한 공백이 들어가던 문제를 고쳤습니다. 한자 덱을 쓰는 경우 v2.1.0 빌더로 다시 만들면 반영됩니다.

## 검증

- 새 설치 통과
- v2.0.3 업데이트와 기존 학습 상태 보존 통과

- 긴 카드는 본문 전체를 캡처하고 가로 넘침이 없는지 확인

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.1.0.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 가져온 뒤 빈 카드 도구에서 `笠` 카드 3장을 삭제합니다.
6. 한자 덱을 쓰는 경우 v2.1.0 한자 빌더로 다시 만듭니다.
7. 모든 기기에서 다시 전체 동기화합니다.

기존 학습 일정과 복습 기록은 유지됩니다. 카드 탐색기에서 `笠` 노트를 직접
지우지 말고 Anki의 빈 카드 도구를 사용하세요.

자세한 내용은 [v2.1.0 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v2.1.0.md)에서 확인할 수 있습니다.
