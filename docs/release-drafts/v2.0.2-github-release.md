# JLPT MAX Deck v2.0.2 — 문법 후리가나와 더 빠른 내 기록

v2.0.2는 문법 카드의 읽기 도움을 보강하고, 모바일 `내 기록`과 선택형 한자
빌더의 문제를 함께 고친 수정판입니다.

- 문법 4종 카드의 답면 예문·정답 문장·선택지·완성 지문에 후리가나를 추가했습니다.
- 첫 동기화 뒤에는 기기 기록으로 화면과 분석을 바로 계산합니다.
- 최근 90일은 일별, 최근 1년은 월별로 보관합니다.
- 7일·30일·이번 달·3개월·1년·전체 합계와 영역별·급수별 분석을 유지합니다.
- 이번 달 순위와 서버 확인은 최대 1시간에 한 번만 새로 받습니다.
- 기록이 비어 있으면 로딩 표시와 함께 첫 화면·분석·순위 자료를 한 요청으로 복원합니다.
- Android 쿠키에서 다시 받을 수 있는 자료를 빼고 월별 기록을 더 작게 압축하며,
  이전 기록 구조를 자동으로 옮깁니다.
- 내 기록 버튼이 눌린 상태를 알아보기 쉽도록 터치 반응을 다듬었습니다.
- 한자 빌더에서 `艹/䒑`·`巴/巳`·`兎(兔)` 같은 복합 자형이 줄바꿈되거나
  읽기·쓰기 정답 칸을 벗어나던 문제를 고쳤습니다.

![AnkiDroid에서 7일 총합과 영역별·급수별 분석을 보여 주는 내 기록 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.2/site/assets/releases/v2.0.2/gallery-v2.0.2-study-records-analysis.png)

## 업데이트

모든 기기를 동기화하고 백업한 뒤 기존 덱을 지우지 않고
`JLPT-MAX-Deck-2.0.2.apkg`를 가져오세요. 학습 진행 상태 가져오기는 끄고,
기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.

한자 확장을 쓰는 경우에는 v2.0.2 한자 빌더 ZIP으로 지원 PDF 2개를 다시 읽어
한자 APKG를 만든 뒤 가져오세요.

자세한 내용은 [v2.0.2 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v2.0.2.md)에서 확인할 수 있습니다.

## 검증

- 새 설치 통과
- v2.0.1 업데이트와 기존 학습 상태 보존 통과
- 실제 AnkiDroid 기록 복원과 기간별·영역별·급수별 합계 확인
- 문법 4종 답면 후리가나와 한자 빌더 복합 자형 표시 확인
