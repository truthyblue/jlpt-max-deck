# JLPT MAX Deck v2.0.2 — 더 빠르고 안정적인 내 기록

v2.0.2는 모바일 `내 기록`을 기기 우선 방식으로 바꾼 수정판입니다.

- 첫 동기화 뒤에는 기기 기록으로 화면과 분석을 바로 계산합니다.
- 최근 90일은 일별, 최근 1년은 월별로 보관합니다.
- 7일·30일·이번 달·3개월·1년·전체 합계와 영역별·급수별 분석을 유지합니다.
- 이번 달 순위와 서버 확인은 최대 1시간에 한 번만 새로 받습니다.
- Android 쿠키를 더 작게 압축하고 이전 기록 구조를 자동으로 옮깁니다.
- 내 기록 버튼의 터치 반응과 한자 빌더의 복합 자형 처리를 고쳤습니다.

![AnkiDroid에서 7일 총합과 영역별·급수별 분석을 보여 주는 내 기록 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.2/site/assets/releases/v2.0.2/gallery-v2.0.2-study-records-analysis.png)

## 업데이트

모든 기기를 동기화하고 백업한 뒤 기존 덱을 지우지 않고
`JLPT-MAX-Deck-2.0.2.apkg`를 가져오세요. 학습 진행 상태 가져오기는 끄고,
기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.

자세한 내용은 [v2.0.2 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v2.0.2/docs/release-details/v2.0.2.md)에서 확인할 수 있습니다.

- v2.0.1 업데이트와 기존 학습 상태 보존 통과
