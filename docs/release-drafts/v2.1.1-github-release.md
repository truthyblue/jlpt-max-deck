# JLPT MAX Deck v2.1.1 — 한자 생성·문법 후리가나 수정

한자 덱 생성 오류와 iPhone·iPad 기본 문법 카드의 후리가나 표시를 고쳤습니다.
뜻·예문·음성과 카드 구성은 v2.1.0과 같습니다.

## 고친 내용

- v2.1.0 한자 빌더에서 한자 확인 오류로 생성이 중단되던 문제를 고쳤습니다.
- iPhone·iPad 기본 문법 카드의 예문과 비교 문형에서 후리가나가 본문 옆에 붙던 문제를 고쳤습니다.

![기본 문법 답안 · iOS 표시 방식을 재현한 v2.1.1 미리보기](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.1/site/assets/releases/v2.1.1/grammar-ruby.png)

## 다운로드

- `JLPT-MAX-Deck-2.1.1.apkg`: 기본 덱
- `JLPT-MAX-kanji-builder-2.1.1.zip`: 한자 덱 만들기 도구
- `SHA256SUMS`: 다운로드 파일 확인값

v2.0.3 이하에서 올라오면 [v2.1.0의 어휘 교정과 화면 개선](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/releases/v2.1.0.md)도 함께 적용됩니다.

## 확인한 내용

- 새 설치와 v2.1.0 업데이트, 기존 복습 기록 보존 확인
- 배포 ZIP 안의 빌더와 공식 PDF 2개로 한자 카드 4,674장 생성·가져오기 통과
- 기본 문법·비교 문형·문제 카드의 후리가나 배치를 자동 검사와 미리보기로 확인

iPhone·iPad 실기기에서의 최종 확인은 아직 하지 못했습니다.

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 v2.1.1 기본 덱을 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
4. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

v2.1.0 한자 덱을 이미 정상적으로 만들었다면 다시 만들 필요가 없습니다.
생성에 실패했거나 v2.0.3 이하 한자 덱을 쓴다면 v2.1.1 빌더로 만드세요.

이전 버전의 빈 카드 정리 등은 [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)를 확인하세요.
