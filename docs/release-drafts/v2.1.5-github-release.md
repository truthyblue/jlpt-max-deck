# JLPT MAX Deck v2.1.5 — 한자 공부방 링크 수정

단어 카드 한자 칸의 일본어 한자 공부방 링크가 다시 그 한자 페이지로 열립니다.

## 바뀐 내용

- 일본어 한자 공부방 사이트 주소가 바뀌어 단어 카드 「한자」 칸의 ↗ 링크가 「페이지를 찾을 수 없음」으로 열리던 문제를 고쳤습니다. 이제 누르면 그 한자 페이지로 바로 열립니다.

![出す 단어 카드에서 펼친 한자 칸과 出 옆의 ↗ 링크 · v2.1.5 카드 미리보기](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.5/site/assets/releases/v2.1.5/kanji-reference-link.png)

## 확인한 내용

- 새 설치와 v2.1.4 업데이트, 기존 학습 기록 보존 검증 통과
- 一·白과 이체자 剥·塡·𠮟·頰·戶의 링크가 해당 한자 페이지로 열리는 것을 브라우저에서 확인
- 배포 ZIP과 공식 PDF 2개로 한자 카드 4,674장 생성·가져오기 검증 통과

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오면 표시가 풀립니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.5 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. v2.1.4 빌더로 만든 한자 덱은 다시 만들지 않아도 됩니다. v2.1.3 이전 빌더로 만든 한자 덱이라면 v2.1.5 빌더로 다시 만들어 가져와야 단어 카드 한자 칸에 일상무따 훈음과 娠 교정이 적용됩니다.
6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
