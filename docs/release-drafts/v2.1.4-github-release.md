# JLPT MAX Deck v2.1.4 — 실전 읽기 보기·정답 음성 수정

실전 읽기 문제의 보기와 정답 음성, 제보받은 읽기·뜻을 고쳤습니다.

## 바뀐 내용

- 실전 한자 읽기 문제 378개의 보기를 바꿨습니다. 오쿠리가나가 밑줄 친 말과 달라서 읽기를 몰라도 지울 수 있던 보기입니다(始まる 문제의 はじめる 등).
- 정답 음성 9개를 다시 만들었습니다. 十時를 「ととき」로, 10분의 十分을 「じゅうぶん」으로 읽는 등 후리가나와 다르게 읽던 음성입니다.
- 제보받은 읽기를 고쳤습니다. 毎年은 まいとし・まいねん, 欲深い는 よくぶかい로 읽고, 문법 예문의 他ならない·温湿度計·誤情報 후리가나를 ほか·おん·ご로 바로잡았습니다.
- 冷やす는 「차게 하다」로 고치고, 満更와 N2 문법 4개(～よりも, どのように 등)의 뜻을 다듬었습니다. 보기 순서와 맞지 않던 실전 해설 106개도 고쳤습니다.
- 출판사 단어 가운데 89개에 존경어·겸양어 같은 쓰임 표시를, 682개에 활용표를 붙였습니다.
- 문법 카드에서 나란히 붙은 후리가나(今週中 등)가 겹치던 문제와, PC Anki에서 후리가나가 한자 왼쪽으로 치우치던 문제를 고쳤습니다.
- 단어 카드 한자 칸에서 常用漢字가 아닌 127자는 네이버 한자사전으로 연결됩니다. 한자 칸 자료의 출처와 라이선스도 덱에 함께 넣었습니다.
- 「내 기록」 달력에서 30일보다 전에 공부한 날도 볼 수 있습니다.
- 한자 빌더에서 娠의 훈음을 「임신할 신」으로 고쳤습니다. 새 빌더로 만든 한자 덱을 가져오면 단어 카드 한자 칸에도 일상무따 훈음이 나옵니다.

## 확인한 내용

- 새 설치와 v2.1.3 업데이트, 기존 학습 기록 보존 검증 통과
- 다시 만든 정답 음성 9개가 후리가나대로 읽는지 음성 인식으로 확인
- 배포 ZIP과 공식 PDF 2개로 한자 카드 4,674장 생성·가져오기 검증 통과

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오면 표시가 풀립니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.4 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 한자 덱은 그대로 써도 됩니다. 새 빌더로 다시 만들어 가져오면 娠 훈음이 「임신할 신」으로 바뀌고, 단어 카드 한자 칸에 일상무따 훈음이 나옵니다.
6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
