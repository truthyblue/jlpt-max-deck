# JLPT MAX Deck v2.1.4 — 실전 읽기 보기·정답 음성 수정

실전 읽기 문제의 보기와 정답 음성, 제보된 읽기·뜻을 고쳤습니다.

## 바뀐 내용

- 실전 한자 읽기 문제 378개에서 밑줄 친 말의 가나 부분과 맞지 않아 읽기를 몰라도 지울 수 있던 보기를 바꿨습니다(始める에 はじまる가 섞인 경우 등).
- 정답 음성이 후리가나와 다르게 숫자를 읽던 9개(十時를 ととき, 十分을 じゅうぶん으로 읽는 등)를 다시 만들었습니다.
- 제보된 읽기를 고쳤습니다. 毎年은 まいとし・まいねん, 欲深い는 よくぶかい로 읽고, 문법 예문의 他ならない(ほか)·温湿度計(おん)·誤情報(ご) 후리가나를 바로잡았습니다.
- N2 문법 4개(～よりも, どのように 등)의 뜻과 満更·冷やす의 뜻을 고치고, 실전 해설이 보기 순서와 어긋나던 106문항을 맞췄습니다.
- 출판사 단어 3,143개 가운데 89개에 존경어·겸양어 같은 쓰임 표시를, 682개에 활용표를 더했습니다.
- 문법 카드에서 붙어 있는 후리가나(今週中 등)가 겹치던 문제와, PC Anki에서 후리가나가 한자 왼쪽으로 밀리던 문제를 고쳤습니다.
- 단어 카드 한자 칸에서 常用漢字가 아닌 한자 127자는 네이버 한자사전으로 연결하고, 칸의 출처와 라이선스를 덱 안에 넣었습니다.
- 「내 기록」 달력이 30일보다 오래된 공부한 날도 보여 줍니다.
- 한자 확장 빌더가 娠을 「임신할 신」으로 넣고, 한자 확장을 가져오면 단어 카드 한자 칸도 일상무따 훈음으로 보여 줍니다.

## 확인한 내용

- 새 설치와 v2.1.3 업데이트, 기존 학습 기록 보존 검증 통과
- 다시 만든 정답 음성 9개를 음성 인식으로 듣고 후리가나와 같은지 확인

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오면 표시가 풀립니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.4 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 한자 덱은 그대로 써도 됩니다. v2.1.4 빌더로 다시 만들어 가져오면 娠 교정과 단어 카드의 일상무따 훈음이 적용됩니다.
6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
