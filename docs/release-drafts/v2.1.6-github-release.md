# JLPT MAX Deck v2.1.6 — 한자 공부방 링크 수정 (v2.1.5 재배포)

v2.1.5에서 빠진 일본어 한자 공부방 링크 수정을 실제로 담았습니다. v2.1.5를 가져왔어도 v2.1.6을 다시 가져오세요.

## 바뀐 내용

- v2.1.5 패키지에는 링크 수정이 들어가지 않아, 가져와도 노트가 「이미 있음」으로 건너뛰어졌습니다. v2.1.6에서는 단어 카드 「한자」 칸의 ↗ 링크를 누르면 일본어 한자 공부방의 그 한자 페이지로 바로 열립니다.

![出す 단어 카드에서 펼친 한자 칸과 出 옆의 ↗ 링크 · v2.1.6 카드 미리보기](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.6/site/assets/releases/v2.1.6/kanji-reference-link.png)

## 확인한 내용

- 새 설치와 v2.1.5 업데이트, 기존 학습 기록 보존 검증 통과
- v2.1.5 위에 가져오면 노트 20,644개가 모두 업데이트되고, 한자 칸 링크 7,716개가 새 주소로 바뀌는 것을 확인
- 배포 ZIP과 공식 PDF 2개로 한자 카드 4,674장 생성·가져오기 검증 통과

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오면 표시가 풀립니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.6 기본 덱을 가져옵니다. v2.1.5를 이미 가져왔어도 다시 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. v2.1.4 이후 빌더로 만든 한자 덱은 다시 만들지 않아도 됩니다. v2.1.3 이전 빌더로 만든 한자 덱이라면 v2.1.6 빌더로 다시 만들어 가져와야 단어 카드 한자 칸에 일상무따 훈음과 娠 교정이 적용됩니다.
6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
