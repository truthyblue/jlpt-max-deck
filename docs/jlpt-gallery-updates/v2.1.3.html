일본어 맥스 덱 업데이트 — 제보받은 뜻·예문·읽기 수정

이번엔 그동안 제보받은 오류를 모아서 고쳤음.

  • 단어 뜻·예문·읽기 오류를 고쳤음. 横道는 よこみち 「옆길」, 却下는 「거절」로 바꿨고, 草의 ㅋㅋㅋ 뜻처럼 안 맞는 뜻은 뺐음.
  • 문법·실전 문제의 숫자 읽기(十時·一分·三本 등)를 바로잡고, 보기 순서가 섞이면 안 맞던 해설의 「N번」 표기를 없앴음.
  • 단어 카드 한자 칸의 훈음과 모양 풀이를 공개 자료 기준으로 바꿨음.
  • N2 문법 중복 2개, 중복 단어 3개(かんごし, おんなの人, どうぞ、よろしく)를 정리했음.
  • 내 기록 안내 창이 안 닫히거나 버튼이 가려지던 문제를 고쳤음. PC Anki에서는 업데이트 알림 창이 더 이상 안 뜨고 카드 아래 링크로만 알려줌.
  • 안드로이드(AnkiDroid)에서 「100일 랭킹, 절반 왔어요」 같은 알림이 카드 넘길 때마다 계속 뜨던 문제를 고쳤음. 이제 한 번만 뜸.

업데이트 전에 ★ 표시한 카드가 있으면 카드 탐색기에서 tag:marked로 찾아 깃발을 붙여 두셈. 새 파일을 가져오면 표시가 풀림. 그다음은 평소처럼 동기화와 백업 후, 덱을 지우지 말고 새 파일을 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기. 가져온 뒤 빈 카드에서 중복 단어 카드를 지우면 끝. 한자 덱은 다시 안 만들어도 됨. 한자 카드에 업데이트 알림이 뜨면 「이 버전 알림 그만 보기」 누르면 됨.
