JLPT MAX DECK v1.3.0
한자를 읽고 쓰는 공부를
따로 할 수 있게 바꿨음

한자 2,337자를 읽기·쓰기로 나누고 획순 연습과 헷갈리는 한자 힌트를 넣었음. 중복되던 가나 보조 카드는 없앴고, 카드 화면·음성·예문·오류 제보도 함께 다듬었음.

기존 사용자는 꼭 확인
덱을 지우지 말고, 기존 노트를 ‘항상’ 업데이트
  1. 모든 기기 동기화와 컬렉션 백업을 먼저 확인
  2. 기존 덱을 삭제하지 않고 v1.3.0 APKG 가져오기
  3. 학습 진행 상태 가져오기: 끄기
  4. 기존 노트 업데이트: 항상
  5. 노트 유형 병합: 켜기
  6. 아래 가나 보조 카드 정리 후 모든 기기에서 전체 동기화

한자 확장을 쓰던 사람은 새 빌더 ZIP과 지원 PDF 2개로 한자 APKG도 다시 만들어 가져와야 새 읽기·쓰기 카드와 획순이 들어감.

한 번만 하는 카드 정리
가나 보조 카드는 ‘빈 카드’ 도구로만 삭제

앞면에서 히라가나만 묻던 어휘(가나 보조) 카드는 v1.3.0부터 만들지 않음. APKG 업데이트만으로 예전 카드 행이 남을 수 있어서 아래 메뉴를 한 번 실행해야 함.

Android·AnkiDroid: ⋮ → 확인 → 빈 카드
iPhone·iPad: 설정 → 빈 카드
PC Anki: 도구 → 빈 카드

JLPT MAX덱 어휘 / 어휘(가나 보조)인지 확인하고 빈 카드 도구의 삭제를 누르면 됨. 144장 또는 6,018장으로 보일 수 있음.

카드 탐색기의 ‘노트 삭제’는 누르면 안 됨. 같은 노트의 어휘·음성 카드까지 같이 지워짐.

가나 보조 카드의 별도 일정·복습 기록은 원래 한자 카드로 옮기지 않음. 원래 한자 카드의 급수, 카드 ID, 일정과 복습 기록은 그대로 유지함. 모바일에서는 대상 카드에 처음 들어갈 때 이 절차도 안내함.

읽기는 유지하고, 쓰기는 새로 시작

기존 한자 카드는 한자::읽기로 옮기지만 카드 ID와 학습 기록을 유지함. 새 한자::쓰기 2,337장은 새 학습 항목으로 시작해서 읽기 공부와 일정이 섞이지 않음.

  • 읽기: 실제 단어를 음독·훈독별로 묶고 공식 상용한자 읽기도 표시
  • 쓰기: 첫 터치부터 쓰기, 전체 지우기, 정답 자형과 획순 재생
  • 비슷한 한자: 뜻·음독·훈독을 한 화면에서 비교
  • 획순 SVG 2,298개, SVG가 깨지는 환경용 PNG 자형 14개
v1.2.1과 v1.3.0의 한자 읽기 카드 비교
덱 구성
기본 덱과 한자 확장을 따로 배포함

기본 APKG는 13,903노트·19,921카드임. 한자 빌더 결과는 4,674노트·4,674카드이고, 둘을 합치면 18,577노트·24,595카드가 됨.

기본 덱에는 어휘·음성·종합 실전·참조표만 들어감. 한자는 빌더가 사용자가 고른 지원 PDF 2개로 개인용 APKG를 만듦. 출판사 PDF 원문·페이지 이미지·추출 원문은 공개 파일에 넣지 않음.

카드가 더 또렷하고, 음성은 더 빨리 시작
  • 한자 읽기·부수·획수, 발음별 단어와 비슷한 한자의 크기·간격을 모바일 폭에 맞게 정리
  • 단어 고저 악센트의 읽기를 키우고 긴 루비·괄호 읽기의 간격 보정
  • 글꼴과 표시 설정을 첫 화면 전에 적용하고 학습 중 글꼴을 고정해 깜빡임·글자 이동 감소
  • 디코딩된 음성의 첫 유효 소리 직전부터 재생해 앞쪽 무음 건너뜀
  • 같은 뜻의 예문은 한 영역에 모으고 다른 뜻의 예문과 분리

iPhone·iPad는 무음 모드에서도 카드 음성을 재생함. 카드 설정의 다른 앱 음악과 함께 재생을 직접 켠 경우에만 다른 앱 음악과 섞어 재생하고, 선택값은 저장함.

모바일 지원·오류 제보
AnkiDroid 안내와 선택형 답장

AnkiDroid 구형 학습 화면에서 카드 저장·오디오·입력이 제한되면 지원되는 새 학습 화면으로 옮기는 안내를 표시함.

오류 제보는 계속 익명이 기본임. 답장을 원하는 경우에만 동의 뒤 연락처 입력란이 나타남. 연락처는 제보와 분리해 암호화하고 수동 답장에만 쓰며 최대 90일 뒤 삭제함. 공개 처리 기록에는 제보 원문·연락처·기기 식별값을 넣지 않음.

뜻·예문·읽기 오류도 함께 교정

掛かる, 沸騰, 細かい, 冷やす, 断る, 改札, 定員, 遠慮의 뜻과 예문 연결을 다시 검토했음.

長い, 直る, 改札, 帯, 合流, いらっしゃる, 積む, 負う, 遥か, 開拓, 食い込む, 連携, 丘陵, くまなく, 中毒의 겹치거나 부족한 예문도 정리했음.

届ける 루비 경계, 잘못 생성된 何つ→幾つ, 씨앗 種→たね, 通っている→かよっている, 噛み癖→かみぐせ, 条件·設定·了承의 읽기, 打診 예문 번역과 이미지 한자 4건을 고쳤음. iOS 재생 제보 6건도 새 기본 재생 방식으로 해결함.

현행 표기가 맞거나 공개본에서 재현되지 않은 이번 7건과 이전 25건은 이유를 공개함. 예전에 기각했던 가나 보조 카드 제보 81건은 이번에 카드 유형을 없애 해결했으므로 기각 합계에서 뺐음. 사전 버튼을 새 창으로 여는 요청 1건은 기능 변경이 필요해 다음 릴리스 검토로 남김.

iPhone·iPad 카드 설정이 초기화됐다면

재생·후리가나 설정이 초기화됐다는 익명 제보 1건이 있었음. JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았고, 저장 공간이 매우 부족할 때 iOS가 카드 화면 저장값을 정리했을 가능성을 보고 있음. 당시 상태를 추가 확인할 수 없어 원인은 확정하지 못했음.

설정 → 일반 → iPhone/iPad 저장 공간을 확인하고 카드 설정을 다시 저장하면 됨. 반복되면 남은 용량, iOS·AnkiMobile 버전과 앱 재실행 전후 중 언제 생겼는지를 제보해 주면 됨. 이 설정은 Anki 학습 기록과 별도라 학습 기록이 초기화되는 현상은 아님.

눈에 안 보이는 안정성 변경

사용 통계를 켠 경우 업데이트 공지 이벤트가 통신 실패 뒤 다시 전송되고, 대기 중인 같은 이벤트는 한 건으로 합쳐짐. 버전별 활동과 익명 설치 수 추정도 추가했음. 이 변경이 사용 통계를 새로 켜지는 않으며 기존 선택을 그대로 따름.

콘텐츠·미디어·APKG를 각각 해시로 묶고 중단된 릴리즈 준비를 같은 지점에서 이어가도록 바꿨음. 사용자가 받는 APKG는 새 설치와 업데이트 검사를 통과한 바로 그 파일임.

실제 후보 파일 검증
  • 빈 profile 새 가져오기 1회 통과
  • v1.2.1 → v1.3.0 업데이트 가져오기 1회 통과
  • 기존 공통 카드 22,258장의 ID·일정·복습 기록 유지 확인
  • 기존 노트 16,240개 갱신, 새 한자 쓰기 2,337개 추가
  • 가나 보조 카드 144개 제거 대상 확인
  • 원본 음성 18,434개는 이전 승인본과 byte 단위로 동일, TTS 새 합성 0회

실물 iPhone·iPad와 Android의 모든 기기·앱 버전 조합은 이번 정식판에서 따로 전수 검증하지 않았음. 실제 배포 APKG의 새 설치·업데이트, 공개 기본 덱과 한자 빌더 구조, 해시와 390×844 모바일 폭 렌더링을 확인했음.
