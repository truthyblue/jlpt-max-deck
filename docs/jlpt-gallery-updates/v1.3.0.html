JLPT MAX Deck · v1.3.0
한자를 읽고,
직접 쓰면서 외우게.

한자 2,337자를 읽기와 쓰기로 나눠 공부하고 획순과 헷갈리는 한자를 함께 확인할 수 있음. 어휘 읽기·음성·예문과 오류 제보도 다듬은 마이너 업데이트.

업데이트할 때 ‘항상’을 선택

기존 덱을 삭제하지 말고 v1.3.0 기본 APKG를 가져오면 됨. 학습 진행 상태 가져오기: 끄기, 기존 노트 업데이트: 항상, 노트 유형 병합: 켜기를 선택한 뒤 모든 기기에서 전체 동기화해야 함.

한자 확장을 쓰고 있다면 v1.3.0 빌더와 지원 PDF 2개로 한자 APKG를 다시 만들어 가져오면 됨.

읽기 카드와 쓰기 카드를 따로

한자 하나마다 읽기 카드와 쓰기 카드를 따로 만들었음. 읽기에서는 음독·훈독별 실제 단어와 공식 읽기를 보고, 쓰기에서는 직접 따라 쓴 뒤 정답 자형과 획순을 확인할 수 있음.

모양이 비슷한 한자는 뜻과 읽기를 같이 보여 줘 어디가 헷갈리는지 비교할 수 있음.

PUBLIC DECK
기본 덱은 가볍게, 한자는 빌더로 합치기

public 기본 APKG는 어휘·음성·종합 실전·참조표 13,903노트·20,065카드만 포함함. 한자는 지원 PDF 원문을 배포하지 않고, 빌더가 개인용 읽기·쓰기 APKG 4,674노트·4,674카드를 만들어 합치는 구조임.

두 APKG를 합치면 전체 18,577노트·24,739카드가 됨. 한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됨.

읽기·음성·예문도 더 자연스럽게

한자 읽기 정보와 단어 고저 악센트의 읽기 글자를 더 또렷하게 다듬었음. 음성은 앞쪽 무음을 건너뛰어 첫 소리가 늦게 들리는 느낌을 줄였고, 같은 뜻을 보여 주는 예문은 한 영역으로 묶었음.

검토가 끝난 뜻·읽기·예문·고저 악센트·문제 후리가나 교정도 함께 반영했음. 届ける 예문, 幾つ, 種, 通っている, 噛み癖, 条件·設定, 了承 예문 후리가나와 제보된 이미지 한자 4건을 고쳤음.

MOBILE SUPPORT
AnkiDroid 안내와 선택형 답장

AnkiDroid 구형 학습 화면에서 일부 기능을 쓸 수 없으면 지원되는 새 학습 화면으로 옮기는 안내를 보여 줌.

iOS는 무음 모드에서도 카드 음성이 나오도록 기본 재생 방식을 바꿨음. 같은 문제가 다시 들어오면 기기와 카드별로 다시 확인함.

오류 제보는 계속 익명으로 보낼 수 있음. 답장을 원할 때만 연락처와 답장 동의를 선택해서 보낼 수 있음.

실제 배포 파일로 두 가지 업데이트 확인

빈 profile에 새로 가져오기 1회와 v1.2.1에서 v1.3.0으로 업데이트 가져오기 1회를 각각 확인했음. 기존 어휘·실전 문제·참조표의 학습 기록은 이어지고, 새 한자 쓰기 카드는 새 학습 항목으로 시작함.

실물 iPhone·iPad와 Android의 모든 조합은 이번 정식판에서 따로 전수 검증하지 않았음. 실제 APKG import와 모바일 폭 HTML 렌더링을 확인했음.
