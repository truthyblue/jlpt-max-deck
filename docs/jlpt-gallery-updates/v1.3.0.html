JLPT MAX DECK v1.3.0
한자 쓰기 카드
2,337장 추가

한자 쓰기를 새로 연습할 수 있고, 기존 한자 읽기 카드는 음독·훈독별 단어와 헷갈리는 한자 힌트를 함께 볼 수 있게 바뀌었음. 음성 재생, iPhone·iPad 설정, 예문과 오류 제보도 개선했음.

기존 사용자 필수 작업
업데이트할 때 이 4단계를 직접 해주세요

새로 설치하는 사람은 아래 정리가 필요 없음. 기존 덱에 v1.3.0을 덮어쓰는 사람만 순서대로 하면 됨.

1. 기존 덱을 지우지 말고 가져오기
  1. 모든 기기를 동기화하고 컬렉션 백업 확인
  2. 기존 덱을 삭제하지 않고 v1.3.0 기본 APKG 가져오기
  3. 학습 진행 상태 가져오기: 끄기
  4. 기존 노트 업데이트: 항상
  5. 노트 유형 병합: 켜기

앞으로도 출발 버전과 상관없이 기존 노트 업데이트: 항상을 쓰면 됨. 직접 고친 공식 노트 내용은 덮어쓸 수 있으니 그런 수정이 있다면 먼저 백업해야 함.

2. 한자 확장을 썼다면 읽기 카드 옮기기

v1.3.0 빌더 ZIP과 지원 PDF 2개로 한자 APKG도 다시 만들어 가져와야 함. 새 쓰기 카드는 자동으로 추가되지만, 기존 읽기 카드는 원래 있던 일상무따::상권·하권에 그대로 남음.

PC Anki에서 옮기는 방법

  1. 카드 탐색을 열고 왼쪽에서 JLPT MAX덱::일상무따::상권 선택
  2. 편집 → 모두 선택을 누른 뒤 카드 → 덱 변경 선택
  3. 대상을 JLPT MAX덱::한자::읽기::상권으로 지정
  4. 하권도 같은 방법으로 한자::읽기::하권에 옮기기

iPhone·iPad는 카드 탐색 → 선택 → 모두 선택 → 동작 → 덱 변경, AnkiDroid는 카드 탐색기 → 덱 선택 → 전체 선택 → 덱 변경으로 같은 작업을 할 수 있음. 덱만 바뀌며 기존 학습 일정과 복습 기록은 그대로 유지됨. 직접 다른 덱으로 옮겨 둔 카드는 원하는 경우에만 새 읽기 덱으로 옮기면 됨.

3. 가나 보조 카드를 빈 카드에서 삭제하기

v1.3.0은 어휘(가나 보조) 카드를 더 이상 쓰지 않음. 하지만 Anki는 업데이트할 때 예전 카드를 자동으로 지우지 않으므로 사용자가 직접 정리해야 함.

Android·AnkiDroid: ⋮ → 확인 → 빈 카드
iPhone·iPad: 설정 → 빈 카드
PC Anki: 도구 → 빈 카드

목록에서 JLPT MAX덱 어휘 / 어휘(가나 보조)만 골라 빈 카드 도구의 삭제를 누름. 표시 수는 사용 중인 버전과 컬렉션 상태에 따라 다를 수 있음. 이 방법은 가나 보조 카드만 지우고 같은 노트의 어휘·음성 카드는 남김.

카드 탐색기의 ‘노트 삭제’는 누르면 안 됨. 같은 노트의 어휘·음성 카드까지 같이 지워짐.

4. 모든 기기에서 전체 동기화하기

가져오기, 한자 읽기 카드 이동, 가나 보조 카드 삭제를 모두 끝낸 뒤 전체 동기화함.

가나 보조 카드에 표시되는 한 번만 정리 안내
한자 쓰기 카드 2,337장 추가
  • 한자::쓰기::상권·하권에 새 쓰기 카드 2,337장이 추가됨
  • 기존 읽기 카드는 일상무따::상권·하권에 그대로 남으므로, 위 2단계에 따라 한자::읽기::상권·하권으로 직접 옮겨야 함
  • 읽기 일정과 섞이지 않고 새 학습 항목으로 시작
  • 직접 쓰기, 한 획 되돌리기, 모두 지우기 지원
  • 정답 자형과 획순 다시 보기 지원
  • 획순 SVG 2,298개와 깨지는 환경용 PNG 자형 14개 포함
새 한자 쓰기 카드의 전체 화면
한자 읽기에 발음별 단어·혼동 힌트 추가

기존 한자 카드 2,337장은 일정과 복습 기록을 유지한 채 새 읽기 화면으로 바뀜. 실제 단어를 음독·훈독별로 묶고, 덱 단어가 없는 공식 읽기도 표시함. 비슷한 한자는 뜻·음독·훈독을 함께 비교함.

음성 재생
음성이 약간 느리게 재생되던 문제 수정

일부 카드에서 음성 앞쪽의 짧은 무음 때문에 소리가 늦게 시작되는 느낌이 있었음. 이제 실제 소리가 시작되는 부분부터 바로 재생됨.

iPhone·iPad 무음 모드 재생을 기본값으로 변경

v1.3.0부터 기본 재생 방식을 바꿔 무음 모드에서도 카드 음성이 나오게 했음. 이전 버전처럼 다른 앱 음악을 계속 들으면서 카드 음성을 섞고 싶다면 카드 설정의 다른 앱 음악과 함께 재생을 켜면 됨. 이 옵션을 켜면 무음 모드에서는 카드 음성이 나오지 않을 수 있으며 선택값은 저장됨.

고저 악센트 읽기와 카드 배치 개선
  • 단어 고저 악센트의 읽기 글자를 키움
  • 긴 루비와 괄호 읽기가 서로 밀리지 않게 간격 보정
  • 첫 화면 전에 글꼴·표시 설정을 적용해 깜빡임과 글자 이동 감소
  • 포함된 일본어 글꼴을 직접 적용해 Mac Anki에서 일부 글자가 □로 보이던 문제 수정
  • 한자 카드 앞뒤 머리글 위치와 모바일 간격 안정화
v1.2.1 화면 보완
예문 묶음에서 빠진 경우 수정

예문을 뜻 묶음별 흰 영역으로 나누는 기능은 v1.2.1에서 추가됐음. v1.3.0에서는 단어 전체에 뜻 묶음이 하나뿐이고 그 안에 표현이 여러 개일 때 예문이 따로 떨어지던 경우도 한 영역으로 모이게 고쳤음.

AnkiDroid
구형 학습 화면 안내 추가

구형 학습 화면에서 카드 저장·오디오·입력이 제한될 수 있는 경우 AnkiDroid 설정 → 새 학습 화면 켜기 경로를 카드 안에서 안내함.

오류 제보에 이메일 답장 옵션 추가

오류 제보는 계속 익명이 기본임. 답장을 원하는 경우에만 이메일 답변 받기에 동의하고 이메일을 입력함. 연락처는 제보와 분리해 암호화하고 수동 답장에만 사용하며, 답변 완료 시 또는 접수 90일 뒤 삭제함.

뜻·읽기·예문 오류 교정

제보받은 내용을 다시 확인해 뜻과 예문 연결, 겹치거나 부족한 예문, 후리가나와 읽기, 예문 번역, 이미지 한자 오류를 고쳤음.

iPhone·iPad 음성 재생 제보와 예전 가나 보조 카드 제보도 이번 변경에 반영했음. 어떤 낱말을 고쳤는지와 반영하지 않은 제보의 이유는 아래 상세 변경 내역에서 확인할 수 있음.

알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 설정이 초기화됐다는 익명 제보 1건이 있었음. JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았고, 저장 공간이 매우 부족할 때 iOS가 카드 화면 저장값을 정리했을 가능성을 보고 있음. 당시 상태를 추가 확인할 수 없어 원인은 확정하지 못했음.

설정 → 일반 → iPhone/iPad 저장 공간을 확인하고 카드 설정을 다시 저장하면 됨. 이 설정은 Anki 학습 기록과 별도라 학습 기록이 초기화되는 현상은 아님.

사용 통계 전송 안정성 개선

사용 통계를 켠 경우 업데이트 공지 기록이 통신 실패 뒤 다시 전송되고, 같은 기록이 여러 번 쌓이지 않게 바뀌었음. 사용 통계를 새로 켜지는 않으며 기존 선택을 그대로 따름.
