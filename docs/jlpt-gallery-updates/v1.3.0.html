JLPT MAX DECK v1.3.0
한자 쓰기 카드
2,337장 추가

한자 읽기 카드에는 음독·훈독별 단어와 헷갈리는 한자 힌트를 넣었음. 가나 보조 카드 정리, 음성 재생, iPhone·iPad 설정, 예문과 오류 제보도 함께 개선했음.

기존 덱 업데이트
기존 노트 업데이트는 언제나 ‘항상’
  1. 모든 기기 동기화와 컬렉션 백업 확인
  2. 기존 덱을 삭제하지 않고 v1.3.0 APKG 가져오기
  3. 학습 진행 상태 가져오기: 끄기
  4. 기존 노트 업데이트: 항상
  5. 노트 유형 병합: 켜기
  6. 아래 가나 보조 카드 정리 뒤 모든 기기에서 전체 동기화

앞으로 JLPT MAX 덱을 업데이트할 때는 출발 버전과 상관없이 이 옵션을 그대로 쓰면 됨. 직접 고친 공식 노트 필드는 덮어쓸 수 있으니 그런 수정이 있다면 먼저 백업해야 함.

한자 확장을 쓰던 사람은 v1.3.0 빌더 ZIP과 지원 PDF 2개로 한자 APKG도 다시 만들어 가져와야 함.

업데이트 뒤 한 번만
가나 보조 카드 144장을 빈 카드로 정리

v1.2.1에서 실제로 업데이트해 보니 기존 어휘(가나 보조) 카드 144장은 물리적으로 남았고, Anki의 빈 카드 검사에 144장 모두 잡혔음. 앞면은 비었다는 화면만 표시됨.

Android·AnkiDroid: ⋮ → 확인 → 빈 카드
iPhone·iPad: 설정 → 빈 카드
PC Anki: 도구 → 빈 카드

JLPT MAX덱 어휘 / 어휘(가나 보조)인지 확인하고 빈 카드 도구의 삭제를 누르면 됨. 이 작업은 가나 보조 카드와 그 복습 기록만 지우고 같은 노트의 어휘·음성 카드는 남김.

카드 탐색기의 ‘노트 삭제’는 누르면 안 됨. 같은 노트의 다른 카드까지 같이 지워짐.

한자 쓰기 카드 2,337장 추가
  • 한자::쓰기::상권·하권에 새 쓰기 카드 2,337장이 추가됨
  • 기존 읽기 카드는 일상무따::상권·하권에 그대로 남으므로, 새 읽기 덱을 쓰려면 한자::읽기::상권·하권으로 직접 옮겨야 함
  • 읽기 일정과 섞이지 않고 새 학습 항목으로 시작
  • 직접 쓰기, 한 획 되돌리기, 모두 지우기 지원
  • 정답 자형과 획순 다시 보기 지원
  • 획순 SVG 2,298개와 깨지는 환경용 PNG 자형 14개 포함
새 한자 쓰기 카드의 전체 화면
한자 읽기에 발음별 단어·혼동 힌트 추가

기존 한자 카드 2,337장은 카드 ID·일정·복습 기록을 유지한 채 새 읽기 화면으로 바뀜. 실제 단어를 음독·훈독별로 묶고, 덱 단어가 없는 공식 읽기도 표시함. 비슷한 한자는 뜻·음독·훈독을 함께 비교함.

기존 카드는 자동으로 한자::읽기 덱으로 이동하지 않음.
일반 APKG 가져오기는 현재 덱 위치를 그대로 둠. 그래서 기존 카드는 일상무따::상권·하권이나 직접 옮겨 둔 덱에 남고, 새 한자::읽기::상권·하권은 비어 있을 수 있음. 새 구조를 쓰려면 카드 탐색기에서 기존 상권·하권 카드를 읽기 상권·하권으로 직접 옮기면 됨.
음성 재생
음성이 약간 느리게 재생되던 문제 수정

일부 카드에서 음성 앞쪽의 짧은 무음 때문에 재생이 약간 늦게 시작되는 느낌이 있었음. 첫 유효 소리 직전부터 재생하고, 같은 카드에서 다시 재생할 때는 찾은 위치를 재사용하도록 고쳤음.

원본 음성 18,434개는 이전 승인본과 byte 단위로 같고 새 TTS 합성은 없었음.

iPhone·iPad 무음 모드 재생 옵션 추가

기본값은 무음 모드에서도 카드 음성을 재생함. 카드 설정의 다른 앱 음악과 함께 재생을 직접 켜면 다른 앱 음악과 카드 음성을 섞어 재생함. 대신 이 옵션을 켠 상태에서는 iPhone 무음 모드에서 카드 음성이 나오지 않을 수 있음. 선택값은 저장됨.

고저 악센트와 예문 묶음 화면 개선
  • 단어 고저 악센트의 읽기 글자를 키움
  • 긴 루비와 괄호 읽기가 서로 밀리지 않게 간격 보정
  • 같은 뜻의 예문은 한 영역에 모으고 다른 뜻과 분리
  • 첫 화면 전에 글꼴·표시 설정을 적용해 깜빡임과 글자 이동 감소
  • 한자 카드 앞뒤 머리글 위치와 모바일 간격 안정화
AnkiDroid
구형 학습 화면 안내 추가

구형 학습 화면에서 카드 저장·오디오·입력이 제한될 수 있는 경우 AnkiDroid 설정 → 새 학습 화면 켜기 경로를 카드 안에서 안내함.

오류 제보에 이메일 답장 옵션 추가

오류 제보는 계속 익명이 기본임. 답장을 원하는 경우에만 이메일 답변 받기에 동의하고 이메일을 입력함. 연락처는 제보와 분리해 암호화하고 수동 답장에만 사용하며, 답변 완료 시 또는 접수 90일 뒤 삭제함.

뜻·읽기·예문 오류 교정

掛かる, 沸騰, 細かい, 冷やす, 断る, 改札, 定員, 遠慮의 뜻과 예문 연결을 다시 검토했음.

長い, 直る, 改札, 帯, 合流, いらっしゃる, 積む, 負う, 遥か, 開拓, 食い込む, 連携, 丘陵, くまなく, 中毒의 겹치거나 부족한 예문을 정리했음.

届ける 루비 경계, 何つ→幾つ, 씨앗 種→たね, 通っている→かよっている, 噛み癖→かみぐせ, 条件·設定·了承의 읽기, 打診 예문 번역과 이미지 한자 4건을 고쳤음.

iPhone·iPad 재생 제보 6건과 예전 가나 보조 카드 제보 81건은 이번 변경으로 해결함. 현행 내용이 맞거나 공개본에서 재현되지 않은 32건은 이유를 공개함. 사전 버튼 새 창 요청 1건은 다음 릴리스 검토로 남김.

배포 구성
기본 덱과 한자 확장을 따로 배포

기본 APKG는 13,903노트·19,921카드임. 한자 addon은 4,674노트·4,674카드이고, 둘을 합치면 18,577노트·24,595카드가 됨.

기본 덱에는 어휘·음성·종합 실전·참조표만 들어감. 한자는 빌더가 지원 PDF 2개를 사용자의 컴퓨터에서 읽어 개인용 APKG로 만듦. 출판사 PDF 원문·페이지 이미지·추출 원문은 공개 파일에 넣지 않음.

알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 설정이 초기화됐다는 익명 제보 1건이 있었음. JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았고, 저장 공간이 매우 부족할 때 iOS가 카드 화면 저장값을 정리했을 가능성을 보고 있음. 당시 상태를 추가 확인할 수 없어 원인은 확정하지 못했음.

설정 → 일반 → iPhone/iPad 저장 공간을 확인하고 카드 설정을 다시 저장하면 됨. 이 설정은 Anki 학습 기록과 별도라 학습 기록이 초기화되는 현상은 아님.

사용 통계와 배포 안정성 개선

사용 통계를 켠 경우 업데이트 공지 이벤트가 통신 실패 뒤 다시 전송되고, 같은 대기 이벤트는 한 건으로 합쳐짐. 버전별 활동과 익명 설치 수 추정도 추가했음. 사용 통계를 새로 켜지는 않으며 기존 선택을 그대로 따름.

콘텐츠·미디어·APKG를 해시로 묶고 중단된 릴리즈 준비를 이어가도록 바꿨음. 사용자가 받는 APKG는 새 설치와 업데이트 검사를 통과한 바로 그 파일임.

실제 배포 후보 검증
  • 빈 profile 새 가져오기 통과
  • v1.2.1 배포 APKG → v1.3.0 실제 업데이트 가져오기 추가 확인
  • 기존 노트 16,240개 갱신, 새 한자 쓰기 2,337장 추가
  • 기존 한자 읽기 2,337장 중 자동 덱 이동 0장

  • UI 9개 상태의 전체 화면 원본과 확대본에서 이미지 누락·가로 넘침·콘솔 오류 없음
  • 원본 음성 18,434개 동일, TTS 새 합성 0회

실물 iPhone·iPad와 Android의 모든 기기·앱 버전 조합은 이번 정식판에서 따로 전수 검증하지 않았음. 실제 배포 APKG의 새 설치·업데이트, 공개 기본 덱과 한자 빌더 구조, 해시와 생성 HTML 렌더링을 확인했음.
