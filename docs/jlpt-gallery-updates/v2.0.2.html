JLPT MAX DECK v2.0.2
문법 후리가나 추가
내 기록·한자 빌더 수정

문법 답면을 더 읽기 쉽게 만들고, 모바일 내 기록이 매번 서버를 기다리던 흐름과 한자 빌더의 복합 자형 표시를 고쳤음.

v2.0.1 사용자
기존 덱을 지우지 말고 업데이트

모든 기기를 AnkiWeb과 동기화하고 백업한 뒤 v2.0.2 기본 APKG를 기존 덱 위에 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 선택.

한자 확장을 쓰면 v2.0.2 한자 빌더 ZIP으로 지원 PDF 2개를 다시 읽어 한자 APKG를 만든 뒤 가져와야 함. 기본 덱만 쓰면 빌더는 필요 없음.

문법 4종 답면에 후리가나

문형 예문과 혼동 표현, 문법 형태의 완성 문장·선택지, 문장 배열의 완성 문장, 지문 빈칸의 제목·완성 지문·선택지에 후리가나를 넣었음.

  • 문제를 푸는 앞면은 그대로 유지
  • 정답을 보는 답면에서만 후리가나 표시
  • 오른쪽 위 후리가나 버튼으로 켜기·끄기
  • 지문 문제의 긴 선택지는 모바일에서 읽기 쉽게 한 줄에 하나씩 표시
모바일 내 기록
첫 복원 뒤에는 기기에서 바로 계산

예전에는 내 기록에 들어갈 때 서버 결과를 기다리는 구간이 컸음. 이제 첫 복원이 끝나면 기기에 저장된 기록만으로 첫 화면과 개인 분석을 바로 만들고, 서버는 뒤에서 빠진 기록만 확인하고 교정함.

  • 기기 기록이 비어 있을 때는 동그란 로딩 표시를 보여 주고 첫 복원 자료를 한 요청으로 받음
  • 최근 90일은 일별, 최근 1년은 월별로 기기에 저장
  • 7일·30일·이번 달·3개월·1년·전체의 기간 합계 유지
  • 각 기간의 영역별·급수별 합계도 기간 총합과 맞게 계산
  • 이번 달 순위와 서버 확인은 최대 1시간에 한 번만 새로 받음
  • Android 쿠키에서 다시 받을 수 있는 자료를 빼고 월별 기록을 더 작게 압축
  • v2.0.1과 시험판의 이전 기록 저장 구조는 자동으로 새 구조로 이전
전체 합계를 없앤 게 아님. 오래된 일별 점은 줄여도 전체 답안 확인 합계와 기간별·영역별·급수별 분석에 필요한 값은 남김.
실제 AnkiDroid · 기간 총합과 영역별·급수별 분석
한자 빌더 복합 자형 수정

한 칸에 여러 자형이 함께 적힌 글자가 모바일에서 두 줄로 갈라지거나 작은 쓰기 정답 칸을 벗어나던 문제를 고쳤음.

  • 艹/䒑, 巴/巳, 兎(兔) 같은 복합 자형을 한 줄로 유지
  • 읽기 카드 정답 영역에 맞는 크기로 자동 축소
  • 더 작은 쓰기 카드 정답 칸에도 따로 맞춤
  • v2.0.2 빌더가 만든 읽기·쓰기 한자 카드에 함께 적용
버튼을 눌렀다는 느낌도 보강

내 기록의 탭과 기간 선택을 포함해 카드 안의 버튼이 손을 뗀 순간 바로 튀어 오르지 않게 했음. 짧게 눌러도 눌린 상태가 눈에 보임.
