v2.1.3에서 사전식으로 바뀌었던 단어 카드 「한자」 칸 훈음이, 한자 확장을 가져오면 일상무따 책 훈음으로 나옴.

- 行 — 다닐 행 → ① 갈 행 ② 행할 행
- 金 — 쇠 금 → ① 금(속) 금 ② 돈 금
- 生 — 날 생 → 태어날 생·살아갈 생

v2.1.4 빌더로 한자 덱을 다시 만들어 가져와야 적용됨. 예전 빌더로 만든 한자 덱에는 이 훈음 표가 없어서 단어 카드는 사전식 훈음 그대로임. 다시 만들면 娠 훈음 교정(임신할 신)도 같이 들어감.

제보받은 읽기와 뜻

- 毎年 — まいとし・まいねん 둘 다
- 欲深い — よくぶかい
- 他ならない · 温湿度計 · 誤情報 — 문법 예문 후리가나를 ほか · おん · ご로 고침
- 冷やす — 「식히다」 대신 「차게 하다」
- 満更 · N2 문법 4개 — 뜻 다듬음

카드 화면

- 문법 카드에서 나란히 붙은 후리가나(今週中 등)가 겹치던 것 고침
- PC Anki에서 후리가나가 한자 왼쪽으로 치우치던 것 고침
- 「내 기록」 달력에서 30일 넘은 공부 기록도 보임
- 단어 카드 한자 칸: 常用漢字가 아닌 127자는 네이버 한자사전으로 연결
