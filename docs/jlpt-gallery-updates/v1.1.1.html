JLPT MAX Deck · v1.1.1 HOTFIX
뜻과 예문의 연결은 또렷하게,
모바일 복습은 더 안정적으로.

같은 뜻 묶음과 서로 다른 뜻을 카드에서 구분하고, 각 예문이 어떤 표현에 대응하는지 바로 보이게 바꿨음. 보충 예문 100개를 더했으며, 모바일 설정 저장과 iPhone·iPad 음성 재생도 함께 보완했음.

MEANING & EXAMPLES
1. 뜻 묶음과 예문의 연결을 더 또렷하게

같은 의미 묶음 안의 표현은 가운데점(·)으로, 서로 다른 독립 의미는 슬래시(/)로 표시함. 예문 1·2 대신 각 문장 위에 대응하는 뜻 칩을 붙여 어떤 의미의 예문인지 바로 확인할 수 있음.

兄 — 형 · 오빠
오빠　私は妹で、兄は私より三歳上です。
형　弟は兄と毎朝一緒に学校へ行く。

구성 요소별로 빠져 있던 보충 예문 100개와 음성을 추가해 검토 예문은 6,883개가 됐음. 노트·카드 ID는 바꾸지 않아 기존 학습 기록을 이어서 쓸 수 있음.

MOBILE SETTINGS
2. 쿠키 + localStorage 이중 저장

일부 iPhone·iPad에서는 AnkiMobile 카드 화면의 쿠키 저장이 실패해 후리가나·해석·자동재생·배속 설정이 앱을 다시 열면 초기화되고, 익명 통계 동의 상태도 유지되지 않을 수 있었음. v1.1.1부터 같은 값을 쿠키와 localStorage에 함께 저장함.

기존 값도 자동으로 이어받음
유효한 쿠키가 있으면 먼저 사용해 localStorage에 복제하고, 쿠키를 쓸 수 없으면 localStorage에서 복원함. 둘 중 하나만 작동해도 설정을 계속 저장할 수 있음.
3. 아이폰·아이패드 음성 재생 수정

AnkiMobile에서는 다른 앱의 소리를 존중하는 ambient 오디오 세션을 요청한 뒤 HTML 오디오 요소를 직접 재생함. Web Audio의 fetch·decode 경로를 거치지 않아 iPhone·iPad 카드 화면에서 재생이 시작되지 않거나 중간에 끊기는 경로를 줄였음.

표제어·예문·실전 정답의 직접 재생과 순차 자동재생에 같은 배속·종료·취소 규칙을 적용함. Android와 데스크톱은 기존 재생 경로를 유지함.

UPDATE NOTICE
4. 새 버전 안내 보강

카드 답면에서 더 최신 버전을 알려 주고 업데이트 가이드로 바로 이동할 수 있음. 당장 업데이트하기 어렵다면 7일간 숨기기를 누르거나, 해당 버전의 알림 다시 보지 않기를 선택할 수 있음.

학습을 방해하지 않게 제한
하루 최대 3번만 표시하며, 최신 버전 확인에 실패해도 학습 화면을 막거나 오류 메시지를 띄우지 않음.
5. AnkiDroid 로컬 스토리지 설정

Android는 기존처럼 쿠키만으로도 설정을 저장함. 설정 → 고급 → 학습 화면 로컬 스토리지를 켜면 카드 서버 주소가 고정돼 localStorage도 앱을 다시 연 뒤 같은 저장소를 사용할 수 있음.

학습 기록과 기존 한자 확장은 그대로
노트 16,240개·카드 22,402개와 안정 ID는 유지했음. 보충 예문 음성을 더해 전체 미디어는 18,267개이며, 기존 한자 확장은 다시 만들 필요 없음.
