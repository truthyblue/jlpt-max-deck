v1.1.1 HOTFIX

아이폰·아이패드 설정 저장 수정

카드 내용이나 음성 재생 방식은 그대로 두고, 모바일에서 설정과 선택형 익명 통계 상태가 유지되는 방식만 보강함.

1. 쿠키 + localStorage 이중 저장

일부 iPhone·iPad에서는 AnkiMobile 카드 화면의 쿠키 저장이 실패해서 후리가나·해석·자동재생·배속 설정이 앱을 다시 열면 초기화되고, 익명 통계 동의 상태도 유지되지 않을 수 있었음. v1.1.1부터 같은 값을 쿠키와 localStorage에 함께 저장함.

기존 값도 자동으로 이어받음

유효한 쿠키가 있으면 먼저 사용해 localStorage에 복제하고, 쿠키를 쓸 수 없으면 localStorage에서 복원함. 둘 중 하나만 작동해도 설정을 저장할 수 있음.

2. AnkiDroid 설정

Android는 기존처럼 쿠키만으로도 저장됨. 아래 옵션을 켜면 카드 서버 주소가 고정돼 localStorage도 앱 재시작 뒤 유지됨.

설정 → 고급 → 학습 화면 로컬 스토리지

3. 음성 재생은 그대로

1배속 혼합 재생, 다른 앱 음악과의 동시 재생, 배속 재생과 덕킹 동작은 건드리지 않았음. 노트 16,240개·카드 22,402개·미디어 18,167개와 안정 ID도 v1.1.0 그대로임.
