v1.1.1 HOTFIX

모바일 설정·음성 재생 안정화

카드 내용과 학습 기록은 그대로 두고, 설정 저장·아이폰 음성·새 버전 안내를 보강함.

1. 쿠키 + localStorage 이중 저장

일부 iPhone·iPad에서는 AnkiMobile 카드 화면의 쿠키 저장이 실패해서 후리가나·해석·자동재생·배속 설정이 앱을 다시 열면 초기화되고, 익명 통계 동의 상태도 유지되지 않을 수 있었음. v1.1.1부터 같은 값을 쿠키와 localStorage에 함께 저장함.

기존 값도 자동으로 이어받음

유효한 쿠키가 있으면 먼저 사용해 localStorage에 복제하고, 쿠키를 쓸 수 없으면 localStorage에서 복원함. 둘 중 하나만 작동해도 설정을 저장할 수 있음.

2. 아이폰·아이패드 음성 재생 수정

AnkiMobile에서는 ambient 오디오 세션을 요청한 뒤 HTML 오디오 요소를 직접 재생함. Web Audio의 fetch·decode 경로를 거치지 않고, 자동재생·직접 재생·배속에 같은 종료와 취소 규칙을 적용함.

3. 새 버전 안내 보강

카드 답면에서 새 버전을 알려 주고 업데이트 가이드로 바로 이동할 수 있음. 당장 업데이트하기 어렵다면 7일간 숨기기를 누르거나, 해당 버전 알림 다시 보지 않기를 선택할 수 있음.

4. AnkiDroid 설정

Android는 기존처럼 쿠키만으로도 저장됨. 아래 옵션을 켜면 카드 서버 주소가 고정돼 localStorage도 앱 재시작 뒤 유지됨.

설정 → 고급 → 학습 화면 로컬 스토리지
