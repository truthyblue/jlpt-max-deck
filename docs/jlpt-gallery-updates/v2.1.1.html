JLPT MAX DECK v2.1.1
어휘 9,160개
뜻·예문 전수 재검토

뜻 또는 예문이 달라지는 2,963개를 고치고, 각 뜻에 맞는 대표 예문을 연결했음. 실제로 공부하는 어휘는 9,159개, 예문은 10,997개임.

2.1.0의 어휘·화면 개선과 2.1.1의 한자 생성·문법 후리가나 수정을 한 번에 안내함. 지금 받는 파일은 2.1.1임.

뜻 사이에 빠져 있던 구분점도 수정

최근 추가한 3천여 어휘 중 일부에서 뜻 사이의 가운데점(·)이 빠져, 여러 뜻이 하나의 표현처럼 붙어 보이던 문제를 고쳤음. 뜻을 다시 검토하면서 같은 쓰임의 표현은 ·로, 따로 외워야 하는 용법은 /로 구분했음.

덜어낼 것은 덜고, 필요한 뜻은 남기고

뜻을 많이 넣는 것보다 외우기 좋은 크기로 정리하는 데 집중했음. 한 표현으로 충분하면 줄이고, 같은 쓰임은 ·로 묶고, 따로 알아야 하는 용법은 /로 나눴음. 기본적이고 자주 쓰는 뜻을 먼저 배치했음.

  • 뜻이 달라진 어휘 2,662개
  • 예문 또는 루비가 달라진 어휘 2,397개
  • 각 뜻에 맞춘 대표 예문 10,997개

아래는 기존 뜻과 v2.1.0에서 정리한 뜻의 비교임. 화면은 v2.1.0 카드 미리보기임.

1. 겹치는 뜻은 짧게

한국어 ‘넘다’로 산을 넘는 것과 수치를 넘는 것을 함께 떠올릴 수 있어 중복된 번역을 덜었음. 뜻을 무조건 늘린 게 아니라, 한 표현으로 충분한 것은 짧게 정리했음.

越える
전: 넘다 / 초과하다
후: 넘다
越える · 넘다

이런 표현도 짧게 줄였음.

  • 繰り返し: 반복 / 거듭 → 반복
  • 重なる: 겹치다 / 거듭되다 → 겹치다
  • 値する: ~할 가치가 있다 · ~할 만하다 → ~할 가치가 있다
2. 같은 쓰임은 한 묶음으로

안개가 짙은 것과 맛이 진한 것은 농도가 높은 같은 이미지로 묶었음. 한국어 표현은 둘 다 남기되, 따로 외울 뜻처럼 나누지는 않았음.

濃い
전: (색·안개가) 짙다 / (맛·농도가) 진하다
후: 짙다 · 진하다
濃い · 짙다 · 진하다
3. 다른 용법은 따로

책상을 치거나 문을 두드리는 것은 한 묶음. 누군가를 비판하는 용법은 따로 두었음. 각 표현에 맞는 예문도 함께 볼 수 있음.

叩く
전: 두드리다 / 비판하다
후: 치다 · 두드리다 / 비판하다
叩く · 치다 · 두드리다 / 비판하다
4. 막연한 뜻에는 사용 조건

‘나다’가 무엇을 말하는지 괄호로 밝혔음. ‘물로 하다’처럼 선택을 정하는 용법에는 Nにする라는 문형도 붙였음.

する
전: 하다 / 나다
후: 하다 / (냄새나 소리가) 나다 / ~로 하다(Nにする)
する · 하다 / (냄새나 소리가) 나다 / ~로 하다(Nにする)
5. 빠진 주요 뜻은 보완

‘씨’만으로는 떠올리기 어려운 다툼의 원인, 소설의 소재 같은 쓰임을 보완했음. 새로 넣은 뜻에는 그 뜻을 보여주는 예문을 붙였음.

種
전: 씨
후: 씨 / 원인 / 소재 · 이야깃거리
種 · 씨 / 원인 / 소재 · 이야깃거리
2.0.3에서 불편했던 화면도 수정

문법 후리가나, 모바일 학습 기록과 한자 필기를 다듬었음. 달라지지 않은 화면은 v2.1.0 미리보기를 사용했고, 문법 후리가나는 v2.1.1 화면으로 교체했음. 학습 기록·순위·필기는 설명용 예시임.

iPhone·iPad 문법 후리가나 표시 수정

iPhone·iPad에서 문법 카드 후리가나가 한자 위가 아니라 본문 옆에 나란히 표시되던 문제를 고쳤음. 기본 문법 카드의 예문·비교 문형까지 함께 바로잡았음.

기본 문법 답안 · 최종 2.1.1 카드 미리보기
JLPT 목표를 처음부터 쉽게

JLPT 목표를 처음 정하거나 바꿀 때 N1~N5 중 원하는 급수를 바로 고를 수 있도록 선택 화면을 정리했음.

급수를 고르기 전 · 예시 기록
연결이 끊겨도 다시 고를 수 있게

연결 문제로 목표 설정을 마치지 못했을 때 상태를 알리고 다시 시도할 수 있도록 했음. 연결이 끊겨도 기기에 저장된 학습 기록은 계속 볼 수 있음.

오프라인 목표 선택 안내 · 예시 기록
연속 학습 보호가 뭔지 한눈에

보호가 언제 쓰이는지, 몇 개 남았는지, 다음 보호까지 며칠 필요한지를 한 화면에 모았음.

연속 학습·보호 상세 · 예시 기록
Android 분석 기록 표시 수정

2.0.3에서 Android의 기간별·영역별·급수별 분석 기록이 일부 빠져 보일 수 있던 문제를 고쳤음. 보고 싶은 기록과 기간을 고르는 탭도 알아보기 쉽게 정리했음.

분석 화면을 아래로 스크롤한 모습 · 예시 기록
오류 제보도 더 분명하게

문제를 어떻게 설명할지 막막하지 않도록 유형별 작성 예시를 넣고, 기능 제안 항목을 추가했음. 보내기 전에 함께 전송되는 정보도 확인할 수 있음.

의견 보내기 화면 · 입력 예시이며 실제로 전송하지 않음
새 버전 안내에서 바로 다운로드

이제 카드의 새 버전 안내에서 기본 덱을 바로 받을 수 있음. 기존 학습 기록을 유지하려면 어떤 가져오기 옵션을 골라야 하는지도 함께 안내함.

새 업데이트 안내 화면 · 버전 전환 예시
필요한 안내를 순서대로

업데이트 후에는 필요한 카드 정리와 내 기록 시작 방법을 차례로 안내함. 지금 해야 할 일을 하나씩 확인할 수 있음.

내 기록 시작 안내
한자 앞면은 문제에 집중

한자 문제를 풀 때 필요하지 않은 표시 설정을 앞면에서 빼고, 학습 현황과 문제에 집중할 수 있도록 했음.

한자 카드 앞면
한자 쓰기와 획순 보기

iPad에서 Apple Pencil로 빠르게 쓸 때 획이 끊기거나 빠지던 문제를 고쳤음. 획순 자료 때문에 카드가 처음 열릴 때 생기던 부담도 줄였음.

쓰기 카드 · 브라우저에서 입력한 필기 예시
한자 카드 뒷면의 쓰기 연습 · 획순 불러오기
좁은 화면에서도 한자 읽기 편하게

좁은 화면에서 비슷한 한자의 읽기가 한 글자씩 세로로 끊겨 보이던 문제를 고쳤음. 음독·훈독을 구분하면서 읽을 수 있도록 표시 공간을 넓혔음.

한자 뒷면 · 비슷한 한자의 읽기 배치
한자 빌더도 함께 수정

2.1.0에서 한자 뜻의 낱말 중간에 들어가던 불필요한 공백을 고쳤고, 2.1.1에서는 한자 확인 오류로 덱 생성이 멈추던 문제도 고쳤음. 새로 만들거나 생성에 실패했던 사람은 2.1.1 빌더를 사용하면 됨. 이미 2.1.0 한자 덱을 정상적으로 만든 사람은 다시 만들 필요 없음.
