# JLPT MAX Deck v1.2.0 업데이트

이번 버전은 **기존 노트 업데이트를 반드시 `항상`으로 선택해야 하는 마이너
업데이트**입니다. 먼저 모든 기기에서 동기화하거나 백업한 뒤, 기존 덱을 삭제하지
말고 `JLPT-MAX-Deck-1.2.0.apkg`를 가져오세요.

- 학습 진행 상태 가져오기: **끄기**
- 기존 노트 업데이트: **항상**
- 노트 유형 병합: **켜기**
- 가져온 뒤: **모든 기기 전체 동기화**

출발 버전별로 보면 다음과 같습니다.

| 지금 사용하는 버전 | 기존 노트 업데이트 | 이유 |
| --- | --- | --- |
| v1.1.x | **항상** | 고저 악센트 필드와 새 카드 템플릿을 적용합니다. |
| v1.0.x | **항상** | v1.1.x의 뜻·예문 변경과 v1.2.0의 새 필드를 함께 적용합니다. |

## 주요 변경

1. 어휘 6,018개와 예문 7,065개에 고저 악센트 선을 추가했습니다. 설정에서 끌 수
   있습니다.
2. 일본어 글꼴을 명조·고딕 중에서 고를 수 있고, 후리가나·해석·자동재생·배속을
   같은 설정 패널에서 조절할 수 있습니다.
3. 새 카드가 복습 카드 뒤에 몰리지 않고 복습 사이에 섞여 나오도록 기본값을
   바꿨습니다.
4. 좁은 모바일 화면의 오류 제보·사용 통계 팝업과 한자 펼치기 동작을 다듬었습니다.
5. 학습자 뜻 표시 249개를 고치고 예문 182개를 추가했습니다.

![v1.1.1과 v1.2.0의 모바일 카드 설정 및 고저 악센트 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/gallery-v1.2.0-pitch-settings.webp)

- [v1.2.0 전체 릴리스 노트](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/releases/v1.2.0.md)
- [v1.2.0 다운로드](https://github.com/truthyblue/jlpt-max-deck/releases/tag/v1.2.0)

기존 한자 확장은 다시 만들지 않아도 계속 사용할 수 있습니다. 한자 카드에도 새
일본어 글꼴 설정과 최신 연결 어휘 표시를 반영하고 싶을 때만 v1.2.0 빌더로 다시
만들어 같은 가져오기 옵션을 적용해 주세요. 기존 GUID와 학습 기록·스케줄은
유지됩니다.
