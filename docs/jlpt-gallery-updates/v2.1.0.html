v2.0.3 사용자 필수 작업
기존 덱을 지우지 말고 업데이트
  1. 모든 기기를 AnkiWeb과 동기화하고 백업
  2. v2.1.0 기본 APKG를 기존 덱 위에 가져오기
  3. 학습 진행 상태는 끄기, 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기
  4. 가져온 뒤 Anki의 빈 카드 도구에서 笠 카드 3장 삭제
  5. 한자 덱을 쓰면 v2.1.0 한자 빌더로 다시 만들기
  6. 모든 기기에서 다시 전체 동기화

笠는 같은 한자를 이미 가르치는 카드와 겹쳐 단독 어휘 카드만 정리했음. 카드 탐색기에서 노트를 직접 지우지 말고 빈 카드 메뉴를 사용하면 됨.
