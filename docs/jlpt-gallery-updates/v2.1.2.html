일본어 맥스 덱 업데이트 — 음성·기록 오류 수정

이번에는 단어 음성과 제보받은 오류 위주로 정리했음.

  • 단어 음성의 속도와 리듬을 통일하고 끝소리와 악센트를 다듬었음.
  • 일부 문법의 읽기와 문제 해설을 수정했음. 코레 단어의 악센트 표시도 평판형으로 바로잡았음.
  • 학습 기록 중복 집계, 카드 전환 중 기록이 덮이는 문제, 동기화 재시도와 목표 저장 처리를 수정했음.
  • 안드로이드는 상세 분석을 열 때 서버에서 불러오도록 변경했음. 분석은 인터넷 연결이 필요하고, 오늘 학습량과 연속 학습 기록은 기기에 유지함. 아이폰과 아이패드는 기존 방식 그대로임.
  • 한자 쓰기 조작과 함께 익힐 글자 표시를 다듬고 빠진 획순 자료를 보완했음.

기존 사용자는 덱을 지우지 말고 동기화와 백업 후 새 파일을 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 설정하면 됨. 한자 덱도 새 생성 도구로 다시 만들어 가져와야 함.
