모바일 내 기록
오늘·습관·분석·JLPT를 한 화면에

AnkiMobile·AnkiDroid 답안 화면에서 동의한 사용자라면 오늘 공부한 흐름을 이어서 확인할 수 있음. 오늘 숫자 하나만 보여 주는 기능이 아니라 최신·분석·이력, 목표 급수와 100일 랭킹까지 이어지는 개인 학습 기록임.

오늘 · 습관

답안 화면 확인 횟수를 세고 20회가 되면 오늘 학습 완료로 표시함. 20회는 20개 단어를 외웠다는 뜻이 아니라 하루 학습 세션을 진행했다는 기준임. 실제 완료일로 연속 학습을 이어 보여 주고, 7일 실제 완료마다 보호 1개를 충전함. 보호는 최대 2개까지 모을 수 있음.

최신 · 분석

최신에서 이번 주 현황·최근 7일 흐름·이번 달 참고 순위·학습 달력을 확인함. 분석에서는 최근 7일·30일·3개월·1년·전체 흐름과 영역·급수·학습 유형별 구성을 보고, 일간·주간·월간 개인 최고와 최장 연속 학습을 돌아봄.

JLPT 목표 · 100일

목표 급수와 다음 공식 시험 D-day를 정함. D-100부터 같은 급수의 100일 랭킹에서 학습량과 꾸준함을 비교하고, D-50 중간 결산·시험일 종료·결과 확인·다음 목표까지 이어짐.

이벤트 · 이력

오늘 학습 완료, 어제 기록 추월, 7·30·100·365일 연속 학습, 보호 사용·충전, 개인 최고, 100일 랭킹 시작·중간 결산을 한 번씩 알려 줌. 이력에서는 지난 랭킹과 개인 기록을 다시 확인함.

기록은 먼저 기기에 저장함. 인터넷 연결이 없어도 오늘 상태와 학습 흐름을 볼 수 있음.

처음 안내에서 내 기록 시작하기를 눌렀을 때만 기록을 시작함. 사용하지 않기를 골라도 덱 학습은 계속되고 다시 자동으로 묻지 않음. 카드 내용·정답 여부·답 버튼 선택·복습 이력·학습 시간·실제 JLPT 결과·응시 여부·JLPT 계정 정보는 수집하지 않음. 기기 간 동기화는 서비스 준비가 끝난 뒤 제공함.
