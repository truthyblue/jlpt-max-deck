2. 학습자 뜻 249개와 예문 182개 보강

뜻 표시 249개를 실제 쓰임이 더 잘 드러나도록 다듬고, 새로 구분한 뜻을 대표하는 예문 182개를 추가해 전체 검토 예문은 6,883개에서 7,065개가 됐음. 기존 예문 3건도 교정했고, 신고된 실전 문제·문장과 変わる의 ‘특이하다’ 예문, 持つ의 ‘오래가다’ 품사, 六本 발음도 함께 바로잡았음.

3. 일본어 글꼴과 카드 설정을 한곳에서

카드에 일본어용 명조·고딕 글꼴을 함께 넣어 기기마다 자형이 달라지는 일을 줄였음. 일본어 본문 글꼴과 후리가나·해석·고저 악센트·자동재생 범위·배속을 같은 설정 패널에서 조절하고, 자주 쓰는 항목은 카드 상단에서도 바로 켜고 끌 수 있음.

기본 덱과 선택형 한자 확장에 같은 설정
어휘·음성·실전 문제·참조표·한자 카드에서 같은 일본어 글꼴 설정을 공유함. 기존 한자 확장은 그대로 쓸 수 있고, 새 글꼴을 적용하고 싶을 때만 다시 만들면 됨.
CONTEXT HINTS
4. 같은 표기의 다른 뜻은 문맥으로 구분

앞면만 보고는 어떤 뜻을 묻는지 알기 어려웠던 そば·開く·避ける·紅葉·なる 5개 표제어의 10개 카드에 짧은 빈칸 문맥을 넣었음. 답을 노출하지 않으면서도 이번 카드가 묻는 읽기와 뜻을 구분할 수 있음.

전체 문장을 미리 보여 주는 대신 답이 드러나지 않는 짧은 문맥을 표시
MOBILE DIALOGS
5. 오류 제보·익명 통계 팝업을 작은 화면에서도 온전히

좁은 모바일 화면에서도 팝업의 제목과 닫기 버튼, 아래쪽 동작 버튼이 잘리지 않도록 safe-area와 시작 위치를 보정했음. 익명 사용 통계는 지금처럼 모바일에서 직접 동의한 경우에만 전송하며, 업데이트 안내 표시·선택 이벤트가 포함된다는 설명도 투명하게 추가했음.

320px 너비에서도 처음부터 온전히 보이는 오류 제보 팝업
전송 항목을 읽고 동의 여부를 고를 수 있는 익명 통계 안내
6. 새 카드는 복습 사이에 섞어서

새 카드가 복습 카드 뒤에 한꺼번에 몰리지 않고 복습 사이에 섞여 나오도록 기본 preset을 바꿨음. 기존 preset ID와 지금까지의 학습 기록·스케줄은 그대로 유지됨.

기존 덱에서 v1.2.0으로 업데이트하기

모든 기기를 먼저 동기화하거나 백업한 뒤, 기존 덱을 삭제하지 말고 v1.2.0 기본 덱을 가져오면 됨. v1.1.x와 v1.0.x 모두 아래 옵션을 사용함.

학습 진행 상태 가져오기: 끄기
기존 노트 업데이트: 항상
노트 유형 병합: 켜기
가져온 뒤: 모든 기기 전체 동기화
직접 수정한 공식 노트 필드는 먼저 백업
항상을 선택하면 직접 고친 뜻·예문도 v1.2.0 공식 내용으로 바뀔 수 있음. v1.1.x에서는 고저 악센트 필드와 새 카드 템플릿을, v1.0.x에서는 그 사이의 뜻·예문 변경까지 함께 적용하기 위해 이번에는 모두 항상을 사용함.
기존 한자 확장은 다시 만들 필요 없음
그대로 계속 사용할 수 있음. 한자 카드에도 새 일본어 글꼴 설정과 최신 연결 어휘 표시를 반영하고 싶을 때만 v1.2.0 빌더로 선택적으로 다시 만들면 됨.
업데이트 뒤 남은 예전 음성은 미디어 검사로 정리
교체된 음성의 예전 파일이 미사용 상태로 남을 수 있음. 새 카드와 음성이 잘 나오는지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki의 도구 → 미디어 검사에서 미사용 파일 목록을 확인해 삭제하고 다시 동기화하면 됨. 다른 덱의 미사용 파일도 함께 잡힐 수 있으니 목록을 보고 지워야 하며, 삭제한 파일은 운영체제 휴지통에서 복구할 수 있음.
