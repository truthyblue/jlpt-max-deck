JLPT MAX Deck · v1.2.0
소리의 높낮이는 눈에 보이게,
카드 설정은 더 편하게.

어휘 6,018개와 예문 7,065개에 고저 악센트 선을 추가했음. 일본어 글꼴과 고저 악센트 표시를 카드 설정에서 바로 바꿀 수 있고, 뜻 249개와 예문 182개도 함께 보강했음.

PITCH ACCENT & CARD SETTINGS
1. 어휘·예문 고저 악센트 + 일본어 글꼴 설정

단어와 예문을 읽을 때 음의 높낮이를 선으로 확인할 수 있음. 필요하지 않으면 설정에서 끌 수 있고, 일본어 본문 글꼴도 명조와 고딕 중에서 선택할 수 있음. 후리가나·해석·자동재생·배속도 같은 패널에서 조절함.

v1.1.1 설정 화면과 v1.2.0 고저 악센트·일본어 글꼴 설정 비교
2. 새 카드는 복습 사이에 섞어서

새 카드가 복습 카드 뒤에 한꺼번에 몰리지 않고 복습 사이에 섞여 나오도록 기본 preset을 바꿨음. 기존 preset ID와 지금까지의 학습 기록·스케줄은 그대로 유지됨.

모바일 카드 조작도 함께 안정화
좁은 화면에서 오류 제보·사용 통계 팝업이 잘리지 않게 고쳤고, 한자 정보 펼치기가 iPhone·iPad와 Android에서 같은 버튼 상태로 열리고 닫히게 했음.

3. 학습자 뜻 249개와 예문 182개 보강

뜻 표시 249개를 실제 쓰임이 더 잘 드러나도록 다듬고, 새로 구분한 뜻을 대표하는 예문 182개를 추가해 전체 검토 예문은 6,883개에서 7,065개가 됐음.

전체 목록은 GitHub에서 따로 확인
공지에는 대표 변경만 적었음. 단어별 뜻 변경 전·후, 독립 뜻 분리·통합 23개, 문구 수정 226개와 새 예문 182개 전체는 아래 상세 패치노트에 정리했음.

기존 덱에서 v1.2.0으로 업데이트하기

모든 기기를 먼저 동기화하거나 백업한 뒤, 기존 덱을 삭제하지 말고 v1.2.0 기본 덱을 가져오면 됨. v1.1.x와 v1.0.x 모두 아래 옵션을 사용함.

학습 진행 상태 가져오기: 끄기
기존 노트 업데이트: 항상
노트 유형 병합: 켜기
가져온 뒤: 모든 기기 전체 동기화
직접 수정한 공식 노트 필드는 먼저 백업
항상을 선택하면 직접 고친 뜻·예문도 v1.2.0 공식 내용으로 바뀔 수 있음. v1.1.x에서는 고저 악센트 필드와 새 카드 템플릿을, v1.0.x에서는 그 사이의 뜻·예문 변경까지 함께 적용하기 위해 이번에는 모두 항상을 사용함.
기존 한자 확장은 다시 만들 필요 없음
그대로 계속 사용할 수 있음. 한자 카드에도 새 일본어 글꼴 설정과 최신 연결 어휘 표시를 반영하고 싶을 때만 v1.2.0 빌더로 선택적으로 다시 만들면 됨.
업데이트 뒤 남은 예전 음성은 미디어 검사로 정리
교체된 음성의 예전 파일이 미사용 상태로 남을 수 있음. 새 카드와 음성이 잘 나오는지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki의 도구 → 미디어 검사에서 미사용 파일 목록을 확인해 삭제하고 다시 동기화하면 됨. 다른 덱의 미사용 파일도 함께 잡힐 수 있으니 목록을 보고 지워야 하며, 삭제한 파일은 운영체제 휴지통에서 복구할 수 있음.
