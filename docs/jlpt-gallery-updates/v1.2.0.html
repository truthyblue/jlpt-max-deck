3. 일본어 글꼴과 카드 설정을 한곳에서

카드에 일본어용 명조·고딕 글꼴을 함께 넣어 기기마다 자형이 달라지는 일을 줄였음. 일본어 본문 글꼴과 후리가나·해석·고저 악센트·자동재생 범위·배속을 같은 설정 패널에서 조절하고, 자주 쓰는 항목은 카드 상단에서도 바로 켜고 끌 수 있음.

설정 패널만 잘라 비교한 일본어 글꼴·고저 악센트·재생 범위 설정
기본 덱과 선택형 한자 확장에 같은 설정
어휘·음성·실전 문제·참조표·한자 카드에서 같은 일본어 글꼴 설정을 공유함. 한자 확장도 v1.2.0 빌더로 다시 만들면 새 글꼴과 최신 연결 어휘가 함께 적용됨.

4. 한자 펼침과 이미지 표시 수정

어휘 카드의 한자 버튼을 Anki WebView에서 직접 제어하는 방식으로 바꿔 모바일에서도 펼침·접힘 상태가 정확히 동작함. 다크 모드 대비 보정은 v1.1.0 한자 빌더부터 적용됐으며, v1.2.0은 Windows Anki의 이미지 표시 경로에 맞춰 한자 14자를 원본부터 빌더 출력까지 투명한 path-only SVG로 통일했음.

오류 제보 반영
한자 보이기·감추기 버튼은 v1.2.0 카드에 반영했고, 한자 이미지 제보는 Windows 동작까지 다시 확인해 SVG 경로를 보강했음. 투명 SVG는 v1.2.0 한자 빌더로 다시 만들면 적용됨.

5. 같은 표기의 다른 뜻은 문맥으로 구분

앞면만 보고는 어떤 뜻을 묻는지 알기 어려웠던 そば·開く·避ける·紅葉·なる 5개 표제어의 10개 카드에 짧은 빈칸 문맥을 넣었음. 답을 노출하지 않으면서도 이번 카드가 묻는 읽기와 뜻을 구분할 수 있음.

전체 문장을 미리 보여 주는 대신 답이 드러나지 않는 짧은 문맥을 표시

6. 오류 제보·익명 통계 팝업을 작은 화면에서도 온전히

좁은 모바일 화면에서도 팝업의 제목과 닫기 버튼, 아래쪽 동작 버튼이 잘리지 않도록 safe-area와 시작 위치를 보정했음. 익명 사용 통계는 지금처럼 모바일에서 직접 동의한 경우에만 전송하며, 업데이트 안내 표시·선택 이벤트가 포함된다는 설명도 투명하게 추가했음.

320px 너비에서도 처음부터 온전히 보이는 오류 제보 팝업
전송 항목을 읽고 동의 여부를 고를 수 있는 익명 통계 안내
UPDATE NOTICE
7. 업데이트 알림 닫기 상태 저장 수정

7일간 숨기기와 이 버전 알림 다시 보지 않기는 v1.1.1부터 제공됐음. 일부 Anki 환경에서는 쿠키와 localStorage가 서로 다른 상태를 읽어 닫은 알림이 다시 나타났음. v1.2.0은 두 저장소를 동기화하고, ×는 이번 학습, 7일간 숨기기는 7일, 이 버전 알림 다시 보지 않기는 해당 버전 전체에 각각 적용되도록 고쳤음.

×·7일간 숨기기·해당 버전 다시 보지 않기를 구분해 선택하는 실제 카드 UI. 버전 숫자는 알림 대상에 맞춰 자동으로 바뀜.
8. 새 카드는 복습 사이에 섞어서

새 카드가 복습 카드 뒤에 한꺼번에 몰리지 않고 복습 사이에 섞여 나오도록 기본 preset을 바꿨음. 기존 preset ID와 지금까지의 학습 기록·스케줄은 그대로 유지됨.

익명 통계로 보는 현재 이용 현황

집계 기준은 사용 통계 공유에 동의한 모바일 설치임. 활성 설치는 업데이트 이후 학습한 무작위 설치 ID 수이고, 학습 횟수는 답안 화면 표시 횟수임. 플랫폼·덱 버전·학습 영역·JLPT 급수별 집계를 함께 보여 줌.

업데이트 이후 익명 이용 현황
덱 개선에 도움을 주고 싶다면
모바일 답안 아래 익명 통계 → 사용 통계 공유하기에서 언제든 켜고 끌 수 있음. 오류 제보는 모바일 카드의 오류 제보 버튼에서 보낼 수 있음.

이번 릴리스 공지에는 요약만 싣고, 버전 전환·일별 이용 추이·설치별 학습 횟수·학습 구성은 별도 통계 글로 공유할 예정임.

기존 덱에서 v1.2.0으로 업데이트하기

모든 기기를 먼저 동기화하거나 백업한 뒤, 기존 덱을 삭제하지 말고 v1.2.0 기본 덱을 가져오면 됨. v1.1.x와 v1.0.x 모두 아래 옵션을 사용함.

학습 진행 상태 가져오기: 끄기
기존 노트 업데이트: 항상
노트 유형 병합: 켜기
가져온 뒤: 모든 기기 전체 동기화
직접 수정한 공식 노트 필드는 먼저 백업
항상을 선택하면 직접 고친 뜻·예문도 v1.2.0 공식 내용으로 바뀔 수 있음. v1.1.x에서는 고저 악센트 필드와 새 카드 템플릿을, v1.0.x에서는 그 사이의 뜻·예문 변경까지 함께 적용하기 위해 이번에는 모두 항상을 사용함.
한자 확장도 v1.2.0 빌더로 다시 만들기
한자 확장을 다시 만들면 Windows Anki 야간 모드용 투명 SVG 렌더링과 새 일본어 글꼴, 최신 연결 어휘 표시가 함께 적용됨.
업데이트 뒤 남은 예전 음성은 미디어 검사로 정리
교체된 음성의 예전 파일이 미사용 상태로 남을 수 있음. 새 카드와 음성이 잘 나오는지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 데스크톱 Anki의 도구 → 미디어 검사에서 미사용 파일 목록을 확인해 삭제하고 다시 동기화하면 됨. 다른 덱의 미사용 파일도 함께 잡힐 수 있으니 목록을 보고 지워야 하며, 삭제한 파일은 운영체제 휴지통에서 복구할 수 있음.
