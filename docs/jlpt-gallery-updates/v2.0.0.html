각 급수 안에서 중요한 단어부터

BCCWJ라는 일본어 균형 말뭉치의 사용 빈도를 새 카드 순서에 연결했음. 같은 표기로 바로 연결된 8,172개, 표기 변형·구성 요소 등을 검토해 연결한 934개, 말뭉치에서 찾지 못한 54개까지 전부 포함함.
