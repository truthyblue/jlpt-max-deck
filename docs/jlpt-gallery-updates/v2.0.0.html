한국어→일본어 카드 9,160장

한국어 뜻과 예문을 보고 일본어 표기와 읽기를 떠올리는 카드가 모든 어휘에 하나씩 생김. 기존 어휘·음성 카드 일정은 그대로고 이 카드는 새 학습 항목으로 시작함.

실제 한국어→일본어 회상 답면
각 급수 안에서 중요한 단어부터

BCCWJ라는 일본어 균형 말뭉치의 사용 빈도를 새 카드 순서에 연결했음. 같은 표기로 바로 연결된 8,172개, 표기 변형·구성 요소 등을 검토해 연결한 934개, 말뭉치에서 찾지 못한 54개까지 전부 포함함.

한자 획순을 원하는 구간부터
  • 일시정지, 이전 획, 다음 획, 처음부터
  • 느리게·보통·빠르게 속도 변경
  • 전체 획 개요에서 원하는 구간 다시 재생
  • 한자 구성 요소와 외부 참고 링크 추가

기존 한자 읽기·쓰기 카드 ID와 학습 기록은 유지됨.
