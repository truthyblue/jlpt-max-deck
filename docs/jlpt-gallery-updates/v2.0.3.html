JLPT MAX DECK v2.0.3
내 기록 자동 복구
목표 카드·공지 화면 수정

동기화 경고가 잘못 남거나 JLPT 목표 카드가 흰색으로 보이던 흐름을 고치고, 개인 최고 기록 알림과 문법 카드 공지 화면을 다듬었음.

내 기록을 한 번 더 자동 복구

기기에 기록이 남아 있는데 서버 응답이 잠깐 비어 있으면 바로 실패로 끝내지 않고 기록과 JLPT 목표를 다시 확인함.

  • 잠깐 연결이 불안정하면 한 번 자동 재시도
  • 일반 연결 오류와 실제 기록 복구 실패를 구분
  • 목표 급수만 먼저 도착해도 초록색 JLPT 목표 카드 유지
  • 상단에 잘못 남던 동기화하지 못했어요 경고 감소
실제 AnkiDroid · 복구된 JLPT N1 목표와 최근 학습 기록
학습 화면
알림은 하루 한 번, 카드 가운데에
  • 하루 개인 최고 기록 알림은 같은 날 한 번만 표시
  • 카드 가운데에 띄워 답안 버튼과 겹치지 않게 수정
  • 문법 카드 공지도 어두운 배경·둥근 창·큰 버튼 스타일 적용
v2.0.2 사용자
기존 덱을 지우지 말고 v2.0.3으로 업데이트

모든 기기를 AnkiWeb과 동기화하고 백업한 뒤 v2.0.3 기본 APKG를 기존 덱 위에 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 선택.

한자 확장을 쓰면 v2.0.3 한자 빌더 ZIP으로 다시 만들어 가져오고, 기본 덱만 쓰면 빌더는 필요 없음.

확인한 범위
  • 새 설치와 v2.0.2 위 업데이트
  • 기존 학습 상태 보존
  • Android 16 AnkiDroid에서 25,324노트 덮어쓰기
  • 문법 카드 공지 화면과 내 기록의 JLPT 목표 카드
v2.0.3 다운로드
