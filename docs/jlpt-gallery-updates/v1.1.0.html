JLPT MAX Deck · v1.1.0
실제로 쓰이는 덱을 더 잘 지원할 수 있게
선택형 사용 통계를 추가했음.

모바일에서 동의한 경우에만 최소한의 사용 현황을 공유함. 어휘 답안 도구도 작게 정리했고, 학습 콘텐츠와 기존 카드·학습 기록은 그대로임.

1. 동의하기 전에는 아무 통계도 보내지 않음

AnkiMobile과 AnkiDroid에서 답안을 10번 확인한 뒤 처음 한 번만 물어봄. 사용 통계 공유하기를 누르기 전에는 전송도, 앞선 학습의 소급 집계도 하지 않음. 공유하지 않기를 누르면 자동으로 다시 묻지 않음.

언제든 끌 수 있음
답안 화면 아래의 사용 통계 설정에서 끄면 설치 ID와 아직 전송하지 않은 기록을 지우고 이후 전송을 중단함.

팝업 아래의 오류 제보하기는 GitHub 오류 양식만 열고 동의 상태는 바꾸지 않음.

카드 설정과 통계 상태는 WebView 쿠키에 저장함. Android 앱을 다시 열어 카드 포트가 바뀌어도 유지되고, 기기에는 오늘과 직전 학습일 최대 이틀치만 남김.

2. 보내는 정보는 이 정도
  • 같은 모바일 설치의 중복 집계를 막는 무작위 설치 ID
  • iOS 또는 Android 구분
  • JLPT MAX 버전과 학습한 세부 덱
  • 세부 덱마다 날짜별로 답안을 확인한 누적 횟수

카드·단어 ID와 내용, 정답·평점·복습 이력, Anki 계정·프로필, 이름·이메일, 다른 덱 정보, 기기 모델과 상세 앱·OS 버전은 보내지 않음. 날짜별 원본은 90일 뒤 삭제함.

3. 어디에 쓰나

다운로드 수 대신 실제로 관측된 모바일 설치 규모와 버전별 사용 현황을 보고, 구버전 지원 기간과 AnkiMobile·AnkiDroid 호환성 점검 순서를 정하는 데 씀. 많이 쓰이는 어휘·음성·실전·참조표·한자와 실전 문제 유형도 확인해 보강 순서를 잡을 수 있음.

공개할 때도 전체 사용자 수라고 부풀리지 않고 최근 30일 관측된 동의 기반 활성 모바일 설치 수처럼 범위를 같이 밝힐 예정임. 실제 카드에 들어간 클라이언트 코드는 공개 저장소에서 누구나 확인할 수 있음.

4. Android 야간 모드 한자 표시 개선

일상무따 한자 확장의 일부 이미지 자형이 Android 야간 모드에서 배경과 같이 어둡게 보이던 문제를 고쳤음. 야간 모드에서는 밝게 표시하고 일반 모드 표시는 그대로 유지함. Android에서 한자 확장을 쓴다면 v1.1.0 빌더로 다시 만드는 것을 권장함.

5. 어휘 답안의 한자·사전 도구를 작게 정리

한자 정보와 네이버 사전 링크를 단어 바로 아래의 작은 버튼으로 묶었음. 한자 정보는 필요할 때 펼치고, 여러 한자는 큰 타일 대신 간결한 행으로 표시해 화면을 덜 차지함.

6. 학습 기록과 콘텐츠는 그대로

기본 덱 13,903노트·20,065카드와 안정 ID, 덱 구조, 학습 콘텐츠는 v1.0.3과 같음. 기존 덱을 지우지 말고 v1.1.0을 위에 가져오면 지금까지의 학습 기록을 이어서 쓸 수 있음.

v1.0.3에서 업데이트하기

먼저 Anki를 동기화하거나 백업한 뒤 v1.1.0 기본 덱을 기존 덱 위에 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트 업데이트와 노트 유형 병합은 켜면 됨.
