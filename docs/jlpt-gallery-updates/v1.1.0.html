JLPT MAX Deck · v1.1.0
설정은 한곳에,
음성은 내 속도에 맞게.

v1.0.3의 후리가나·해석·자동재생 설정을 하나로 모으고 0.8·1·1.2·1.5배속을 추가했음. 문제 있는 카드는 답안에서 바로 제보할 수 있고, 어휘 답안과 Android 야간 한자 표시도 다듬었음.

CARD SETTINGS
1. 카드 설정 통합 + 4단계 재생 배속

v1.0.3에서 따로 보이던 후리가나, 예문 해석, 자동재생 설정을 답안 오른쪽 위 설정 하나로 모았음. 어휘 자동재생은 단어만, 첫 예문까지, 모든 예문까지 중에서 고를 수 있음.

새로 추가된 0.8·1·1.2·1.5배속
  • 0.8배: 빠르게 들리는 단어나 예문을 천천히 확인할 때
  • 1배: v1.0.3과 같은 기본 속도로 들을 때
  • 1.2·1.5배: 익숙한 카드를 빠르게 복습할 때

선택한 속도는 자동재생과 직접 누른 음성에 똑같이 적용되고 앱을 다시 열어도 유지됨. 1배속은 다른 앱의 배경 음악과 함께 듣는 기존 재생 방식을 유지함. 0.8·1.2·1.5배속은 기기와 앱에 따라 배경 음악이 줄거나 멈출 수 있어 주의가 필요함.

답안 오른쪽 위 설정 · 후리가나·해석·자동재생·재생 속도
2. 문제 있는 카드에서 바로 오류 제보

모든 플랫폼의 답안 아래에 오류 제보를 추가했음. 내용 오류, 화면·표시 문제, 음성 문제, 기타 중 하나를 고르고 설명을 적으면 현재 카드를 찾는 데 필요한 버전과 내부 식별 정보가 함께 접수됨.

카드 본문, 복습 기록, Anki 계정·프로필, 익명 통계 설치 ID는 보내지 않으며 사용 통계 동의 여부와도 연결하지 않음.

문제 유형을 고르고 설명을 적는 카드 오류 제보 화면
OPTIONAL MOBILE STATS
3. 선택형 모바일 익명 통계 추가

AnkiMobile·AnkiDroid에서 실제로 쓰이는 버전과 학습 영역을 확인해 모바일 호환성 점검과 개선 순서를 정할 수 있도록 선택형 익명 통계 설정을 추가했음.

원할 때만 켜고, 언제든 끌 수 있음
모바일 답안을 10번 확인한 뒤 처음 한 번 선택창이 열림. 공유를 선택해야 그때부터 집계하며, 공유하지 않으면 다시 묻지 않음. 답안 아래 익명 통계에서 나중에 선택을 바꿀 수 있음.

공유 항목은 무작위 설치 ID, iOS·Android 구분, JLPT MAX 버전, 학습한 세부 덱과 날짜별 답안 확인 누적 횟수임. 카드·단어 내용, 정답·평점·복습 이력, Anki 계정·프로필, 이름·이메일, 다른 덱 정보와 기기 모델은 포함하지 않음.

4. 한자·사전 도구는 작게, Android 야간 자형은 밝게

v1.0.3 어휘 답안의 한자 정보와 네이버 사전 링크를 단어 아래의 작은 버튼으로 묶어 예문을 덜 가리게 했음. 여러 한자도 큰 타일 대신 간결한 행으로 표시함. 일상무따 한자 확장의 이미지 자형은 Android 야간 모드에서 밝게 보이도록 고쳤음.

5. 장음과 일부 실전 정답 발음 보정

합성 음성의 장음이 의도한 길이로 들리도록 처리하고, 실전 정답의 문맥이나 표시 기호 때문에 잘못 읽히던 남은 사례를 보정했음. 노트·카드 구조는 바꾸지 않고 해당 음성과 발음 입력만 갱신함.

v1.0.3에서 업데이트하기

먼저 Anki를 동기화하거나 백업한 뒤 v1.1.0 기본 덱을 기존 덱 위에 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트 업데이트와 노트 유형 병합은 켜면 됨.
