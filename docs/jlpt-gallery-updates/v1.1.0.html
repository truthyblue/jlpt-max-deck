JLPT MAX Deck · v1.1.0
카드 설정과 오류 제보를
답안 화면 안에 정리했음.

재생 배속과 인앱 오류 제보를 추가했고, 모바일 사용 통계는 동의한 경우에만 최소 정보로 작동함. 기존 카드 ID와 학습 기록은 그대로 유지됨.

1. 카드 설정을 한곳에 모음

답안 오른쪽 위 설정에서 후리가나·예문 해석·자동재생을 조절함. 어휘 자동재생은 단어만, 첫 예문까지, 모든 예문까지 중에서 고를 수 있음.

0.8·1·1.2·1.5배속
자동재생과 직접 누른 음성에 같은 속도를 적용하고 기기에 저장함. 1배가 아닌 배속은 기기에 따라 다른 앱 음악을 줄이거나 멈출 수 있어 카드 안에 경고를 표시함.
IN-CARD REPORT
2. 문제 있는 카드에서 바로 제보

모든 플랫폼의 답안 아래에 오류 제보가 생김. 내용·표시·음성·기타 중 하나를 고르고 설명을 적으면 현재 카드를 찾는 내부 식별 정보와 함께 접수됨.

카드 본문, 복습 기록, 계정 정보, 사용 통계 설치 ID는 보내지 않고 통계 동의 상태와도 연결하지 않음.

3. 동의하기 전에는 사용 통계를 보내지 않음

AnkiMobile과 AnkiDroid에서 답안을 10번 확인한 뒤 처음 한 번만 물어봄. 사용 통계 공유하기를 누르기 전에는 전송도, 앞선 학습의 소급 집계도 하지 않음. 공유하지 않기를 누르면 자동으로 다시 묻지 않음.

답안 아래의 익명 통계 설정에서 끄면 설치 ID와 아직 전송하지 않은 기록을 지우고 이후 전송을 중단함. 카드 설정과 통계 상태는 WebView 쿠키에 저장함.

SHARED DATA
4. 보내는 사용 통계는 이 정도
  • 같은 모바일 설치의 중복 집계를 줄이는 무작위 설치 ID
  • iOS 또는 Android 구분
  • JLPT MAX 버전과 학습한 세부 덱
  • 세부 덱마다 날짜별로 답안을 확인한 누적 횟수

카드·단어 ID와 내용, 정답·평점·복습 이력, Anki 계정·프로필, 이름·이메일, 다른 덱 정보, 기기 모델과 상세 앱·OS 버전은 보내지 않음. 날짜별 원본은 90일 뒤 삭제함.

5. 한자·사전 도구와 Android 야간 모드 개선

어휘 답안의 한자 정보와 사전 링크를 단어 아래의 작은 버튼으로 묶었음. 여러 한자는 큰 타일 대신 간결한 행으로 표시함. 일상무따 한자 확장의 이미지 자형은 Android 야간 모드에서 밝게 보이도록 고쳤음.

6. 일부 음성 발음 보정

합성 음성의 장음 처리와 실전 정답의 문맥·표식 때문에 잘못 읽히던 남은 사례를 보정했음. 노트·카드 구조를 바꾸지 않고 해당 음성과 발음 입력만 갱신함.

7. 기존 학습 기록은 그대로

기본 덱 13,903노트·20,065카드와 안정 ID, 덱 구조는 v1.0.3과 같음. 기존 덱을 지우지 말고 v1.1.0을 위에 가져오면 지금까지의 학습 기록을 이어서 쓸 수 있음.

v1.0.3에서 업데이트하기

먼저 Anki를 동기화하거나 백업한 뒤 v1.1.0 기본 덱을 기존 덱 위에 가져오면 됨. 학습 진행 상태 가져오기는 끄고, 기존 노트 업데이트와 노트 유형 병합은 켜면 됨.
