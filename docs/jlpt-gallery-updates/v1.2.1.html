PITCH ACCENT
단어가 끝난 뒤의 높낮이도 화살표로

단어 고저 악센트 선 끝에 화살표를 추가했음. 단어 뒤에서도 높게 이어지는지, 낮게 떨어지는지 바로 구분할 수 있음. 단어 안의 선 모양이 같아 보여도 끝 화살표로 차이를 알 수 있음.

긴 단어는 좁은 악센트 칸 안에서 히라가나 폭을 필요한 만큼 조정해 선과 글자가 덜 겹침.

CARD VIEW
카드를 넘길 때 덜 깜빡이게

Mac Anki에서 새 카드로 넘어갈 때 일본어가 굵게 보였다가 선택한 글꼴로 바뀌는 순간을 줄였음. 설정에서 명조체와 고딕체를 바꿀 때도 카드가 잠깐 사라지지 않고 글꼴만 바뀜.

긴 후리가나는 옆 글자를 밀지 않고, 고저 악센트 선도 처음 나타날 때 덜 움직임.

한자 버튼을 열어도 글자가 밀리지 않게

한자 버튼과 사전 버튼의 크기를 맞췄음. 한자 내용을 열고 닫아도 화살표와 ‘한자’ 글자가 옆으로 움직이지 않음.

활용·학습·익명 통계처럼 펼쳐 보는 항목의 화살표도 같은 모양과 움직임으로 맞췄음.

MOBILE SETTINGS
익명 통계에서 불편했던 두 부분 수정

기존 익명 통계 기능은 그대로 사용됨. 이번에는 공유를 껐다 다시 켰을 때 같은 기기를 새 설치로 중복 집계하지 않도록 고쳤음.

좁은 화면에서도 통계 창이 옆으로 밀리지 않아 좌우로 움직이지 않고 읽을 수 있음.
