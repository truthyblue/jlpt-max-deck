한자 버튼과 사전 버튼을 같은 줄에서

한자 버튼은 카드가 직접 만든 클릭 동작 대신 기본 열고 닫기 동작을 사용함. Mac Anki에서도 두 버튼의 높이와 폭을 맞추고, 닫힘·펼침 화살표를 같은 칸에서 회전시켜 ‘한자’ 글자가 밀리지 않게 함.

후리가나는 본문을 밀지 않게

긴 후리가나는 본문 폭에 포함하지 않고, 실제로 옆 글자와 부딪힐 때만 필요한 만큼 간격을 둠. 고저표는 문장과 곡선 폭을 그대로 두고 좁은 모라의 히라가나 라벨만 칸 안에서 조정함.

取る: 뜻 순서와 예문 순서 그대로

잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다라는 뜻 표시와 같은 순서로 예문을 배치함. 같은 뜻 묶음은 한 흰색 영역에 모으고, 독립 뜻은 다음 영역으로 나눔.
