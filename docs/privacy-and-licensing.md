# 개인정보·저작권·라이선스

이 문서는 학습자가 알아야 할 배포 경계를 쉽게 설명한 요약이며 법률 자문이
아닙니다. 정확한 조건은 [LICENSE](../LICENSE)와 [NOTICE](../NOTICE)가
우선합니다.

## 기본 덱

v2.0.0 기본 덱 APKG는 공식 GitHub Release에서 직접 받습니다. 어휘,
예문, 문제, 번역, 합성 음성과 JMdict·KANJIDIC2 파생 정보가 함께 들어 있으므로
파일 전체에 하나의 라이선스만 적용되는 것은 아닙니다.

공식 기본 덱은 개인 학습용으로 받을 수 있습니다. 다시 업로드하거나 판매,
변형·재포장 또는 미러링하기 전에 NOTICE에서 각 자료의 조건을 확인하세요. 공식
다운로드 링크를 공유하는 것은 가능합니다.

## 선택형 한자 확장

한자 빌더는 사용자가 지정한 길벗 PDF 2개를 사용자 컴퓨터에서만 읽습니다.
[초심자용 한자 확장 가이드](https://truthyblue.github.io/jlpt-max-deck/kanji.html)에서 공식 PDF 링크와
더블클릭 실행 순서를 확인할 수 있습니다.

| 동작 | 외부로 나가는 정보 |
| --- | --- |
| PDF 읽기와 한자 APKG 생성 | 없음 |
| 첫 실행의 빌드 도구·Python 자동 준비 | 프로그램 배포 서버와 패키지 저장소에 일반 요청 |
| Release 자산 다운로드 | GitHub에 일반 다운로드 요청 |
| 덱 카드의 최신 버전 확인 | GitHub Pages에 작은 버전 파일 요청 |
| 동의한 모바일 사용 통계 | JLPT MAX Cloudflare Worker에 아래 최소 통계 전송 |
| 사용자가 직접 보낸 카드 오류 제보 | JLPT MAX Cloudflare Worker에 아래 제보 정보 전송 |
| 카드나 문서의 외부 링크 열기 | 사용자가 눌렀을 때 해당 사이트에 요청 |

1.0.2부터 덱 카드 뒷면은 학습 세션에서 최신 버전을 확인할 때
`latest-release.json`을 요청합니다. 요청 URL과 본문에는 PDF·카드 내용·학습
기록이나 별도 개인 식별자를 넣지 않지만, 일반 웹 요청처럼 접속 IP와 브라우저
정보가 GitHub에 전달될 수 있습니다. 확인에 실패해도 학습을 막거나 오류를
표시하지 않습니다.

## 선택형 모바일 사용 통계

v1.1.0부터 AnkiMobile과 AnkiDroid의 답안 화면 10회 뒤 사용 통계를
공유할지 한 번 묻습니다. 동의하기 전에는 통계를 전송하거나 앞선 학습을 소급해
집계하지 않습니다. 거절하면 자동으로 다시 묻지 않으며, 답안 화면 하단의
`익명 통계`에서 언제든 선택을 바꿀 수 있습니다.

v1.1.1부터 카드 안의 설정과 통계 상태는 WebView 쿠키와 `localStorage`에 함께
저장합니다. 유효한 쿠키가 있으면 먼저 사용해 기존 Android 상태를 이어받고,
쿠키를 쓸 수 없는 iPhone·iPad에서는 `localStorage`를 사용합니다. 한쪽에만
유효한 값이 남으면 다른 저장소에도 복제합니다. 통계 횟수는 오늘과 가장 최근의
이전 학습일, 최대 이틀치만 기기에 남깁니다. 날짜가 바뀐 뒤 첫 답안을 확인하면 이전 학습일의 최종 횟수와
오늘 첫 횟수 1을 함께 보내고, 성공한 뒤 이전 학습일 기록을 지웁니다. 전송에
실패하면 다음 답안에서 다시 시도하지만 더 오래된 오프라인 기록을 계속 쌓지는
않습니다.

동의하면 다음 정보만 전송합니다.

- 이 모바일 설치에서 무작위로 만든 설치 ID
- 기기 현지 날짜와 iOS 또는 Android 구분
- JLPT MAX 버전, 학습한 세부 덱과 날짜별 답안 확인 누적 횟수

카드·단어 ID와 내용, 정답·평점·복습 이력, Anki 계정·프로필, 이름·이메일,
다른 덱 정보, 기기 모델과 상세 앱·OS 버전은 보내지 않습니다. Worker 코드는
IP 주소, User-Agent와 Cloudflare 요청 메타데이터를 읽거나 통계 데이터베이스에
저장하지 않습니다. 다만 HTTPS 연결과 네트워크 보안 과정에서는 Cloudflare가
일반적인 웹 서비스와 마찬가지로 IP 주소를 처리할 수 있습니다.

날짜별 원본 기록은 90일 뒤 삭제하고, 설치 ID와 직접 연결되지 않은 날짜·월별
집계 결과는 장기 보관할 수 있습니다. 공유를 끄면 이 기기의 설치 ID와 아직
전송하지 않은 기록을 즉시 삭제하고 이후 전송을 중단합니다. 이미 전송된 원본은
별도 삭제 요청을 보내지 않고 90일 보존 기간이 지나면 삭제됩니다. 이름이나
계정과 연결하지 않지만, 전송되는 무작위 설치 ID는 같은 모바일 설치의 중복
집계를 막기 위한 가명 식별자입니다.

실제 카드에 포함된 클라이언트 코드는
[`src/usage_telemetry_client.js`](../src/usage_telemetry_client.js)에서 확인할 수
있습니다. 집계 결과를 공개할 때는 다운로드 수나 전체 사용자 수가 아니라
`최근 30일 관측된 동의 기반 활성 모바일 설치 수`처럼 측정 범위를 함께 밝힙니다.

## 인앱 오류 제보

모든 플랫폼의 답안 화면 하단에서 **오류 제보**를 열 수 있습니다. 사용자가
**제보 보내기**를 누를 때만 한 번 전송하며, 자동 수집·로컬 대기열·백그라운드
재전송은 하지 않습니다. 사용 통계 동의 여부와도 무관합니다.

전송하는 정보는 사용자가 고른 문제 유형, 직접 작성한 설명, JLPT MAX 버전,
iOS·Android·데스크톱 구분, 학습 영역·급수·실전 유형과 현재 카드를 찾기 위한
내부 식별 코드입니다. 카드 본문과 복습 기록, 이름·이메일, Anki 계정·프로필,
사용 통계 설치 ID와 카운터는 보내지 않습니다. 설명란에는 개인정보를 적지
말아야 합니다.

제보 원본은 접수 시각과 처리 상태를 포함해 최대 365일 보관한 뒤 삭제합니다.
실제 전송 계약은
[`src/error_report_client.js`](../src/error_report_client.js)에서 확인할 수 있습니다.

빌더 ZIP에는 한글 뜻과 일부 자형이 비어 있는 한자 골격이 들어 있습니다. 로컬
실행이 지원 PDF에서 해당 부분을 채워 개인용 한자 APKG를 만듭니다. 원본 PDF와
페이지 이미지는 APKG에 들어가지 않습니다.

사용자가 만든 한자 확장 APKG와 PDF는 개인 학습용으로만 보관하세요. 같은 사용자가
자신의 기기 사이에서 비공개 AnkiWeb 동기화를 하는 것은 NOTICE에서 개인 학습의
일부로 설명하지만, APKG나 계정 접근 권한을 다른 사람에게 공유하는 것은 포함하지
않습니다.

## 코드와 콘텐츠의 조건

- 저장소의 코드·문서·사이트: AGPL-3.0-or-later
- JMdict·KANJIDIC2 파생 부분: EDRDG 라이선스와 CC BY-SA 4.0 적용 범위
- 프로젝트 작성·생성 콘텐츠와 음성: NOTICE의 별도 조건
- 길벗 PDF와 로컬에서 채운 파생 부분: 권리자 권리 유지

코드가 AGPL이라는 이유만으로 APKG의 모든 데이터가 AGPL이 되지는 않습니다.

## 안전하게 오류 제보하기

카드 내용·표시·음성 문제는 해당 카드 답안의 **오류 제보**를 사용하세요. 설치나
한자 빌더 문제를 공개 issue에 적을 때는 버전, 운영체제, Anki 버전, 실행 단계와
비민감 오류 문구만 포함합니다. PDF, 책 본문·페이지 이미지, 추출 문자열, 기본
덱이나 한자 확장 APKG, 개인 Anki 컬렉션, 계정 정보 또는 실명·홈 폴더가 드러나는
경로는 첨부하지 마세요. 보안 문제는 [SECURITY](../SECURITY.md)의 비공개 제보
절차를 사용합니다.
