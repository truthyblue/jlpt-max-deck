이게 뭔데?

Anki는 외운 내용을 잊을 때쯤 다시 보여 주는 암기 앱임. JLPT MAX는 여기에 바로 가져와 공부할 수 있게 만든 한국어 JLPT 카드 묶음이고, PC·iPhone·iPad·Android에서 쓸 수 있음.

기본 덱 하나에 N5부터 N1까지의 문법·어휘·음성·실전 문제·참조표가 들어 있음. 처음이면 Anki를 설치하고 APKG 파일을 가져온 뒤 JLPT MAX덱::어휘::N5부터 시작하면 됨.

카드에 적힌 뜻만 외우면 됨

사전 뜻을 통째로 늘어놓지 않고, 한국어 학습자가 실제로 구분해 외워야 할 뜻만 따로 정리했음. 비슷한 표현은 하나로 묶고, 다의어는 외울 뜻별로 나눴음.

01엄마, 어머니 → 엄마
같은 의미의 표현은 학습용 뜻 하나로 정리
02꺼내다 / 제출하다 / 편지를 보내다
다의어는 외울 뜻별로 분리
03뜻 1 → 예문 1 · 뜻 2 → 예문 2
각 뜻에 그 쓰임이 분명한 대표 예문 연결

단어와 각 뜻별 예문 음성은 모두 AivisSpeech 1.2.0의 まい로 합성했음. 단어와 예문을 눌러 각각 들을 수 있음.

실제 어휘 답면 · 出す · 한자 패널 펼침 · AivisSpeech 1.2.0 · まい · ACML 1.0

카드의 한자를 펼치면 뜻·읽기·모양자·부수·획수를 바로 볼 수 있음. 한자 옆 ↗를 누르면 nihongokanji의 해당 글자 설명으로 연결됨.

외운 뒤에는 JLPT 형식 문제로 확인

한자 읽기, 표기, 문맥, 바꿔쓰기, 용법, 단어 형성까지 7,876문제를 풀 수 있음. 카드를 뒤집으면 정답·후리가나·번역과 선택지별 해설을 확인할 수 있음.

실제 실전 문제 답면 · 한자 읽기
그 밖에 들어 있는 기능
  • 활용: 동사·형용사의 주요 활용형을 한눈에 확인
  • 헷갈리는 단어: 비슷한 단어와 차이를 같은 카드에서 비교
  • 고저 악센트: 단어와 예문의 높낮이를 표시하고 설정에서 켜기·끄기
  • 표시와 재생 설정: 후리가나·한국어 해석·자동재생 범위·0.8~1.5배속
  • 한국어 → 일본어 학습 카드
만드는 방법도 공개
작성 → 별도 판정 → 규칙 검사

학습자용 뜻·예문·번역과 문제·해설 작성에 GPT‑5.6 Sol을 사용했음. 생성 결과를 그대로 넣지 않고, 작성과 분리된 판정과 로컬 규칙 검사를 통과한 내용으로 덱을 만들었음.
