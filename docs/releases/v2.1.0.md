# v2.1.0

v2.1.0은 어휘 9,160개의 뜻과 예문을 같은 기준으로 전부 다시 점검한 업데이트입니다.
실제로 공부하는 어휘 9,159개 가운데 뜻 또는 예문이 달라지는 2,963개를 고쳤고,
최종 뜻마다 맞는 대표 예문을 연결했습니다.

## v2.0.3에서 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 컬렉션을 백업합니다.
2. 기존 덱을 지우지 않고 `JLPT-MAX-Deck-2.1.0.apkg`를 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다.
4. 기존 노트와 노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 가져오기가 끝나면 Anki의 빈 카드 도구를 열어 `笠` 카드 3장을 삭제합니다.
6. 한자 덱을 쓰는 경우 `JLPT-MAX-kanji-builder-2.1.0.zip`으로 다시 만듭니다.
7. 모든 기기에서 다시 전체 동기화합니다.

기존 학습 일정과 복습 기록은 유지됩니다. `笠`는 같은 한자를 이미 가르치는 카드와
겹쳐 단독 어휘 카드만 정리했습니다. 카드 탐색기에서 노트를 직접 지우지 말고,
가져오기 뒤 생긴 빈 카드 3장만 빈 카드 도구로 삭제하세요.

## 어휘 9,160개 전수 재검토

- 뜻이 달라진 어휘: 2,662개
- 예문 또는 루비가 달라진 어휘: 2,397개
- 사용자에게 보이는 내용이 달라진 어휘: 2,963개
- 최종 학습 어휘: 9,159개
- 최종 예문: 10,997개
- 미해결 항목: 0개

서로 바꿔 말할 수 있는 뜻은 가운데점 `·`으로 묶고, 따로 외워야 하는 용법은
슬래시 `/`로 나눴습니다. `하다`, `나다`, `내리다`처럼 한국어만 보면 범위가 너무
넓은 뜻에는 대상이나 문형을 덧붙였습니다. 뜻 순서는 사전 배열이 아니라 기본적이고
자주 쓰는 용법부터 떠올리기 쉽게 정리했습니다.

![여러 뜻과 뜻별 예문이 나뉘어 표시된 抜ける 카드](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-nukeru.png)

![비슷한 뜻은 묶고 용법별 예문을 붙인 空く 카드](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.1.0/site/assets/releases/v2.1.0/gallery-v2.1.0-aku.png)

급수가 달라진 6개 어휘는 출판사 급수를 따릅니다. 새 설치에서는 새 급수 덱에
들어가며, 기존 설치에서는 학습 일정을 건드리지 않도록 카드의 원래 덱 위치가
유지됩니다. 카드에 표시되는 급수와 태그는 새 기준으로 바뀝니다.

## 카드 화면과 모바일 기록

- 새 버전 안내에서 기본 덱을 바로 받고 가져오기 옵션을 같은 화면에서 확인할 수
  있습니다.
- 내 기록의 JLPT 목표 선택을 처음 설정할 때도 같은 선택 화면을 사용합니다.
- 연결이 끊긴 상태에서 고른 목표는 다시 보낼 수 있도록 안내합니다.
- 오류 제보에서 문제 종류와 설명, 답장을 받을 이메일을 더 분명하게 입력할 수
  있습니다.
- Android에서 기간별·영역별·급수별 분석 기록이 빠질 수 있던 경우를 막았습니다.
- iPad에서 Apple Pencil을 빠르게 움직여도 획이 끊기지 않게 했습니다.

## 확인한 내용

- 빈 프로필 새 가져오기 통과
- v2.0.3에서 v2.1.0 업데이트 통과
- 기존 학습 상태 보존 확인
- 급수가 달라진 카드 18장의 기존 덱 위치 보존 확인
- `笠` 빈 카드 3장 정리 뒤 다시 생기지 않는 것 확인
- 공개 기본 덱과 한자 빌더 분리 검증 통과
- 실제 어휘 카드 2장을 390×844에서 확인

기본 덱은 20,650노트·38,967카드·미디어 25,511개입니다. 이 노트 수에는 기존
`笠` 카드를 안전하게 정리하기 위한 숨은 노트 1개가 포함됩니다. 한자 빌더는
읽기·쓰기 4,674노트·4,674카드를 별도로 만듭니다.
