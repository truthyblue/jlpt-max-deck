# v2.1.1

한자 덱 생성 오류와 iPhone·iPad 기본 문법 카드의 후리가나 표시를 고친 수정판입니다.
뜻·예문·음성과 카드 구성은 v2.1.0과 같습니다.

## 고친 내용

- v2.1.0 한자 빌더가 한자를 확인하는 단계에서 오류로 멈추던 문제를 고쳤습니다.
- iPhone·iPad 기본 문법 카드의 예문과 비교 문형에서 후리가나가 본문 옆에 붙던 문제를 고쳤습니다. 읽기가 한자 위에 놓이도록 표시 범위를 바로잡았습니다.

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 v2.1.1 기본 덱을 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
4. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

v2.1.0 한자 덱을 이미 정상적으로 만들었다면 다시 만들 필요가 없습니다.
생성에 실패했거나 v2.0.3 이하 한자 덱을 쓴다면 v2.1.1 빌더로 만드세요.

v2.0.3 이하에서 올라오는 분은 [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)의
빈 카드 정리도 확인하세요. [v2.1.0 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/releases/v2.1.0.md)의 어휘 교정과 화면 개선이 함께 적용됩니다.
