# v1.0.0

첫 공개 배포는 Anki에 바로 가져오는 **기본 덱**과, 공식 학습자료로 개인용 APKG를
만드는 **일상무따 한자 확장**으로 구성됩니다.

## 이번 갱신

- iPhone·iPad에서 자동재생 설정을 터치할 때 학습 답변으로 처리되던 문제를
  수정했습니다.

## 학습자가 받는 것

- `JLPT-MAX-Deck-1.0.0.apkg`: 어휘·음성·실전 문제·참조표가 들어 있는 완성 APKG
- `JLPT-MAX-kanji-builder-1.0.0.zip`: 지원 PDF 2개로 개인용 한자 확장을 만드는 선택형 빌더
- `SHA256SUMS`: 위 Release 자산의 SHA-256 목록
- `public-release.json`: 릴리스 수량·해시·정책을 묶은 검증 pin

기본 덱 APKG는 Anki에서 바로 가져옵니다. 일상무따 한자 확장을 추가할 때는 길벗
《일본어 상용한자 무작정 따라하기》 1·2권의 지원 소책자 PDF를 사용자 컴퓨터에서
읽어 개인용 APKG를 만듭니다.

| 두 APKG 합산 | 16,240 | 22,402 | 17,964 |

새 임시 컬렉션에 두 APKG를 순서대로 가져온 뒤 SQLite `integrity_check`가 `ok`임을
확인했습니다. 한자 빌더는 상권
`5ccd96a8594c5e869e8f069771cce86b3a72601b591aa861f1264c26fbb0556c`, 하권
`0980a68ea9c6055b9c44559c81ed20a5ecf0d59e42d38a3b426a3ea8bf9cb789` 판본에서
2,337개를 검증했습니다.

기본 덱 가져오기는 Anki Desktop·AnkiMobile·AnkiDroid에서 사용할 수 있습니다.
한자 빌더 Release 검증 범위는 macOS 12+와 Windows
x64입니다.
