# v2.0.0

v2.0.0은 검토된 어휘를 **6,018개에서 9,160개**로 늘리고, 모든 어휘에
**한국어→일본어 회상 카드**를 추가한 큰 업데이트입니다. 각 급수의 새 카드
순서는 BCCWJ 사용 빈도를 바탕으로 다시 정리했습니다. 한자 쓰기 조작, 카드 표시와
음성 설정, 제보받은 콘텐츠·화면 오류도 함께 고쳤습니다.

## 기존 덱 업데이트 방법

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. **기존 덱이나 학습한 급수를 삭제하지 않고**
   `JLPT-MAX-Deck-2.0.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**를 선택합니다.
4. **기존 노트 업데이트 → 항상**, **노트 유형 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
5. 아래의 빈 카드 정리를 끝낸 뒤 모든 기기에서 전체 동기화합니다.

직접 고친 공식 노트 필드는 `항상` 업데이트로 덮어쓸 수 있습니다. 그런 수정이
있다면 먼저 백업하세요. 한자 확장을 사용한다면
`JLPT-MAX-kanji-builder-2.0.0.zip`과 지원 PDF 2개로 한자 APKG도 다시
만들어 가져오세요.

## 새 어휘 순서를 쓰고 싶을 때

v2.0.0은 각 급수 안에서 BCCWJ 사용 빈도를 기준으로 중요한 어휘부터 새 카드가
나오도록 정렬했습니다. 하지만 Anki는 이미 들어 있는 카드의 순서와 학습 일정을
보존합니다. 따라서 **가져오기만 해서는 기존 덱이 새 순서로 다시 배열되지
않습니다.**

- 이미 한 장이라도 학습한 급수는 정렬만을 위해 삭제하지 마세요.
- 어떤 급수가 완전히 미학습 상태이고 새 순서를 처음부터 쓰고 싶을 때만
  `JLPT MAX덱::어휘::N○`와 `JLPT MAX덱::음성::N○`를 **둘 다** 삭제합니다.
- 그 뒤 v2.0.0을 위의 옵션으로 다시 가져옵니다. 학습 진행 상태는 끈 채로
  가져와야 합니다.

어휘 덱만 지우면 같은 단어의 음성 카드가 남을 수 있습니다. 반드시 같은 급수의
어휘·음성 덱을 한 쌍으로 다루세요.

## 업데이트 뒤 빈 카드 4장 정리

v2.0.0에서는 독립 어휘로 두지 않는 `五万`과, `キロ`와 중복되던 `～キロ` 노트를
정리했습니다. Anki는 가져오기만으로 예전 노트와 카드를 자동 삭제하지 않으므로,
v1.3.0에서 업데이트한 기준 컬렉션에서는 예전 어휘·음성 카드 **4장**이 빈 카드로
남습니다.

- Android·AnkiDroid: `⋮ → 확인 → 빈 카드`
- iPhone·iPad·AnkiMobile: `설정 → 빈 카드`
- Windows·macOS·Linux Anki: `도구 → 빈 카드`

목록에서 `五万`과 `～キロ`의 어휘·음성 카드인지 확인한 뒤 **빈 카드 도구의
삭제**를 누르세요. 카드 탐색기의 `노트 삭제`는 다른 카드까지 지울 수 있으므로
사용하면 안 됩니다. 출발 버전과 개인 컬렉션 상태에 따라 표시 수는 달라질 수
있습니다.

## 어휘 9,160개와 예문 10,463개

- 검토된 어휘 노트가 6,018개에서 9,160개로 늘었습니다.
- 모든 어휘에 뜻을 대표하는 검토된 예문이 하나 이상 있습니다.
- 예문은 뜻별로 연결했으며 전체 10,463개입니다.
- 단어·예문 음성과 관련어, 활용, 말투·사용 상황, 핵심 용법을 같은 카드에서
  확인할 수 있습니다.
- 각 급수 안의 중요도 순서는 BCCWJ 장단위어 사용 빈도와 검토된 표기 연결을
  사용합니다.

## 한국어→일본어 회상 카드 9,160장

모든 어휘에 한국어 뜻과 짧은 예문을 보고 일본어 표기와 읽기를 떠올리는 카드를
한 장씩 추가했습니다. 기존 일본어→한국어 어휘 카드와 음성 카드는 그대로
유지합니다. 새 회상 카드는 처음 추가되는 카드이므로 기존 복습 기록을 옮기지 않고
새 학습 항목으로 시작합니다.

## 뜻과 예문을 더 정확하게 분리

뜻 하나로 서로 다른 쓰임을 억지로 묶지 않고, 학습자가 따로 외워야 하는 뜻은
나눴습니다. `断る`는 “거절하다”와 “양해를 구하다”를 분리하고 각 뜻을 대표하는
예문만 남겼습니다.

![v1.3.0과 v2.0.0의 断る 뜻·예문 배치 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.0/site/assets/releases/v2.0.0/gallery-v2.0.0-kotowaru-before-after.png)

## 한자 쓰기 조작과 구성 요소 추가

- 획순 애니메이션을 일시정지하고 이전 획·다음 획·처음부터를 누를 수 있습니다.
- 느리게·보통·빠르게 속도를 바꿀 수 있습니다.
- 전체 획의 진행 위치를 보고 원하는 구간을 다시 재생할 수 있습니다.
- 한자를 이루는 모양과 부수, 발음별 단어, 헷갈리기 쉬운 한자를 함께 봅니다.
- 외부 한자 참고 링크를 읽기·쓰기 카드에서 바로 열 수 있습니다.

기존 한자 읽기·쓰기 카드의 안정 ID와 학습 기록은 유지됩니다.

![v1.3.0과 v2.0.0의 한자 쓰기 화면 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v2.0.0/site/assets/releases/v2.0.0/gallery-v2.0.0-kanji-controls-before-after.png)

## 카드 표시와 음성 개선

- 후리가나·해석·표시 설정과 음성 설정을 나눠 찾기 쉽게 했습니다.
- 선택한 설정은 지원되는 AnkiMobile·AnkiDroid 카드 화면에서 저장됩니다.
- 음성 카드가 처음 나타났을 때 자동재생이 빠지는 문제를 고쳤습니다.
- 합성 한자 자형의 크기와 Android 답면 잘림을 고쳤습니다.
- 투명 한자 이미지가 검은 배경에서 보이지 않던 경우를 고쳤습니다.
- 사전 버튼은 새 창에서 열립니다.
- 지원하지 않는 AnkiDroid 구형 학습 화면에서는 새 학습 화면을 켜는 경로를
  안내합니다.

## 오류 제보 49건 처리

v2.0.0 범위에서 검토한 제보 49건 중 **35건은 수정으로 해결**했고, **14건은 현재
내용을 유지하는 이유를 기록**했습니다. 뜻·예문·품사·읽기·고저 악센트·음성·한자
자형·모바일 표시·실전 문제 해설과 익명 통계 전송을 포함합니다.

개인정보와 제보 원문은 공개하지 않습니다. 항목별 공개 결과는
[v2.0.0 오류 제보 처리 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v2.0.0/docs/release-details/v2.0.0-report-outcomes.md)에서
볼 수 있습니다. 처리 결과 알림 버전은 49건 모두 `2.0.0`으로 맞췄습니다.

## 기본 APKG와 한자 빌더 구성

- public 기본 APKG: 17,045노트·35,365카드·미디어 24,978개
- 한자 addon: 4,674노트·4,674카드
- 두 APKG를 합친 전체: 21,719노트·40,039카드

기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는 빌더가
사용자의 지원 PDF 2개로 개인용 APKG를 만들어 합칩니다. 출판사 PDF 원문,
페이지 이미지와 추출 원문은 저장소나 배포 파일에 포함하지 않습니다.

## 실제 배포 후보 검증

- 빈 profile 새 가져오기 1회 통과
- v1.3.0 배포 APKG 위에 v2.0.0 업데이트 가져오기 1회 통과
- 가져오기 옵션: 학습 진행 상태 끄기, 기존 노트·노트 유형 업데이트 항상,
  노트 유형 병합 켜기
- 기존 노트 18,575개 업데이트, 새 노트 3,144개 추가
- 제거 검토된 노트 2개와 예전 카드 4장 확인
- 제거된 노트의 학습 기록을 다른 단어로 옮기지 않은 것 확인
- private 전체 21,719노트·40,039카드 확인
- public 기본 17,045노트·35,365카드 확인
- 한자 addon 4,674노트·4,674카드 확인
- 실제 카드 HTML을 390×844에서 확인하고 가로 넘침과 잘림이 없는지 검사
- 최종 private APKG 생성 1회, 승인된 미디어 재사용 1회, TTS 새 합성 0회

실물 iPhone·iPad와 Android의 모든 기기·앱 버전 조합을 전수 검증한 것은 아닙니다.
실제 후보 APKG의 새 설치·업데이트, 공개 기본 덱과 한자 빌더 구조, 해시와 생성
HTML의 모바일 폭 화면을 확인했습니다.
