# v1.1.0

1.1.0은 공개 1.0.3의 학습 콘텐츠와 덱 구조를 그대로 유지하면서, 모바일에서
명시적으로 동의한 경우에만 익명 사용 통계를 공유하는 설정을 추가하고 Android
야간 모드의 일상무따 한자 자형 표시를 개선했습니다. 어휘 답안의 한자·사전
도구도 더 작고 찾기 쉽게 정리했습니다.

## 1.0.3 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.1.0.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기**는 끄고, **기존 노트 업데이트**와
   **노트 유형 병합**은 켭니다.

기존 노트·카드 ID, 학습 기록과 개인 덱 옵션은 그대로 유지됩니다. Android에서
일상무따 한자 확장을 야간 모드로 사용한다면 같은 1.1.0 한자 빌더로 확장을 다시
만드는 것을 권장합니다. 기존 한자 카드 위에 가져오면 학습 기록은 유지됩니다.

## 선택형 익명 모바일 사용 통계

AnkiMobile과 AnkiDroid의 답안 화면을 10번 본 뒤 처음 한 번만 사용 통계를
공유할지 묻습니다. **사용 통계 공유하기**를 누르기 전에는 아무 통계도 전송하지
않고, **공유하지 않기**를 누르면 자동으로 다시 묻지 않습니다.

동의하면 이 모바일 설치에서 만든 무작위 설치 ID와 다음 정보만 보냅니다.

- iOS 또는 Android 구분
- JLPT MAX 버전과 학습한 세부 덱
- 세부 덱마다 기기 현지 날짜별로 답안을 확인한 누적 횟수

카드·단어 ID와 내용, 정답·평점·복습 이력, Anki 계정·프로필, 다른 덱 정보,
기기 모델과 상세 앱·OS 버전은 보내지 않습니다. 날짜별 원본 기록은 90일 뒤
삭제하고 집계 결과만 보관할 수 있습니다.

답안 화면 하단의 **사용 통계 설정**에서 언제든 공유를 끌 수 있습니다. 끄면 이
기기의 설치 ID와 아직 전송하지 않은 기록을 즉시 삭제하고 이후 전송을 중단합니다.
팝업 하단의 **오류 제보하기**는 공개 GitHub 오류 양식만 열며 동의 상태는 바꾸지
않습니다.
전체 전송·보관 설명은 [개인정보·저작권·라이선스](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/privacy-and-licensing.md),
실제 클라이언트 코드는
[`src/usage_telemetry_client.js`](https://github.com/truthyblue/jlpt-max-deck/blob/main/src/usage_telemetry_client.js)에서
확인할 수 있습니다.

## 어휘 답안의 한자·사전 도구 정리

어휘 답안에서 한자 정보와 네이버 사전 링크를 단어 바로 아래의 작은 버튼으로
묶었습니다. 한자 정보는 필요할 때 펼칠 수 있으며, 여러 한자는 큰 타일 대신
간결한 행으로 표시해 예문을 보기 전 화면을 덜 차지합니다.

## Android 야간 모드 한자 표시

이미지로 표시되는 일부 일상무따 한자 자형이 Android 야간 모드에서 배경과 함께
어둡게 보이던 문제를 수정했습니다. 야간 모드에서는 해당 자형의 명암을 반전해
밝게 표시하며, 일반 모드의 표시는 바뀌지 않습니다.
