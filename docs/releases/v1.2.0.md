# v1.2.0

v1.2.0은 모든 어휘와 예문에 고저 악센트를 추가하고, 학습자 뜻 249개를 다듬고
예문 182개를 보강한 마이너 업데이트입니다. 카드 설정·다의어 문맥 힌트·모바일
팝업·한자 표시·업데이트 알림과 새 카드 배치도 함께 개선했습니다.

## 먼저: 1.1.1에서 업데이트하는 방법

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.2.0.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

이번 버전은 어느 기존 버전에서 오더라도 **항상**을 선택합니다.

| 지금 사용하는 버전 | 기존 노트 업데이트 | 이유 |
| --- | --- | --- |
| v1.1.x | **항상** | 고저 악센트 필드와 새 카드 템플릿을 적용해야 합니다. |
| v1.0.x | **항상** | v1.1.x의 뜻·예문 변경과 v1.2.0의 새 필드를 함께 적용해야 합니다. |

직접 편집한 공식 노트 필드가 있다면 먼저 백업하세요. 기존 한자 확장은 그대로
계속 사용할 수 있습니다. Windows Anki 야간 모드의 투명 SVG 렌더링과 새 일본어
글꼴, 최신 연결 어휘 표시를 적용하려면 v1.2.0 빌더로 다시 만들어 같은 옵션으로
가져오세요.

## 업데이트 후 선택: 미사용 음성 정리

Anki는 같은 이름의 음성이 새 내용으로 바뀌면 기존 파일을 바로 덮어쓰지 않고,
새 파일을 다른 이름으로 가져올 수 있습니다. 카드는 새 음성을 재생하지만 예전
파일은 미사용 상태로 남아 저장 공간을 차지할 수 있습니다.

1. 업데이트된 카드와 음성이 정상인지 먼저 확인합니다.
2. 모든 기기의 미디어 동기화를 끝냅니다.
3. 데스크톱 Anki에서 **도구 → 미디어 검사**를 엽니다.
4. 미사용 파일 목록을 확인하고 삭제한 뒤 다시 동기화합니다.

미디어 검사는 프로필 전체를 대상으로 하므로 다른 덱의 미사용 파일도 함께 표시될
수 있습니다. 목록을 확인한 뒤 삭제하세요. 삭제된 파일은 운영체제 휴지통으로
이동하므로 실수했다면 복구할 수 있습니다.

### 2. 뜻·예문과 신고 내용 교정

- 뜻 표시 변경: 249개
  - 독립 뜻 분리·통합: 23개
  - 뜻 문구·구성 수정: 226개
- 새 예문: 182개
- 기존 예문 교체·번역·뜻 칩 교정: 3건
- 전체 검토 예문: 6,883개 → 7,065개
- 신고된 실전 문제·문장과 `変わる`의 ‘특이하다’ 예문, `持つ`의 ‘오래가다’
  품사, `六本` 발음, `とお`를 묻는 조수사 문제의 `十つ` 표기를 `十`으로 교정

대표 예시는 다음과 같습니다.

- **독립 뜻 구분 · 濃い:** `짙다` → `(색·안개가) 짙다 / (맛·농도가) 진하다`
- **뜻 문구 보강 · 取り上げる:** `집어 들다 / 다루다 / 빼앗다` →
  `집어 들다 / 채택하다·다루다 / 빼앗다`
- **새 예문 · 磨く — 갈고닦다:** `職人は長年かけて技を磨いた。` — 장인은 오랜
  세월 기술을 갈고닦았다.
- **기존 예문 교정 · 示す — 가리키다:** `矢印は駅の方向を示す。` —
  `화살표는 역의 방향을 나타낸다.` → `화살표는 역 방향을 가리킨다.`

단어별 변경 전·후와 새 예문 전체는
[v1.2.0 뜻·예문 상세 변경 내역](https://github.com/truthyblue/jlpt-max-deck/blob/main/docs/release-details/v1.2.0.md)에서
확인할 수 있습니다.

### 3. 일본어 글꼴과 카드 설정 통합

일본어용 명조·고딕 글꼴을 카드에 포함해 기기마다 자형이 달라지는 일을 줄였습니다.
일본어 본문 글꼴과 후리가나·해석·고저 악센트·자동재생 범위·배속을 같은 설정
패널에서 조절하고, 자주 쓰는 항목은 카드 상단에서도 바로 바꿀 수 있습니다.
어휘·음성·실전 문제·참조표·한자 카드에 같은 일본어 글꼴 설정이 적용됩니다.

![v1.1.1과 v1.2.0의 카드 설정 패널 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.2.0/gallery-v1.2.0-card-settings.png)

### 4. 한자 펼침과 이미지 표시 수정

어휘 카드의 **한자** 버튼을 Anki WebView에서 직접 제어하는 방식으로 바꿔
모바일에서도 펼침·접힘 상태가 정확히 동작합니다. 다크 모드 대비 보정은 v1.1.0
한자 빌더부터 적용됐으며, v1.2.0은 Windows Anki의 이미지 표시 경로에 맞춰 한자
14자를 원본부터 빌더 출력까지 투명한 path-only SVG로 통일했습니다. 투명 SVG는
v1.2.0 한자 빌더로 다시 만들면 적용됩니다.

### 5. 같은 표기의 다른 뜻을 구분하는 문맥 힌트

앞면만 보고는 어떤 뜻을 묻는지 알기 어려웠던 `そば`, `開く`, `避ける`, `紅葉`,
`なる` 5개 표제어의 10개 카드에 답을 노출하지 않는 짧은 빈칸 문맥을 넣었습니다.

![開く 카드의 전체 예문 앞면과 짧은 빈칸 문맥 앞면 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.2.0/gallery-v1.2.0-context-hint.png)

### 6. 작은 모바일 화면에서도 온전히 보이는 지원 팝업

좁은 화면에서 오류 제보와 사용 통계 팝업의 제목·닫기·동작 버튼이 잘리지 않도록
safe-area와 시작 위치를 보정했습니다. 익명 사용 통계는 모바일에서 명시적으로
동의한 경우에만 전송하며, 업데이트 안내 표시·선택 이벤트가 포함된다는 설명도
추가했습니다.

### 7. 업데이트 알림 닫기 상태 저장 수정

**7일간 숨기기**와 **이 버전 알림 다시 보지 않기**는 v1.1.1부터 제공했습니다.
일부 Anki 환경에서는 쿠키와 `localStorage`가 서로 다른 상태를 읽어 닫은 알림이
다시 나타났습니다. v1.2.0은 두 저장소를 동기화하고, **×**는 이번 학습,
**7일간 숨기기**는 7일, **이 버전 알림 다시 보지 않기**는 해당 버전 전체에
각각 적용되도록 수정했습니다.

### 8. 새 카드를 복습 사이에 배치

새 카드는 기본적으로 복습 카드 뒤에 몰아서 나오지 않고 복습 카드 사이에 섞여
나옵니다. 기존 preset ID와 학습 기록은 유지됩니다.

확인했습니다. 오류 제보는 모바일 카드의 오류 제보 버튼에서 누구나 보낼 수 있습니다.

## 익명 통계로 보는 현재 이용 현황

집계 기준은 사용 통계 공유에 동의한 모바일 설치입니다. 활성 설치는 업데이트 이후
학습한 무작위 설치 ID 수이고, 학습 횟수는 답안 화면 표시 횟수입니다. 플랫폼,
덱 버전, 학습 영역과 JLPT 급수별 집계를 함께 보여 줍니다.

![업데이트 이후 JLPT MAX 익명 이용 현황](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.2.0/gallery-v1.2.0-usage-summary.png)

덱 개선에 도움을 주고 싶다면 모바일 답안 아래 **익명 통계 → 사용 통계
공유하기**에서 언제든 켜고 끌 수 있습니다. 오류 제보는 모바일 카드의 **오류
제보** 버튼에서 보낼 수 있습니다.

이번 릴리스 공지에는 요약만 싣고, 버전 전환, 일별 이용 추이, 설치별 학습 횟수와
학습 구성은 별도 통계 글로 공유할 예정입니다.
