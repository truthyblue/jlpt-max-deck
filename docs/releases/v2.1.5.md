# v2.1.5

단어 카드 한자 칸의 일본어 한자 공부방 링크를 고친 수정판입니다.

## 바뀐 내용

- 일본어 한자 공부방 사이트 주소가 바뀌어 단어 카드 「한자」 칸의 ↗ 링크가 「페이지를 찾을 수 없음」으로 열리던 문제를 고쳤습니다. 이제 누르면 그 한자 페이지로 바로 열립니다.

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오기가 노트의 태그를 새 판으로 바꾸면서 표시와 직접 붙인 태그가 풀리고, 깃발은 남습니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.5 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. v2.1.4 빌더로 만든 한자 덱은 다시 만들지 않아도 됩니다. 한자 카드에 v2.1.5 알림이 뜨면 「이 버전 알림 그만 보기」를 누르세요. v2.1.3 이전 빌더로 만든 한자 덱이라면 v2.1.5 빌더로 다시 만들어 가져와야 단어 카드 한자 칸에 일상무따 훈음과 娠 교정이 적용됩니다.
6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

자세한 가져오기 설정은 [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)에서 확인하세요.
