# v1.0.2

1.0.2는 예문 후리가나 표시를 직접 고를 수 있게 하고, 덱 안에서 새 버전을
확인할 수 있게 한 사용성 업데이트입니다. 일상무따 한자 확장 빌더도
명령어를 직접 입력하지 않고 실행할 수 있게 바꿨습니다.

## 1.0.1 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.0.2.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기**는 끄고, **덱 프리셋**, **노트 유형 병합**,
   **기존 노트 업데이트**는 켭니다.

기존 덱이나 카드를 먼저 삭제할 필요는 없습니다. 어휘·음성·실전 문제·참조표의
학습 기록과 복습 일정은 유지되고 새 카드 템플릿이 반영됩니다. 이미 만든
일상무따 한자 확장도 다시 만들 필요가 없습니다.

## 이번 업데이트

- 어휘·음성·실전 문제 정답 화면에 **예문 후리가나 ON/OFF** 버튼을
  추가했습니다.
- 선택한 후리가나 상태는 카드를 넘기거나 Anki를 다시 열어도 유지됩니다.
- 카드 하단에서 현재 덱 버전을 확인하고, 더 최신 버전이 공개되면 업데이트
  안내를 볼 수 있습니다.
- 일상무따 한자 확장은 운영체제별 실행 파일을 더블클릭하고 공식 PDF 2개를
  순서대로 고르면 만들 수 있습니다.

## 학습자가 받는 것

- `JLPT-MAX-Deck-1.0.2.apkg`: 어휘·음성·실전 문제·참조표가 들어 있는 완성 APKG
- `JLPT-MAX-kanji-builder-1.0.2.zip`: 지원 PDF 2개로 개인용 한자 확장을 만드는 선택형 빌더
