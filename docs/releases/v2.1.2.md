# v2.1.2

단어 음성을 새로 정리하고, 제보된 읽기·해설과 내 기록 집계를 고친 수정판입니다.

## 바뀐 내용

- 단어 음성 9,159개의 속도와 리듬을 통일하고, 단어 끝소리와 표시 악센트에 맞춰 음원을 다시 만들었습니다.
- 일부 문법 카드의 후리가나와 어휘 문제의 선택지 해설을 바로잡았습니다.
- 내 기록에서 아직 전송되지 않은 답변이 중복 집계되던 문제를 고쳤습니다. 기기에 저장된 연속 학습 보호 기록도 유지합니다.
- 기기 저장 오류 뒤 다시 시도해도 동기화 오류 표시가 남던 문제를 고쳤습니다.
- 목표 설정을 저장했을 때 선택 결과를 더 분명하게 표시합니다.
- 한자 쓰기 화면의 조작과 함께 익힐 글자 표시를 다듬고, 누락된 획순 자료를 보완했습니다.
- 카드 버튼을 누를 때 글자가 선택되는 현상을 줄였습니다.

## 업데이트

1. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
2. 기존 덱을 지우지 않고 v2.1.2 기본 덱을 가져옵니다.
3. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
4. 한자 덱을 쓰는 경우에는 v2.1.2 한자 빌더로 확장 덱을 다시 만들고, 기존 덱을 지우지 않은 상태에서 가져옵니다.
5. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

자세한 가져오기 설정은 [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)에서 확인하세요.
