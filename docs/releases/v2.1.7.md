# v2.1.7

제보된 단어 뜻·예문과 잘못 읽던 음성을 고친 수정판입니다.

## 바뀐 내용

- 제보된 단어 뜻을 고쳤습니다. その上은 「게다가」, 手数(てかず)는 「(바둑·장기 등의) 수」로 바꾸고, 載せる에 「(글을) 싣다」, 為替에 「환율」 뜻과 예문을 더했습니다. 直る에서는 治る의 뜻인 「낫다」와 그 예문을 뺐습니다.
- N1 문법의 중복 문형 2개(～まじき, ～ならでは)와 중복 단어 1개(思いかえす)를 정리했습니다.
- 반말로 옮겨져 있던 ます·です 문법 예문 번역 9개를 존댓말로 고치고, 「속이 빈」 뜻의 空 후리가나를 そら에서 から로 바로잡았습니다.
- 단어·예문·정답 음성 99개를 다시 만들었습니다. 덱 전체 읽기 재검사와 제보로 찾은, 郊外를 「こうかい」로, 宝를 「たり」로 읽는 등 읽기가 틀린 음성입니다.
- 예문이 두 줄로 넘어가거나 글자를 키웠을 때 후리가나가 뜻 표시나 윗줄 악센트와 겹치던 문제를 고쳤습니다.
- iPhone·iPad(AnkiMobile)에서 긴 카드를 볼 때 앱 출시·업데이트 안내 창이 화면 밖으로 밀려 흐린 화면만 보이거나 닫기 버튼 위치가 카드마다 바뀌던 문제를 고쳤습니다.
- 毎年(まいとし・まいねん)처럼 읽기가 둘인 단어는 두 읽기를 이어 붙인 악센트 대신 읽기만 보여 줍니다. 頬의 ↗ 링크도 일본어 한자 공부방의 그 한자 페이지로 열립니다.
- 한자 덱을 v2.1.7 빌더로 다시 만들면 획순 그림이 없던 22자(貇 등)에 획순이 들어가고, 「헷갈리기 쉬운 한자」의 塁 뜻에 HTML 기호가 그대로 보이던 문제가 고쳐집니다.

## 업데이트

1. 표시(★)해 둔 카드가 있으면 카드 탐색기에서 `tag:marked`로 찾아 깃발을 붙입니다. 가져오기가 노트의 태그를 새 판으로 바꾸면서 표시와 직접 붙인 태그가 풀리고, 깃발은 남습니다.
2. 모든 기기를 AnkiWeb과 동기화하고 백업합니다.
3. 기존 덱을 지우지 않고 v2.1.7 기본 덱을 가져옵니다.
4. 학습 진행 상태 가져오기는 끕니다. 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.
5. 가져온 뒤 카드 탐색기에서 `UnitID:*e3b9b09c20c1 OR UnitID:*aaa6ed663bdf`로 찾은 N1 문법 노트 6개(～ならでは·～まじき)를 삭제합니다. 같은 문형은 「～ならではの」·「～にあるまじき」 카드로 계속 공부합니다. 「빈 카드」에서 비워진 思いかえす 카드도 삭제합니다. 같은 말은 思い返す 카드로 공부합니다.
6. v2.1.4 이후 빌더로 만든 한자 덱도 그대로 쓸 수 있습니다. 획순 22자와 塁 표시 수정을 받으려면 v2.1.7 빌더로 다시 만들어 가져오세요. 한자 카드에 v2.1.7 알림이 뜨면 「이 버전 알림 그만 보기」를 누르세요. v2.1.3 이전 빌더로 만든 한자 덱이라면 v2.1.7 빌더로 다시 만들어 가져와야 단어 카드 한자 칸에 일상무따 훈음과 娠 교정이 적용됩니다.
7. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.

자세한 가져오기 설정은 [업데이트 가이드](https://truthyblue.github.io/jlpt-max-deck/update.html)에서 확인하세요.
