# v1.1.1

1.1.1은 공개 1.1.0의 노트·카드·미디어와 안정 ID를 그대로 유지하면서,
iPhone·iPad와 AnkiDroid에서 카드 설정과 선택형 익명 통계 상태가 안정적으로
유지되도록 저장 방식을 보강한 호환성 핫픽스입니다.

## 1.1.0 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.1.1.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기**는 끄고, **기존 노트 업데이트**는 반드시
   **항상**, **노트 유형 병합**은 **켜기**를 선택합니다.

**새 버전일 때**로 두면 기존 노트와 카드 템플릿이 갱신되지 않을 수 있습니다.
**항상**은 직접 수정한 노트 필드도 패키지 내용으로 덮어쓸 수 있으므로, 뜻이나
예문 등을 편집했다면 먼저 백업하거나 별도 프로필에서 확인하세요. 기존 한자
확장은 다시 만들 필요가 없습니다.

## iPhone·iPad 설정 저장 수정

1.1.0은 카드 설정과 익명 통계 상태를 WebView 쿠키에 저장했습니다. 일부
iPhone·iPad의 AnkiMobile 카드 화면에서는 쿠키 쓰기가 성공하지 않아 후리가나,
예문 해석, 자동재생 범위와 배속이 앱을 다시 열었을 때 초기화되고, 익명 통계
동의·설치 ID·횟수도 유지되지 않을 수 있었습니다.

1.1.1은 같은 값을 쿠키와 `localStorage`에 함께 기록합니다. 유효한 쿠키가 있으면
먼저 사용하고 `localStorage`에도 복제하며, 쿠키를 쓸 수 없으면
`localStorage`에서 복원해 쿠키에 다시 기록합니다. 한 저장소가 실패해도 다른
저장소가 작동하면 설정과 통계 상태를 계속 사용할 수 있습니다.

## AnkiDroid의 로컬 스토리지 설정

AnkiDroid는 기본적으로 쿠키 저장을 계속 사용할 수 있습니다. AnkiDroid의
**설정 → 고급 → 학습 화면 로컬 스토리지**를 켜면 카드 서버의 포트가 고정되어
`localStorage`도 앱 재시작 뒤 같은 origin에서 유지됩니다. 이 옵션은 보조 저장소를
더 안정적으로 쓰기 위한 설정이며, 끈 상태에서도 기존 쿠키 값은 우선 사용합니다.

- 기존 학습 기록과 스케줄 호환성
