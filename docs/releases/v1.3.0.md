# v1.3.0

v1.3.0은 **한자 쓰기 카드 2,337장**을 추가하고,
한자 읽기 카드·음성·예문·모바일 설정을 다듬은 업데이트입니다. 중복되던 가나
보조 카드는 더 이상 만들지 않습니다.

## 기존 덱 업데이트 방법

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. 기존 덱을 삭제하지 않고 `JLPT-MAX-Deck-1.3.0.apkg`를 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원
   PDF 2개로 한자 APKG를 다시 만들어 가져옵니다.
5. 아래의 가나 보조 카드 정리를 끝낸 뒤 모든 기기에서 전체 동기화합니다.

앞으로 JLPT MAX 덱을 업데이트할 때는 출발 버전과 관계없이 **기존 노트 업데이트를
`항상`**으로 선택합니다. 이 옵션은 직접 고친 공식 노트 필드도 덮어쓸 수 있으므로
그런 수정이 있다면 먼저 백업하세요.

## 업데이트 뒤 가나 보조 카드 144장 정리

v1.2.1에서 v1.3.0을 실제로 가져오면 기존 `어휘(가나 보조)` 카드 144장은
물리적으로 남지만, Anki의 **빈 카드** 검사에 144장 모두 잡힙니다. 해당 카드는
앞면이 비었다는 화면만 표시합니다.

- Android·AnkiDroid: `⋮ → 확인 → 빈 카드`
- iPhone·iPad·AnkiMobile: `설정 → 빈 카드`
- Windows·macOS·Linux Anki: `도구 → 빈 카드`

목록에서 `JLPT MAX덱 어휘 / 어휘(가나 보조)`인지 확인한 뒤 **빈 카드 도구의
삭제**를 누릅니다. 이 작업은 가나 보조 카드와 그 카드의 복습 기록만 지웁니다.
같은 노트의 어휘·음성 카드는 남습니다. 카드 탐색기의 `노트 삭제`는 같은 노트의
다른 카드까지 지우므로 사용하면 안 됩니다. 더 오래된 버전이나 컬렉션 상태에
따라 표시 수는 달라질 수 있습니다.

![가나 보조 카드 정리 안내](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kana-cleanup-notice.png)

## 한자 쓰기 카드 2,337장 추가

- `한자::쓰기::상권`과 `한자::쓰기::하권`에 새 쓰기 카드 2,337장이 추가됩니다.
- 기존 읽기 카드는 `일상무따::상권·하권`에 그대로 남습니다. 새 읽기 덱을
  쓰려면 `한자::읽기::상권·하권`으로 직접 옮겨야 합니다.
- 쓰기 카드는 새 학습 항목이라 일정과 복습 기록을 처음부터 시작합니다.
- 화면에 직접 쓰기, 한 획 되돌리기, 모두 지우기, 정답 자형과 획순 다시 보기를
  지원합니다.
- 획순 SVG 2,298개와 SVG 자형이 깨지는 환경을 위한 PNG 자형 14개를 넣었습니다.

![한자 쓰기 카드 전체 화면](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-writing-full.png)

## 한자 읽기 카드에 발음별 단어·혼동 힌트 추가

기존 한자 카드 2,337장은 같은 카드 ID·일정·복습 기록을 유지한 채 새 읽기
화면으로 바뀝니다. 실제 단어를 음독·훈독별로 묶고, 현재 어휘에 단어가 없는
공식 상용한자 읽기도 표시합니다. 모양이 비슷한 한자는 뜻·음독·훈독을 함께
비교합니다.

일반 APKG 가져오기는 기존 카드의 덱 위치를 바꾸지 않습니다. 따라서 기존 카드는
`일상무따::상권·하권`이나 사용자가 옮겨 둔 덱에 그대로 남고, 새
`한자::읽기::상권·하권`은 비어 있을 수 있습니다. 새 폴더 구조를 쓰려면 카드
탐색기에서 기존 `일상무따::상권`과 `일상무따::하권`의 카드를 각각 선택해
`한자::읽기::상권`과 `한자::읽기::하권`으로 직접 옮기세요. 사용자가 따로 배치한
카드는 원하는 경우에만 옮기면 됩니다.

![음독과 훈독별 단어 묶음](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-reading-groups.png)

![헷갈리기 쉬운 한자 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-confusion-hints.png)

## 음성이 약간 느리게 재생되던 문제 수정

일부 카드에서 음성 앞쪽의 짧은 무음 때문에 재생이 약간 늦게 시작되는 느낌이
있었습니다. 디코딩된 음성의 첫 유효 소리 직전부터 재생하고, 같은 카드에서 다시
재생할 때는 찾은 위치를 재사용하도록 고쳤습니다. 원본 음성 파일 18,434개는
이전 승인본과 byte 단위로 같습니다.

## iPhone·iPad 무음 모드 재생을 기본값으로 변경

v1.3.0부터 iPhone·iPad의 기본 재생 방식을 바꿨습니다. 이전 버전에서는 다른 앱
음악과 카드 음성이 함께 재생되는 대신 무음 모드에서 카드 음성이 나오지 않을 수
있었습니다. 이제 기본값은 무음 모드에서도 카드 음성을 재생합니다. 이전 방식이
필요하면 카드 설정의 **다른 앱 음악과 함께 재생**을 켜면 됩니다. 이 옵션을 켜면
무음 모드에서는 카드 음성이 나오지 않을 수 있으며 선택값은 저장됩니다.

![iPhone과 iPad의 다른 앱 음악과 함께 재생 옵션](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.3.0/site/assets/releases/v1.3.0/gallery-v1.3.0-ios-audio-setting.png)

## 고저 악센트 읽기와 카드 배치 개선

- 단어 고저 악센트의 읽기 글자를 키웠습니다. 예문 읽기 크기는 그대로입니다.
- 긴 루비와 괄호 읽기가 서로 밀지 않도록 간격을 보정했습니다.

  이동을 줄였습니다.
- 덱에 포함한 일본어 글꼴을 한자·가나에 직접 적용해 Mac Anki에서 일부 글자가
  `□`로 보이던 문제를 수정했습니다.
- 한자 카드 앞뒤의 머리글 위치와 모바일 폭의 간격을 안정화했습니다.

## 오류 제보에 이메일 답장 옵션 추가

오류 제보는 계속 익명이 기본입니다. 답장을 원하는 경우에만 **이메일 답변 받기**에
동의하고 연락처를 입력합니다. 동의한 연락처는 제보와 분리해 암호화하고 수동
답장에만 사용하며, 답변 완료 시 또는 접수 90일 뒤 삭제합니다. 공개 처리 기록에는
제보 원문·연락처·기기 식별값을 넣지 않습니다.

## 검토된 뜻·읽기·예문 오류 교정

- `掛かる`, `沸騰`, `細かい`, `冷やす`, `断る`, `改札`, `定員`, `遠慮`의
  뜻과 예문 연결을 다시 검토했습니다.
- `長い`, `直る`, `改札`, `帯`, `合流`, `いらっしゃる`, `積む`, `負う`,
  `遥か`, `開拓`, `食い込む`, `連携`, `丘陵`, `くまなく`, `中毒`의 겹치거나
  부족한 예문을 정리했습니다.
- `届ける` 루비 경계, `何つ`→`幾つ`, 씨앗 `種`→`たね`, `通っている`→
  `かよっている`, `噛み癖`→`かみぐせ`를 고쳤습니다.
- `条件`·`設定`·`了承`의 읽기, `打診` 예문 번역과 이미지 한자 4건을 고쳤습니다.
- iPhone·iPad 재생 제보 6건은 새 기본 재생 방식으로 해결했습니다.
- 이번 기각 7건과 이전 기각 25건을 합친
  [기각 32건 전체 처리 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.3.0/docs/release-details/v1.3.0-dismissed-reports.md)을 공개합니다.
- 예전에 기각했던 가나 보조 카드 제보 81건은 카드 유형을 없애 해결했으므로 기각
  합계에서 뺐습니다.
- 사전 버튼 새 창 요청 1건은 기능 변경이 필요해 다음 릴리스 검토로 남겼습니다.

## 기본 APKG와 한자 빌더 구성

- public 기본 APKG: 13,903노트·19,921카드·미디어 18,437개
- 한자 addon: 4,674노트·4,674카드
- 두 APKG를 합친 전체: 18,577노트·24,595카드

기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는 빌더가
사용자의 지원 PDF 2개로 개인용 APKG를 만들어 합칩니다. 출판사 PDF 원문,
페이지 이미지와 추출 원문은 저장소나 배포 파일에 포함하지 않습니다.

## 사용 통계와 배포 안정성 개선

- 사용 통계를 켠 경우 업데이트 공지 이벤트가 통신 실패 뒤 다시 전송되고, 대기
  중인 같은 이벤트는 한 건으로 합쳐집니다.
- 업데이트 버전별 활동과 익명 설치 수 추정치를 추가했습니다. 이 변경은 사용
  통계를 새로 켜지 않으며 기존 선택을 그대로 따릅니다.
- 콘텐츠·미디어·APKG를 해시로 묶고 중단된 릴리즈 준비를 이어가도록 했습니다.
  사용자가 받는 APKG는 새 설치와 업데이트 검사를 통과한 같은 파일입니다.

## 알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 같은 카드 설정이 초기화됐다는 익명 제보 1건이 있었습니다.
JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았습니다. 저장 공간이 매우
부족할 때 iOS가 카드 화면의 저장값을 정리했을 가능성을 보고 있지만, 당시 상태를
추가 확인할 수 없어 원인은 확정하지 못했습니다.

같은 현상이 생기면 `설정 → 일반 → iPhone/iPad 저장 공간`의 여유 공간을 확인하고
카드 설정을 다시 저장해 주세요. 반복되면 남은 용량, iOS·AnkiMobile 버전과 앱
재실행 전후 중 언제 발생했는지를 오류 제보에 적어 주세요. 카드 화면 설정은 학습
기록·카드 데이터와 별도입니다.

- 기존 공통 카드 22,258개의 카드 ID·일정·복습 기록 유지 확인
- private 전체 18,577노트·24,595카드 확인
- public 기본 13,903노트·19,921카드 확인
- 한자 addon 4,674노트·4,674카드 구조 확인

  이미지 누락, 가로 넘침과 콘솔 오류가 없는지 확인

실물 iPhone·iPad와 Android의 모든 기기·앱 버전 조합은 이번 정식판에서 따로
전수 검증하지 않았습니다. 실제 배포 APKG의 새 설치·업데이트, 공개 기본 덱과
한자 빌더 구조, 해시와 생성 HTML 렌더링을 확인했습니다.
