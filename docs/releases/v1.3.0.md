# v1.3.0

v1.3.0은 한자 2,337자를 읽기와 쓰기로
나누고 획순 연습을 추가한 마이너 업데이트입니다. 기존 어휘·실전 문제·참조표의
안정 ID와 학습 기록은 이어지지만, 새 필드와 노트 유형을 적용하려면 기존 노트를
`항상` 업데이트하고 전체 동기화해야 합니다.

## 기존 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.3.0.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원
   PDF 2개로 한자 APKG를 다시 만들어 가져옵니다.
5. 모든 기기에서 전체 동기화합니다.

한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됩니다.

## 한자 읽기·쓰기

- 한자 2,337자마다 읽기 카드와 쓰기 카드를
  따로 만듭니다.
- 읽기 카드는 음독·훈독별 실제 단어와 공식 상용한자 읽기를 보여 줍니다.
- 쓰기 카드는 직접 쓰기, 정답 자형과 획순 확인 기능을 제공합니다.
- 모양이 비슷한 한자는 뜻·음독·훈독을 함께 보여 줍니다.

![v1.2.1과 v1.3.0의 한자 읽기 카드 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-reading-before-after.png)

## 기본 APKG와 한자 빌더

- public 기본 APKG: 13,903노트·20,065카드·미디어 18,437개
- 한자 addon: 4,674노트·4,674카드
- 두 APKG를 합친 전체: 18,577노트·24,739카드

기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는 빌더가
사용자의 지원 PDF 2개로 개인용 APKG를 만들어 합칩니다. PDF 원문은 저장소나
배포 파일에 포함되지 않습니다.

## 카드 화면·음성·오류 제보

- 한자 읽기 정보와 단어 고저 악센트 읽기의 모바일 가독성을 높였습니다.
- 디코딩된 음성의 앞쪽 무음을 재생할 때 건너뜁니다.
- iOS에서는 무음 모드에서도 카드 음성이 재생되도록 오디오 세션 기본값을
  바꿨습니다. 같은 증상이 다시 접수되면 기기와 카드별로 재조사합니다.
- 같은 뜻을 보여 주는 예문을 한 영역으로 묶었습니다.
- AnkiDroid 구형 학습 화면에서는 지원되는 새 학습 화면 안내를 표시합니다.
- 오류 제보는 계속 익명으로 보낼 수 있고, 답장을 원할 때만 연락처와 동의를
  함께 보낼 수 있습니다.

## 알려진 현상: iPhone·iPad 카드 설정 초기화

재생·후리가나 같은 카드 설정이 초기화됐다는 익명 제보 1건이 있었습니다.
JLPT MAX가 설정을 한꺼번에 지우는 동작은 확인되지 않았습니다. 현재는 기기
저장 공간이 매우 부족할 때 iOS가 카드 화면의 저장값을 정리했을 가능성을 가장
높게 보고 있습니다. 익명 제보라 당시 기기 상태를 추가로 확인할 수 없어 원인은
아직 확정하지 않았습니다.

같은 현상이 발생했다면 `설정 → 일반 → iPhone/iPad 저장 공간`에서 여유 공간을
확인하고, 공간을 확보한 뒤 카드 설정을 다시 저장해 주세요. 문제가 반복되면
오류 제보에 남은 용량, iOS·AnkiMobile 버전과 앱 재실행 전후 중 언제
발생했는지를 함께 적어 주세요. 이 설정값은 Anki의 학습 기록·카드 데이터와
별도로 저장되므로 학습 기록이나 카드가 초기화되는 현상은 아닙니다.

## 오류 제보 처리 결과

- `進学塾`의 올바른 쓰임을 묻는 문제는 `通っている`의 후리가나를
  `とおっている`에서 문맥에 맞는 `かよっている`로 고쳤습니다.
- `届ける` 예문의 루비 경계, 수 세기 `幾つ`, 씨앗을 뜻하는 `種`,
  `噛み癖`, `条件`·`設定`의 읽기, `了承` 예문 후리가나와 제보된 이미지 한자
  4건을 고쳤습니다.
- iOS 재생 제보 6건은 새 오디오 기본값으로 해결 처리했습니다. 번역·표기·음성
  입력이 맞거나 공개 패키지에서 재현되지 않은 7건은 이유를 기록하고
  기각했습니다.
- 사전 버튼을 새 창으로 여는 요청 1건은 기능 변경이 필요해 다음 릴리스 검토로
  남겼습니다.
- 사유 저장 기능 도입 전에 닫힌 제보 160건도 기존 검토 기록과 반영 내역을
  대조해 55개 처리 사유로 소급 정리했습니다. 이번 기각 7건과 이전 기각 106건을
  합친 [기각 113건 전체 처리 내역](https://github.com/truthyblue/jlpt-max-deck/blob/v1.3.0/docs/release-details/v1.3.0-dismissed-reports.md)에서
  대상 카드와 이유를 확인할 수 있습니다.

처리 결과는 제보 원문이나 연락처 없이 익명으로 알립니다. 수정하거나 현행 표기를
유지하기로 한 제보는 공개 가능한 처리 사유와 공지 버전을 함께 기록합니다.
