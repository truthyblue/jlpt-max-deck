# v1.3.0

v1.3.0은 한자 2,337자를 읽기와 쓰기로
나누고 획순 연습을 추가한 마이너 업데이트입니다. 기존 어휘·실전 문제·참조표의
안정 ID와 학습 기록은 이어지지만, 새 필드와 노트 유형을 적용하려면 기존 노트를
`항상` 업데이트하고 전체 동기화해야 합니다.

## 기존 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내고 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.3.0.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 항상**,
   **노트 유형 병합 → 켜기**를 선택합니다.
4. 한자 확장을 사용한다면 `JLPT-MAX-kanji-builder-1.3.0.zip`과 지원
   PDF 2개로 한자 APKG를 다시 만들어 가져옵니다.
5. 모든 기기에서 전체 동기화합니다.

한자 확장을 쓰지 않으면 기본 APKG만 가져오면 됩니다.

## 한자 읽기·쓰기

- 한자 2,337자마다 읽기 카드와 쓰기 카드를
  따로 만듭니다.
- 읽기 카드는 음독·훈독별 실제 단어와 공식 상용한자 읽기를 보여 줍니다.
- 쓰기 카드는 직접 쓰기, 정답 자형과 획순 확인 기능을 제공합니다.
- 모양이 비슷한 한자는 뜻·음독·훈독을 함께 보여 줍니다.

![v1.2.1과 v1.3.0의 한자 읽기 카드 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/main/site/assets/releases/v1.3.0/gallery-v1.3.0-kanji-reading-before-after.png)

## 기본 APKG와 한자 빌더

- public 기본 APKG: 13,903노트·20,065카드·미디어 18,437개
- 한자 addon: 4,674노트·4,674카드
- 두 APKG를 합친 전체: 18,577노트·24,739카드

기본 APKG에는 어휘·음성·종합 실전·참조표만 들어 있습니다. 한자는 빌더가
사용자의 지원 PDF 2개로 개인용 APKG를 만들어 합칩니다. PDF 원문은 저장소나
배포 파일에 포함되지 않습니다.

## 카드 화면·음성·오류 제보

- 한자 읽기 정보와 단어 고저 악센트 읽기의 모바일 가독성을 높였습니다.
- 디코딩된 음성의 앞쪽 무음을 재생할 때 건너뜁니다.
- 같은 뜻을 보여 주는 예문을 한 영역으로 묶었습니다.
- AnkiDroid 구형 학습 화면에서는 지원되는 새 학습 화면 안내를 표시합니다.
- 오류 제보는 계속 익명으로 보낼 수 있고, 답장을 원할 때만 연락처와 동의를
  함께 보낼 수 있습니다.
