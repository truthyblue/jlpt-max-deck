# v1.0.3

1.0.3은 공개 1.0.2의 노트·카드 구조와 사용법은 유지하면서, 학습자가 실제로
외울 뜻과 그 뜻을 보여 주는 예문을 더 정확하고 분명하게 다듬고 모바일 음성
재생과 답면 조작을 개선한 업데이트입니다.

## 1.0.2 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.0.3.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기**는 끄고, **기존 노트 업데이트**와
   **노트 유형 병합**은 켭니다.

기존 어휘·음성·실전 문제·참조표의 카드와 학습 기록은 그대로 유지됩니다.
기존 조작 방법은 그대로 사용할 수 있고, 답면에는 예문 한국어만 따로 가리는
**해석 켬/끔** 버튼이 추가됩니다. 내부 음성 재생 방식도 혼합 재생으로
바뀝니다.

이미 만든 일상무따 한자 확장도 계속 사용할 수 있습니다. 다만 한자 카드의
연결 어휘 89개에서 이번에 바뀐 뜻까지 보고 싶다면 같은 v1.0.3 한자 빌더로
확장을 다시 만든 뒤 기존 컬렉션에 가져오세요. 한자 카드의 학습 기록은
유지됩니다.

## 이번 업데이트

- 어휘 208개의 학습용 뜻을 실제 쓰임과 의미 구분이 더 잘 드러나도록
  고쳤습니다.
- 158개 단어에는 빠져 있던 독립 의미 165개를 추가했습니다. 새 의미에도
  그 뜻을 직접 보여 주는 예문과 음성을 붙였습니다.
- 50개 단어는 뜻의 범위를 좁히거나 자연스러운 한국어로 다듬었습니다.
  예를 들어 `克明`은 `정밀하다`에서 `세세하고 꼼꼼하다`로 바뀝니다.
- 의미와 함께 바뀌어야 하는 예문·번역·활용·관련어·사용 정보와 실전 문제
  77개의 한국어 정답 표시를 같은 기준으로 맞췄습니다.
- 최종 예문은 6,681개이며, 모든 어휘 6,018개에 적어도 하나의 예문이 있습니다.
- 표제어·예문·실전 답 음성을 하나의 Web Audio 재생기로 통합했습니다. 모바일에서
  다른 앱의 음악과 함께 재생해도 음악 볼륨을 유지합니다.
- 어휘·음성 답면에서 예문 한국어만 따로 가릴 수 있습니다. 해석 표시 선택은
  같은 기기에 저장됩니다.
- 후리가나·해석·재생 컨트롤을 글자 줄 높이에 맞게 정렬하고, 어휘 한자 정보의
  큰 글자가 네모 칸 아래로 튀어나오지 않도록 고쳤습니다.

## 음악과 함께 복습할 때

iPhone·iPad와 Android 휴대폰에서 음악 앱을 틀어 둔 채 카드 음성을 재생해도
배경 음악이 줄어들거나 멈추지 않습니다. 자동재생 범위와 음성을 다시 듣는 방법은
기존과 같습니다. iPhone·iPad의 무음 모드에서는 카드 음성도 나오지 않는 것이
정상입니다.

Bluetooth·Android Auto 동작은 연결 기기와 앱 버전에 따라 달라질 수 있습니다.
문제가 있으면 Anki 버전, 휴대폰 기종과 연결 방식을 함께 알려 주세요.

## 일본어 예문을 먼저 해석할 때

어휘·음성 답면의 **해석 켬/끔** 버튼으로 예문의 한국어 번역만 숨길 수 있습니다.
후리가나는 별도 버튼으로 계속 조절할 수 있어, 일본어 문장을 먼저 읽고 뜻을
스스로 떠올린 뒤 필요한 정보만 다시 확인할 수 있습니다. 두 버튼은 화면 폭이
좁아도 같은 줄에서 자연스럽게 정렬됩니다.

한자 정보를 펼쳤을 때 큰 한자 글자도 네모 칸 안에 맞게 표시됩니다.

## 대표적인 전후 사례

| 단어 | 1.0.2 | 1.0.3 | 학습할 때 좋아지는 점 |
| --- | --- | --- | --- |
| `上がる` | 오르다 | 오르다 / 실내로 들어가다 / 비가 그치다 | 문장에 따라 전혀 달라지는 용법을 따로 외울 수 있습니다. |
| `打ち込む` | 몰두하다 / 박아 넣다 | 몰두하다 / 박아 넣다 / 데이터를 입력하다 | 컴퓨터 문맥의 현대 용법을 놓치지 않습니다. |
| `払う` | 지불하다 | 지불하다 / 털어 내다 | 돈을 내는 뜻과 먼지 등을 털어 내는 뜻을 구별합니다. |
| `司会` | 사회 | 사회(회의·행사 진행) | 한국어의 ‘사회’ 일반 개념과 혼동하지 않습니다. |
| `克明` | 정밀하다 | 세세하고 꼼꼼하다 | 설명·기록·묘사가 자세하고 빈틈없다는 느낌이 더 잘 드러납니다. |

실제 v1.0.3 카드에서는 새 뜻이 다음 문장처럼 제시됩니다.

- `上がる`
  - `どうぞと言われて部屋に上がる。` — 들어오라는 말을 듣고 방으로 들어간다.
  - `昼過ぎに雨が上がる。` — 오후에 비가 그친다.
- `打ち込む`
  - `パソコンにデータを打ち込む。` — 컴퓨터에 데이터를 입력한다.
- `払う`
  - `コートに付いたほこりを払う。` — 코트에 묻은 먼지를 털어 낸다.
- `司会`
  - `彼女が会議の司会をする。` — 그녀가 회의의 사회를 본다.
- `克明`
  - `日記には当時の生活が克明に記されている。` — 일기에는 당시 생활이 세세하고 꼼꼼하게 기록되어 있다.
