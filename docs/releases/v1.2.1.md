# v1.2.1

v1.2.1은 뜻 표시 순서와 예문 순서를 맞추고, 슬래시로 나뉜 뜻의 예문을
흰색 영역으로 나눠 보여 주는 패치입니다.

## v1.2.0 사용자의 업데이트 절차

1. 모든 기기의 Anki 동기화를 끝내거나 컬렉션 백업을 확인합니다.
2. `JLPT-MAX-Deck-1.2.1.apkg`를 기존 덱을 삭제하지 않고 가져옵니다.
3. **학습 진행 상태 가져오기 → 끄기**, **기존 노트 업데이트 → 새 버전일 때**,
   **노트 유형 병합 → 켜기**를 선택합니다.

마지막 숫자만 바뀌는 패치이므로 **새 버전일 때**를 선택합니다. 한자 확장의
내용은 바뀌지 않아 기존 v1.2.0 한자 확장을 그대로 쓸 수 있습니다.

## 뜻과 예문 순서

어휘 102개의 예문을 카드에 보이는 뜻 순서대로 다시 배치했습니다. `取る`의
뜻은 `잡다 · 집다 · 들다 / 빼앗다 / 얻다 / 없애다`이며, 예문도 다음
순서로 표시됩니다.

1. 잡다
2. 집다
3. 들다
4. 빼앗다
5. 얻다
6. 없애다

예문 내용과 음성은 바꾸지 않았습니다.

## 슬래시 뜻 묶음 표시

슬래시(`/`)로 나뉜 뜻이 여러 개인 어휘 651개는 각 뜻 묶음의 예문을 별도
흰색 영역에 담습니다. 같은 묶음 안의 뜻과 예문은 하나의 영역에 함께 들어가고,
묶음 이름을 반복하는 칩은 추가하지 않았습니다.

![v1.2.0과 v1.2.1의 뜻 묶음별 예문 표시 비교](https://raw.githubusercontent.com/truthyblue/jlpt-max-deck/v1.2.1/site/assets/releases/v1.2.1/gallery-v1.2.1-meaning-groups-before-after.png)

## 유지되는 것

- 기본 덱 노트 13,903개, 카드 20,065개, 미디어 18,438개
- 전체 구성 노트 16,240개, 카드 22,402개
- 기존 GUID, 노트 유형 ID, 학습 기록과 스케줄
- 음성 18,435개와 한자 확장 내용
- 공식 사이트와 카드 안의 최신 버전 안내는 프리릴리스 동안 v1.2.0 유지

## 검증

Anki 25.09.2의 폐기 가능한 컬렉션에서 v1.2.0 기본 덱을 가져온 뒤 v1.2.1을
**새 버전일 때**로 가져왔습니다.

- 공유 노트 13,903개가 v1.2.1 내용과 일치
- 새 노트 0개, 충돌 0개
- 컬렉션을 닫았다가 다시 연 뒤 카드 템플릿과 CSS가 새 버전과 일치
- 검사용으로 바꾼 카드의 학습 일정이 그대로 유지
- 390×1600 모바일 미리보기에서 가로 넘침 없음

실물 iPhone·iPad와 Android에서는 이번 후보를 따로 재검증하지 않았습니다.
