00 · 먼저

먼저 모든 기기를 동기화하세요.

여러 기기를 쓴다면 각 기기의 최신 복습 기록이 AnkiWeb에 반영됐는지 확인합니다. 가능하면 컬렉션 백업도 확인하세요.

최상위 JLPT MAX덱을 삭제하지 마세요.

기존 카드와 학습 일정은 그대로 두고 새 덱 파일을 가져오면 됩니다.

03 · 새 어휘 순서

학습하지 않은 급수만 새 중요도 순서로 다시 넣으세요.

v2.0.3은 각 급수 안에서 BCCWJ 중요도 순으로 새 카드가 나옵니다. Anki는 기존 카드의 순서와 학습 일정을 보존하므로 가져오기만 해서는 이미 있는 카드가 다시 배열되지 않습니다.

이미 한 장이라도 학습한 급수는 정렬만을 위해 삭제하지 마세요.

학습 기록을 지우는 것보다 기존 순서를 유지하는 편이 안전합니다.

  1. 완전히 미학습 상태인 급수인지 확인합니다.

    복습 기록이나 일정이 하나라도 있다면 이 절차를 건너뜁니다.

  2. 그 급수의 어휘 덱과 음성 덱을 함께 삭제합니다.

    예: N2라면 JLPT MAX덱::어휘::N2와 JLPT MAX덱::음성::N2를 둘 다 삭제합니다.

  3. JLPT-MAX-Deck-2.0.3.apkg를 다시 가져옵니다.

    학습 진행 상태는 끄고, 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 둡니다.

04 · 빈 카드

예전 가나 보조와 삭제된 카드를 정리하세요.

Anki는 새 덱을 가져와도 예전 카드를 자동으로 지우지 않습니다. 출발 버전과 개인 컬렉션 상태에 따라 표시 수는 달라질 수 있습니다.

v1.2.1 이하에서 업데이트

가나 보조

JLPT MAX덱 어휘 / 어휘(가나 보조) 빈 카드를 삭제합니다. 앞면에서 히라가나만 나오던 예전 카드입니다.

05 · 필요할 때만

음성 카드가 어휘 덱에 나오면 위치만 고치세요.

일부 하위 덱만 삭제한 뒤 APKG를 다시 가져오면 같은 노트의 다른 카드가 남아 있던 덱으로 들어갈 수 있습니다. 신규 설치나 하위 덱을 삭제하지 않은 일반 업데이트는 대부분 해당하지 않습니다.

먼저 백업하고 검색된 카드를 삭제하지 마세요.

아래 작업은 카드의 덱 위치만 바꿉니다. 복습 기록과 일정은 유지됩니다.

  1. 카드 탐색기에서 잘못 놓인 음성 카드를 찾습니다.
    note:"JLPT MAX덱 어휘" card:음성 -deck:"JLPT MAX덱::음성"

    검색 결과가 0이면 정상입니다. 아래 복구는 건너뜁니다.

  2. 결과가 있으면 N1부터 N5까지 급수별로 검색합니다.
    note:"JLPT MAX덱 어휘" card:음성 tag:jlpt::N1

    N1을 N2·N3·N4·N5로 바꿔 한 번씩 실행합니다. 검색 결과를 모두 선택하고 덱 변경에서 같은 급수의 JLPT MAX덱::음성::N○로 이동합니다.

  3. 어휘·한→일 하위 덱도 삭제한 적이 있다면 함께 확인합니다.
    note:"JLPT MAX덱 어휘" card:어휘 -deck:"JLPT MAX덱::어휘"
    note:"JLPT MAX덱 어휘" card:"어휘(한국어→일본어)" -deck:"JLPT MAX덱::한→일"

    결과가 있으면 같은 방식으로 tag:jlpt::N1부터 N5까지 나누어 어휘 카드는 어휘::해당 급수, 한→일 카드는 한→일::해당 급수로 이동합니다.

  4. 첫 검색을 다시 실행해 결과가 0인지 확인합니다.

    한 기기에서 복구를 끝낸 뒤 동기화하고, 그다음 다른 기기를 사용하세요.

06 · 설정

업데이트한 뒤에는 실전 설정만 확인하세요.

개인 설정은 그대로 유지됩니다. 음성 덱의 새 카드 수를 포함한 나머지 옵션은 지금 설정을 그대로 두세요.

신규 카드 수집을 무작위 노트로 바꿉니다. 급수 덱을 눌렀을 때 문제 유형이 섞여 나옵니다.

07 · 확인

업데이트가 잘 됐는지 확인하세요.

  1. 전에 공부한 어휘 몇 장의 복습 일정이 그대로인지 확인합니다.
  2. 새 카드 내용과 템플릿이 반영됐는지 확인합니다.
  3. 실전의 신규 카드 수집이 무작위 노트인지 확인합니다.
  4. 기존 한자 확장은 v2.0.3 빌더로 다시 만듭니다.

    한자 2,337개에 읽기와 쓰기 노트를 각각 만들고, 쓰기 순서가 포함된 카드 4,674장을 적용합니다.

  5. 기존 한자 읽기 카드는 현재 덱에 그대로 남습니다.

    일반 APKG 가져오기는 덱 위치를 바꾸지 않으므로 한자::읽기::상권·하권은 비어 있을 수 있습니다. 새 폴더 구조를 쓰려면 카드 탐색기에서 기존 일상무따 상권·하권 카드를 읽기 상권·하권으로 직접 옮기세요.

  6. 가져오기가 끝나면 모든 기기에서 다시 전체 동기화합니다.
  7. 교체된 예전 음성이 남으면 데스크톱 Anki의 도구 → 미디어 검사에서 정리합니다.

    새 카드와 음성이 정상인지 확인하고 모든 기기의 미디어 동기화를 끝낸 뒤, 미사용 파일 목록을 확인해 삭제하고 다시 동기화합니다. 다른 덱의 미사용 파일도 함께 표시될 수 있으므로 목록을 먼저 확인하세요. 삭제한 파일은 운영체제 휴지통에서 복구할 수 있습니다.
