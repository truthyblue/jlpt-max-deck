Anki 설치

내 기기에 맞는
Anki를 설치하세요.

데스크톱은 Anki, iPhone·iPad는 공식 AnkiMobile, Android는 무료 오픈소스 AnkiDroid를 사용합니다.

설치 순서
  1. 앱 선택
  2. 첫 실행
기기 선택

공부할 기기의 Anki를 설치합니다.

아래에서 사용할 기기를 고르세요. iPhone·iPad의 공식 앱은 AnkiMobile Flashcards, Android 앱은 무료 오픈소스 AnkiDroid입니다.

macOS

Anki Desktop for Mac

Apple Silicon 또는 Intel 항목을 Mac 사양에 맞게 선택합니다.

  1. DMG 다운로드
  2. Anki를 응용 프로그램으로 이동
  3. 첫 실행 후 프로필 생성
공식 다운로드 ↗
WINDOWS

Anki Desktop for Windows

대부분의 PC는 Windows x64 설치 파일을 사용합니다.

  1. 설치 파일 다운로드
  2. 설치 마법사 완료
  3. Anki 실행 후 프로필 생성
공식 다운로드 ↗
LINUX

Anki Desktop for Linux

공식 패키지의 지원 배포판과 아키텍처 조건을 먼저 확인합니다.

  1. 공식 패키지 다운로드
  2. 설치 안내 실행
  3. Anki 실행 후 프로필 생성
공식 다운로드 ↗
iPHONE · iPAD

AnkiMobile Flashcards

공식 iOS 앱입니다. 구독이 아닌 유료 구매이며, 가격은 App Store에서 확인하세요.

  1. App Store에서 개발자 확인
  2. AnkiMobile 설치
  3. APKG 열기 또는 AnkiWeb 동기화
App Store ↗
ANDROID

AnkiDroid Flashcards

무료 오픈소스 Android 앱입니다. AnkiWeb 동기화와 APKG 가져오기를 지원합니다.

  1. Google Play에서 앱 확인
  2. AnkiDroid 설치
  3. APKG 열기 또는 AnkiWeb 동기화
Google Play ↗
AnkiWeb은 앱을 대신하지 않습니다.

브라우저의 AnkiWeb은 동기화와 간단한 학습용입니다. 기본 덱 APKG는 공부할 기기에 설치한 앱에 가져오세요.

다음 단계

설치가 끝났으면 기본 덱을 넣습니다.

  1. 설치한 앱을 한 번 실행합니다.

    앱에 표시되는 첫 실행 안내를 완료합니다.

  2. 기본 덱 APKG를 다운로드합니다.

    기본 덱 파일 JLPT-MAX-Deck-1.0.1.apkg을 받습니다.

  3. 시작 가이드의 가져오기 순서를 따릅니다.

    처음 설치와 기존 버전 업데이트의 옵션 차이를 확인하세요.
