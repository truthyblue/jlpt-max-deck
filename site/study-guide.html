01 · 어휘

어휘 학습

N2 시험을 본다면 N5 → N4 → N3 → N2, N4 시험을 본다면 N5 → N4 순서입니다. 지금 공부하는 급수의 새 카드가 0장이 되면 다음 급수로 넘어갑니다. 앞서 공부한 급수의 복습은 계속하세요.

처음에는 어휘::N5만 누르면 됩니다.

그 아래 덱이나 태그를 따로 고르지 않아도 됩니다. 이미 아는 단어는 Easy로 빠르게 넘기세요.

어휘 카드 채점

Again

틀림

읽기나 뜻을 틀렸거나 하나라도 기억나지 않았다면 누릅니다.

Hard

불확실

답은 맞았지만 오래 걸렸거나 확신이 없었다면 누릅니다.

Good

맞음

읽기와 뜻을 무리 없이 떠올렸다면 누릅니다.

Easy

이미 앎

보자마자 바로 알았다면 누릅니다.

하루 학습 순서

  1. 밀린 복습부터 합니다.

    복습이 쌓였다면 새 카드를 0장으로 줄이세요.

  2. 앞서 공부한 급수의 복습을 합니다.

    N4를 공부하고 있다면 N5 복습부터 끝냅니다.

  3. 지금 공부하는 급수의 복습과 새 카드를 봅니다.

    새 카드는 하루 20장이 기본이며, 부담되면 10장으로 줄이세요.

이미 아는 카드가 많아 Easy로 금방 넘길 수 있고 다음 날 복습도 적다면 새 카드 수를 늘려도 됩니다.

N5 하위 덱

어휘::N5 덱을 누르면 수량 표현, 날짜, 월, 요일 하위 덱도 함께 나옵니다. 하위 덱을 따로 누르지 않아도 됩니다. 참조표는 외우는 덱이 아니라 헷갈릴 때 찾아보는 자료입니다.

선택 · 필터 덱

여러 급수 함께 보기

처음이라면 이 부분은 건너뛰고 위 안내대로 어휘::N5부터 공부해도 됩니다. 앞서 공부한 급수의 복습과 현재 급수의 새 카드를 한곳에서 보고 싶다면 필터 덱을 설정하세요.

필터 덱 설정 보기처음에 한 번 설정해야 하는 선택 기능입니다.
필터 덱이란?

원래 덱을 합치거나 카드를 복사하는 기능이 아닙니다. 검색 조건에 맞는 카드를 잠시 한곳에 모아 보여 주며, 학습 기록과 다음 복습 일정은 원래 덱에 그대로 남습니다.

필터 덱 만들기

ANKI DESKTOP

PC

  1. Anki의 덱 목록으로 이동
  2. 도구 → 필터 덱 만들기 누르기
ANKIMOBILE

iPhone·iPad

  1. 어휘 덱 하나를 열어 학습 화면으로 이동
  2. 오른쪽 아래 톱니바퀴 → Filter/Cram 누르기
ANKIDROID

Android

  1. 덱 목록 오른쪽 아래 + 누르기
  2. 필터 덱 만들기 누르기
메뉴 이름은 표시 언어나 앱 버전에 따라 조금 다를 수 있습니다.

Filtered Deck, Filter/Cram, 필터 덱이 들어간 항목을 찾으세요.

필터 조건 입력

검색식은 Anki가 가져올 카드를 고르는 조건입니다. 내용을 이해하거나 외울 필요 없이 아래 값을 그대로 복사하면 됩니다.

복습용 필터

필터 1

N5부터 응시 급수까지 오늘 복습할 카드를 모두 모읍니다.

새 카드용 필터

필터 2

지금 공부 중인 한 급수에서 새 카드 20장만 모읍니다.

먼저 복습용 필터에 넣을 값을 고릅니다. 아래에서 응시 급수를 선택하세요.

복습용 필터 · N5 응시 · N5 복습

deck:"JLPT MAX덱::어휘::N5" is:due

한도 9999장 · 선택 기준: Relative overdueness

복습용 필터 · N4 응시 · N5–N4 복습

(deck:"JLPT MAX덱::어휘::N5" or deck:"JLPT MAX덱::어휘::N4") is:due

한도 9999장 · 선택 기준: Relative overdueness

복습용 필터 · N3 응시 · N5–N3 복습

(deck:"JLPT MAX덱::어휘::N5" or deck:"JLPT MAX덱::어휘::N4" or deck:"JLPT MAX덱::어휘::N3") is:due

한도 9999장 · 선택 기준: Relative overdueness

복습용 필터 · N2 응시 · N5–N2 복습

(deck:"JLPT MAX덱::어휘::N5" or deck:"JLPT MAX덱::어휘::N4" or deck:"JLPT MAX덱::어휘::N3" or deck:"JLPT MAX덱::어휘::N2") is:due

한도 9999장 · 선택 기준: Relative overdueness

복습용 필터 · N1 응시 · N5–N1 복습

(deck:"JLPT MAX덱::어휘::N5" or deck:"JLPT MAX덱::어휘::N4" or deck:"JLPT MAX덱::어휘::N3" or deck:"JLPT MAX덱::어휘::N2" or deck:"JLPT MAX덱::어휘::N1") is:due

한도 9999장 · 선택 기준: Relative overdueness

새 카드용 필터 · 처음에는 N5

deck:"JLPT MAX덱::어휘::N5" is:new

한도 20장 · 선택 기준: Order due

  1. 덱 이름을 어휘 통합 학습으로 정합니다.
  2. 필터 1의 검색 칸에 응시 급수용 복습 조건을 넣습니다.

    한도는 9999장, 선택 기준은 Relative overdueness로 둡니다. 복습이 더 급한 카드부터 나옵니다.

  3. 두 번째 필터 사용을 켜고 필터 2에 N5 새 카드 조건을 넣습니다.

    한도는 하루 학습량인 20장, 선택 기준은 Order due로 둡니다. N5 안에서 먼저 볼 카드부터 나옵니다.

  4. 카드 일정 다시 잡기를 켜고 만들기(Build)를 누릅니다.

    덱 목록에 어휘 통합 학습이 생기면 완료입니다.

필터 덱을 쓸 때는 이 덱 하나만 열면 됩니다.

어휘 통합 학습을 열고 다시 만들기(Rebuild)를 누른 뒤, 모인 복습과 새 카드를 모두 봅니다. 다시 만들기는 저장한 검색 조건을 다시 실행해 오늘 공부할 카드를 불러오는 기능이며, 학습 기록을 초기화하지 않습니다.

한 급수의 새 카드가 끝나면 새 카드용 필터만 바꾸세요.

다시 만들기 직후 새 카드가 0장이면 필터 2의 N5를 N4로 바꿉니다. 이후에도 N5 → N4 → N3 → N2 → N1 순서로 올리되, 시험 볼 급수에서 멈추세요. 복습용 필터는 그대로 두므로 앞 급수의 복습은 계속 나옵니다.

02 · 한자

한자 읽기·쓰기

1권이 상권이고 2권이 하권입니다. 한자 2,337개마다 읽기 카드와 쓰기 카드가 하나씩 있습니다.

  1. N3 어휘 + 1권(상권)

    N3 어휘를 시작할 때 1권 덱도 함께 시작합니다.

  2. N2·N1 어휘 + 2권(하권)

    N2 어휘를 시작할 때 2권 덱도 함께 시작하세요. 이미 N1을 공부하고 있다면 2권 덱을 지금 시작하면 됩니다.

읽기로 익힌 뒤 쓰기로 확인하세요.

읽기 카드에서 뜻과 읽기를 익히고, 쓰기 카드에서 획순을 따라 써 봅니다. 복습을 먼저 끝내고 부담되면 한자 새 카드를 10장으로 줄이세요. 복습이 밀렸다면 새 카드를 0장으로 둡니다.

03 · 종합 실전

종합 실전

시험 볼 급수까지 어휘를 모두 한 번 본 뒤 시작합니다. N4 시험을 본다면 종합 실전::어휘::N4만, N2 시험을 본다면 종합 실전::어휘::N2만 누르세요. 실전 문제는 N5부터 차례대로 풀 필요가 없습니다.

급수 덱을 누르면 한자 읽기·표기·문맥 규정·유의 표현·용법 문제가 무작위 노트 순서로 골고루 섞여 나옵니다. 한 유형만 따로 연습하고 싶을 때만 그 하위 덱을 누르세요.

기존 사용자는 실전 설정을 확인하세요.

JLPT MAX덱 · 실전 → 신규 카드 수집을 무작위 노트로 바꿉니다. 다른 개인 설정은 유지하세요. 자세한 순서는 업데이트 뒤 권장 설정에 있습니다.

그날 복습을 먼저 끝내고 새 문제를 하루 20개씩 푸세요. 틀렸거나 찍어서 맞혔다면 Again, 답은 맞았지만 풀이 근거가 불확실했다면 Hard, 근거까지 확실히 알았다면 Good을 누릅니다.

선택 · 음성

음성 덱

소리만 듣고 단어를 떠올리는 연습용이며 처음에는 덱 목록에서 접혀 있습니다. 이미 음성 카드를 공부하고 있다면 지금 새 카드 설정을 유지하세요.

처음 시작한다면 하루 5–10장부터 보세요. 문장을 듣고 이해하는 청해 연습은 나중에 별도 청해 덱으로 보강할 예정입니다.
