한자 읽기·쓰기 덱

직접 완성

저작권 때문에 한글 뜻이 든 완성본을 배포하지 않습니다. 공식 PDF 2개를 사용자의 컴퓨터에서 읽어 한자 2,337개의 읽기·쓰기 카드를 담은 개인용 APKG를 만듭니다.

한자 덱은 선택 사항입니다.

기본 덱만으로 문법·어휘·음성·실전 문제·참조표를 모두 학습할 수 있습니다. 한자 읽기·쓰기도 공부할 때만 아래 과정을 진행하세요.

공부 순서

추천 학습 순서

1권이 상권이고 2권이 하권입니다. N5와 N4는 어휘만 공부하고, N3 어휘를 시작할 때 1권(상권)을 함께 시작하세요. N2 어휘를 시작할 때는 2권(하권)을 함께 시작하고, 이미 N1을 공부하고 있다면 2권을 지금 시작하면 됩니다.

읽기로 익힌 뒤 쓰기로 확인하세요.

한 글자마다 읽기 카드와 쓰기 카드가 하나씩 있습니다. 부담되면 한자 새 카드를 10장으로 먼저 줄입니다. 자세한 조절 방법은 덱 학습법에서 확인하세요.

01 · 준비물

준비물

  1. 한자 빌더 ZIP

    현재 기본 덱과 같은 v2.1.1 파일을 사용합니다.

  2. 1권 지원 소책자 PDF

    길벗 공식 자료 페이지에서 제공 방식과 이용 조건을 확인하고 받은 원본입니다.

  3. 2권 지원 소책자 PDF

    1권과 2권을 각각 받아 두세요. 첫 번째 선택창에는 1권, 두 번째에는 2권을 고릅니다.

  4. macOS 또는 Windows 컴퓨터

    처음 실행할 때 필요한 프로그램을 자동으로 받으므로 인터넷 연결이 필요합니다. 완성된 APKG는 다른 Anki 기기로 옮겨 학습할 수 있습니다.

03 · 빌더

한자 빌더 받기

한자 덱 만들기 · v2.1.1

JLPT-MAX-kanji-builder-2.1.1.zip

출력: JLPT-MAX-kanji-addon-2.1.1.apkg

다운로드 ↓
  1. Windows는 ZIP을 마우스 오른쪽 버튼으로 누릅니다.

    모두 압축 풀기를 선택하고, 새로 생긴 폴더를 엽니다.

  2. macOS는 ZIP을 더블클릭합니다.

    압축이 풀리면서 생긴 JLPT-MAX-kanji-builder 폴더를 엽니다.

ZIP 안에서 바로 실행하지 마세요.

반드시 압축을 푼 폴더에서 실행해야 합니다. assets 폴더는 제작용이므로 그 안의 파일을 Anki에 직접 넣지 마세요.

04 · 실행

한자 빌더 실행

  1. Mac에서 한자 확장 만들기.command를 더블클릭합니다.

    터미널을 따로 열거나 명령어를 입력하지 않습니다.

  2. 첫 번째 창에서 1권 PDF를 고릅니다.

    화면에는 1권(상권)의 지원 소책자 PDF라고 표시됩니다.

  3. 두 번째 창에서 2권 PDF를 고릅니다.

    같은 파일을 두 번 고르면 안전하게 중단됩니다.

  4. 완료 안내가 나올 때까지 기다립니다.

    처음 실행할 때만 필요한 프로그램을 자동으로 준비합니다. 열린 창을 닫지 마세요.

  1. Windows에서 한자 확장 만들기.cmd를 더블클릭합니다.

    PowerShell을 직접 열거나 명령어를 입력하지 않습니다.

  2. 첫 번째 창에서 1권 PDF를 고릅니다.

    화면에는 1권(상권)의 지원 소책자 PDF라고 표시됩니다.

  3. 두 번째 창에서 2권 PDF를 고릅니다.

    같은 파일을 두 번 고르면 안전하게 중단됩니다.

  4. 완료 안내가 나올 때까지 기다립니다.

    처음 실행할 때만 필요한 프로그램을 자동으로 준비합니다. 열린 창을 닫지 마세요.

한글이나 띄어쓰기가 있는 폴더도 사용할 수 있습니다.

PDF와 빌더 폴더의 위치는 서로 달라도 됩니다. 파일 선택창에서 실제 PDF를 고르면 됩니다.

완성한 APKG 가져오기

문제 해결

실행 파일이 보이지 않아요.
ZIP 미리보기 안이 아니라 압축을 푼 새 폴더를 열었는지 확인하세요. Windows에는 Windows에서 한자 확장 만들기.cmd, macOS에는 Mac에서 한자 확장 만들기.command가 있습니다.
필요한 프로그램을 받지 못했다고 나와요.
처음 실행에만 인터넷 연결이 필요합니다. 연결을 확인하고 ZIP을 새 폴더에 다시 푼 뒤 실행 파일을 다시 여세요. Python이나 별도 프로그램을 직접 설치할 필요는 없습니다.
PDF hash 또는 page count 오류가 나요.
공식 자료 페이지에서 받은 원본 PDF인지, 첫 번째 창에 1권을 고르고 두 번째 창에 2권을 골랐는지 확인하세요. 다시 저장·병합·최적화한 파일은 사용할 수 없습니다.
중간에 PDF 선택을 취소했어요.
아무 파일도 바뀌지 않습니다. 실행 파일을 다시 더블클릭하고 처음부터 선택하면 됩니다.
완성 파일을 다시 만들고 싶어요.
실행 파일을 다시 열면 기존 결과를 지우고 새로 만들지 묻습니다. 필요한 APKG를 다른 곳에 복사한 뒤 다시 만들기를 선택하세요.
오류가 계속되면 kanji-builder.log를 확인하세요.

전체 로그나 PDF는 공개 issue에 첨부하지 마세요. 개인 경로를 지운 오류 문구, 버전, 운영체제와 멈춘 단계만 오류 제보 안내에 따라 알려주세요.
