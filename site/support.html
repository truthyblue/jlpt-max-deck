기본 덱 · Anki

가져오기가 멈추면 세 가지만 봅니다.

  1. 기기에 맞는 Anki 앱인지 확인합니다.

    데스크톱은 Anki, iPhone·iPad는 AnkiMobile, Android는 AnkiDroid를 사용하세요. 이름이 비슷한 다른 앱은 APKG와 호환되지 않을 수 있습니다.

  2. 저장 공간과 앱 버전을 확인합니다.

    가져오기와 미디어 복사에 여유 공간이 필요합니다. 앱을 최신 안정 버전으로 업데이트하세요.

  3. 손상된 파일을 다시 받습니다.

    SHA-256이 다르면 기존 다운로드를 버리고 안정적인 네트워크에서 다시 받습니다.

처리 중 강제 종료하지 마세요.

17,899개 미디어를 처리하므로 환경에 따라 시간이 걸립니다. 완료 메시지가 나오기 전까지 앱을 유지하세요.

별도 선택 · 한자 확장

한자 확장 문제는 PDF와 빌더 버전을 맞춥니다.

기본 덱에 일상무따 덱이 없는 것은 정상입니다. 길벗 공식 자료 페이지에서 제공 방식과 이용 조건을 확인하고 정상적으로 받은 상·하권 PDF 2개와 같은 v1.0.1 빌더를 사용하세요.

  1. 상권·하권 소책자 PDF 2개인지 확인합니다.

    파일명보다 실제 책과 페이지 구성이 중요합니다. 다른 판본이나 미리보기 PDF는 지원되지 않습니다.

  2. v1.0.1 빌더 ZIP을 새 폴더에 풉니다.

    이전 버전 위에 덮어쓰지 말고 JLPT-MAX-kanji-builder-1.0.1.zip을 새로 받으세요.

  3. 오류에 표시된 PDF 경로를 확인합니다.

    따옴표를 포함해 전체 경로를 넘기고, 출력 폴더가 비어 있는지 확인합니다.

개인 컴퓨터 안에서만 처리됩니다.

빌더는 PDF에서 필요한 뜻과 글자 모양을 읽어 한자 확장을 만듭니다. PDF·페이지 이미지·생성 APKG를 업로드하지 마세요.

업데이트

1.0.0에서는 실전 덱만 지우고 새 버전을 넣습니다.

최상위 덱 전체를 삭제하지 마세요.

1.0.0에서 1.0.1로 올릴 때는 JLPT MAX덱::종합 실전만 삭제합니다. 이 덱의 학습 기록은 초기화되지만 어휘·음성·일상무따·참조표의 카드 ID와 일정은 유지됩니다.

  1. AnkiWeb 동기화 또는 컬렉션 백업을 완료합니다.

    여러 기기를 쓰면 모든 기기의 동기화를 먼저 끝내세요.

  2. JLPT MAX덱::종합 실전만 삭제합니다.

    그 아래 급수·문제 유형 하위 덱도 함께 삭제되는지 확인합니다.

  3. 새 기본 덱 APKG를 가져옵니다.

    학습 진행 상태 가져오기는 끄고, 기존 노트 업데이트와 노트 유형 병합은 켭니다.

  4. 이번 교정에서는 한자 확장을 다시 만들 필요가 없습니다.

    기존 일상무따 학습 기록과 APKG를 그대로 유지할 수 있습니다.

  5. 노트·카드 수와 학습 일정을 확인합니다.

    새 카드가 중복 생성되거나 기존 복습 일정이 초기화되지 않았는지 표본으로 확인합니다.

자주 묻는 질문

짧게 답합니다.

기본 덱에는 무엇이 들어 있나요?
어휘, 음성, 실전 문제, 참조표가 들어 있습니다. 일상무따 한자 2,337개는 별도 선택 확장으로 추가할 수 있습니다.
한자 빌더에 PDF를 업로드하나요?
아닙니다. 빌더는 사용자 컴퓨터에서만 실행되며 PDF·이미지·생성 APKG를 외부로 전송하지 않습니다. 필요한 프로그램을 설치할 때만 uv가 패키지 저장소에 접속합니다.
AnkiWeb 사이트에서 APKG를 바로 가져올 수 있나요?
아닙니다. Desktop 또는 공식 모바일 앱에 먼저 가져온 뒤 AnkiWeb로 동기화하세요.
