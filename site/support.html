자주 묻는 질문

설치·업데이트

업데이트할 때 기존 덱을 지워야 하나요?
지우지 마세요. 모든 기기를 먼저 동기화하거나 백업한 뒤 최신 기본 덱 파일을 그대로 가져오면 됩니다. 학습 진행 상태는 끄기, 기존 노트·노트 유형 업데이트는 항상, 노트 유형 병합은 켜기로 두면 기존 복습 기록과 일정은 남고 카드 내용만 새로 바뀝니다. 업데이트 순서 전체 보기 →
아주 오래된 버전에서도 최신 버전으로 바로 올려도 되나요?
네. 중간 버전을 차례로 설치할 필요는 없습니다. 최신 파일을 바로 가져온 뒤, 빈 카드 정리, 삭제된 어휘 정리, 카드 위치 복구가 필요한지만 확인하세요.
어휘 덱에서 음성 카드가 나와요.
일부 하위 덱만 삭제한 뒤 APKG를 다시 가져오면 카드가 다른 덱 위치에 들어갈 수 있습니다. 카드를 삭제하거나 다시 가져오지 말고, 카드 탐색기에서 위치만 고치세요. 복습 기록은 유지됩니다. 카드 위치 확인·복구 순서 보기 →
다른 일본어 덱의 학습 기록을 JLPT MAX덱으로 옮길 수 있나요?
자동으로 합쳐지지는 않습니다. 다만 PC Anki의 Transfer Scheduling 부가 기능을 쓰면, 두 덱에서 단어 필드와 카드가 서로 맞는 항목의 복습 일정과 기록을 옮길 수 있습니다. 카드 구성이 다른 항목은 빠질 수 있습니다. 먼저 두 덱을 백업하고 적은 카드로 시험한 뒤 진행하세요. 이 방법은 공식 기능이 아닙니다. 커뮤니티의 학습 진도 옮기기 글 보기 ↗
AnkiDroid에서 덱 가져오기가 실패해요.
큰 APKG를 가져올 때는 압축을 푸는 임시 공간이 더 필요합니다. Android 설정에서 AnkiDroid를 완전히 종료하고 앱 → AnkiDroid → 저장 공간 → 캐시 삭제를 실행한 뒤, 기기 여유 공간을 5GB 이상 확보하고 다시 가져오세요. 캐시는 임시 파일입니다. 데이터 삭제는 누르지 마세요. 공간이 부족하면 PC Anki에 먼저 가져온 뒤 동기화가 모두 끝날 때까지 기다리는 방법도 있습니다.
AnkiWeb 사이트에서 APKG를 바로 가져올 수 있나요?
아닙니다. 데스크톱 Anki, AnkiMobile 또는 AnkiDroid에 먼저 가져온 뒤 AnkiWeb로 동기화하세요.

학습 순서·덱 구성

N3·N2부터 공부해도 되나요? 어디서 시작하나요?
어휘는 시험 급수와 상관없이 N5부터 시작합니다. N3 시험이라면 N5 → N4 → N3 순서로 새 카드를 보고 앞 급수 복습은 계속하세요. 종합 실전은 시험 볼 급수까지 어휘를 한 번 본 뒤 그 급수의 문제만 풉니다. 덱별 학습 순서 보기 →
N5 아래 하위 덱을 하나씩 눌러야 하나요?
아닙니다. 어휘::N5를 누르면 수량 표현·날짜·월·요일 같은 하위 덱도 함께 나옵니다. 하위 덱을 따로 전부 끝낼 필요가 없습니다.
음성 덱도 꼭 공부해야 하나요?
선택입니다. 기본 어휘 카드에는 단어와 예문 음성이 이미 들어 있습니다. 별도 음성 덱은 소리만 듣고 단어를 떠올리는 연습이 더 필요할 때 하루 5–10장부터 시작하세요.
한자 쓰기 화면은 어디에 있나요?
기본 덱에는 선택형 일상무따 한자 확장이 들어 있지 않습니다. 한자 읽기·쓰기 카드가 필요하면 Windows 또는 macOS 컴퓨터에서 현재 버전의 빌더와 지원 PDF 2개로 개인용 APKG를 만든 뒤 추가하세요. 한자 확장 만들기 →

표시·음성·내 기록

카드를 뒤집기 전에 한자 없이 히라가나만 나와요.
v1.2.1까지 있던 어휘(가나 보조) 카드입니다. 최신 버전에서는 이 카드 유형을 더 이상 사용하지 않습니다. 최신 덱을 가져온 뒤 Anki의 빈 카드 도구에서 JLPT MAX덱 어휘 / 어휘(가나 보조)만 골라 삭제하세요. 카드 탐색기의 노트 삭제는 사용하지 마세요. 기기별 정리 방법 보기 →
음성이 아예 안 나오거나 일부만 나와요.
먼저 PC의 미디어 업로드와 모바일의 미디어 다운로드가 모두 끝났는지 확인하세요. PC에 덱을 가져온 직후 모바일에서 확인하면, 동기화 중인 음성은 아직 없거나 일부만 재생될 수 있습니다. 양쪽 동기화가 끝난 뒤 모바일 Anki를 완전히 닫았다가 다시 열어 확인하세요. 문법 덱에 음성이 없는 것은 정상입니다. 그래도 재생되지 않으면 아래 iPhone·iPad 설정을 확인하거나 대표 카드 한 장에서 오류를 제보하세요.
iPhone·iPad에서 카드 소리가 안 나요.
먼저 답안 오른쪽 위 설정 → 다른 앱 음악과 함께 재생이 켜져 있는지 확인하세요. 이 옵션을 켜면 무음 모드에서 카드 음성이 나오지 않을 수 있습니다. 다른 음악과 섞어 듣지 않는다면 옵션을 끄고 다시 재생해 보세요.
PC에서 공부한 내용도 ‘내 기록’에 들어가나요?
현재 내 기록은 AnkiMobile과 AnkiDroid의 카드 화면에서만 기록합니다. PC에서 한 복습도 Anki 자체 학습 일정과 동기화에는 정상 반영되지만, JLPT MAX의 내 기록·랭킹 숫자에는 포함되지 않습니다. 휴대폰과 태블릿의 내 기록도 자동으로 하나로 합쳐지지 않습니다.
개인 최고 기록 알림을 끌 수 있나요?
현재는 별도 끄기 설정이 없습니다. v2.0.3에서는 같은 날 한 번만 카드 가운데에 표시해 학습 버튼을 가리지 않도록 줄였습니다.

Anki 가져오기

Anki 가져오기 문제

  1. 기기에 맞는 Anki 앱인지 확인합니다.

    데스크톱은 Anki, iPhone·iPad는 AnkiMobile, Android는 AnkiDroid를 사용하세요. 이름이 비슷한 다른 앱은 APKG와 호환되지 않을 수 있습니다.

  2. AnkiDroid라면 캐시와 저장 공간을 먼저 확인합니다.

    AnkiDroid를 완전히 종료하고 Android 설정의 앱 → AnkiDroid → 저장 공간 → 캐시 삭제를 실행하세요. 데이터 삭제는 누르지 마세요. 여유 공간은 5GB 이상 확보합니다. 그래도 부족하면 PC Anki에 먼저 가져온 뒤 미디어 동기화를 끝내세요.

  3. 미사용 미디어를 삭제해 저장 공간을 확보합니다.

    앱을 최신 안정 버전으로 업데이트하고, 여러 기기를 쓴다면 미디어 동기화를 먼저 끝내세요. 데스크톱 Anki에서 도구 → 미디어 검사를 열어 미사용 파일 목록을 확인한 뒤 삭제합니다. 삭제된 파일은 휴지통으로 이동하므로 필요한 파일이 없는지 확인한 뒤 휴지통을 비워야 실제 여유 공간이 생깁니다.

  4. 손상된 파일을 다시 받습니다.

    SHA-256이 다르면 기존 다운로드를 버리고 안정적인 네트워크에서 다시 받습니다.

처리 중 강제 종료하지 마세요.

24,978개 미디어를 처리하므로 환경에 따라 시간이 걸립니다. 완료 메시지가 나오기 전까지 앱을 유지하세요.

한자 확장

한자 확장 문제

기본 덱에 일상무따가 없는 것은 정상입니다. 한자 확장이 필요하다면 처음부터 따라가는 만들기 가이드를 먼저 확인하세요.

  1. 더블클릭할 실행 파일이 보이지 않아요.

    ZIP 미리보기 안이 아니라 압축을 푼 새 폴더를 여세요. Windows에는 Windows에서 한자 확장 만들기.cmd, macOS에는 Mac에서 한자 확장 만들기.command가 있습니다.

  2. 필요한 프로그램을 받지 못했다고 나와요.

    처음 실행할 때만 빌드 도구와 Python을 자동으로 받습니다. 인터넷 연결을 확인한 뒤 ZIP을 새 폴더에 다시 풀고 더블클릭 실행 파일을 다시 여세요.

  3. PDF hash 또는 page count 오류가 나요.

    공식 자료 페이지에서 정상적으로 받은 상·하권 소책자 PDF 2개와 순서를 확인하세요. 다시 저장·병합·최적화한 PDF나 미리보기 파일은 지원되지 않습니다.

  4. alignment 오류가 나요.

    같은 v2.0.3의 빌더와 지원 PDF가 맞지 않거나 1권·2권 선택 순서가 바뀌었을 수 있습니다. 현재 빌더 ZIP을 새 폴더에 다시 풀고 실행하세요.

  5. PDF 선택창을 취소했어요.

    아무 파일도 바뀌지 않습니다. 실행 파일을 다시 더블클릭하고 처음부터 선택하면 됩니다.

  6. 완성 파일을 다시 만들고 싶어요.

    더블클릭 실행 파일을 다시 열면 기존 결과를 지우고 새로 만들지 묻습니다. 다시 만들기를 선택한 뒤 PDF 두 개를 다시 고르세요.

실패하면 빌더 폴더의 kanji-builder.log를 확인하세요.

공개 issue에 전체 로그나 PDF를 올리지 말고 개인 경로를 지운 오류 문구만 적어 주세요.

업데이트 기록

최신 버전에서 무엇이 바뀌었는지 확인하는 곳입니다. 덱을 업데이트하려면 먼저 업데이트 방법을 보세요.

  1. v2.0.3최신
    2026-08-29

    내 기록의 자동 복구와 연결 재시도를 보강하고 JLPT 목표 카드·개인 최고 기록 알림·문법 카드 공지 화면을 고쳤습니다.

    • 기기에 기록이 남아 있는데 서버 응답이 비어 있을 때 기록과 JLPT 목표를 자동으로 다시 확인하도록 고쳤습니다.
    • 잠깐 연결이 불안정한 경우에는 바로 실패로 표시하지 않고 한 번 자동으로 다시 시도하며, 실제 복구 실패와 일반 연결 오류를 구분해 안내합니다.
    • 서버의 목표 급수가 먼저 확인되고 상세 일정이 늦게 도착해도 JLPT 목표 카드를 흰 빈 카드로 바꾸지 않고 기존 초록색 흐름을 유지합니다.
