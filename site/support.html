Anki 가져오기가 멈춰요.

앱, 저장 공간, 다운로드 파일을 순서대로 확인하세요.

  1. 기기에 맞는 Anki 앱인지 확인합니다.

    데스크톱은 Anki, iPhone·iPad는 AnkiMobile, Android는 AnkiDroid를 사용하세요. 이름이 비슷한 다른 앱은 APKG와 호환되지 않을 수 있습니다.

  2. 미사용 미디어를 삭제해 저장 공간을 확보합니다.

    앱을 최신 안정 버전으로 업데이트하고, 여러 기기를 쓴다면 미디어 동기화를 먼저 끝내세요. 데스크톱 Anki에서 도구 → 미디어 검사를 열어 미사용 파일 목록을 확인한 뒤 삭제합니다. 삭제된 파일은 휴지통으로 이동하므로 필요한 파일이 없는지 확인한 뒤 휴지통을 비워야 실제 여유 공간이 생깁니다.

  3. 손상된 파일을 다시 받습니다.

    SHA-256이 다르면 기존 다운로드를 버리고 안정적인 네트워크에서 다시 받습니다.

처리 중 강제 종료하지 마세요.

17,899개 미디어를 처리하므로 환경에 따라 시간이 걸립니다. 완료 메시지가 나오기 전까지 앱을 유지하세요.

한자 확장을 만들 수 없어요.

기본 덱에 일상무따가 없는 것은 정상입니다. 한자 확장이 필요하다면 처음부터 따라가는 만들기 가이드를 먼저 확인하세요.

  1. 더블클릭할 실행 파일이 보이지 않아요.

    ZIP 미리보기 안이 아니라 압축을 푼 새 폴더를 여세요. Windows에는 Windows에서 한자 확장 만들기.cmd, macOS에는 Mac에서 한자 확장 만들기.command가 있습니다.

  2. 필요한 프로그램을 받지 못했다고 나와요.

    처음 실행할 때만 빌드 도구와 Python을 자동으로 받습니다. 인터넷 연결을 확인한 뒤 ZIP을 새 폴더에 다시 풀고 더블클릭 실행 파일을 다시 여세요.

  3. PDF hash 또는 page count 오류가 나요.

    공식 자료 페이지에서 정상적으로 받은 상·하권 소책자 PDF 2개와 순서를 확인하세요. 다시 저장·병합·최적화한 PDF나 미리보기 파일은 지원되지 않습니다.

  4. alignment 오류가 나요.

    같은 v1.0.1의 빌더와 지원 PDF가 맞지 않거나 1권·2권 선택 순서가 바뀌었을 수 있습니다. 현재 빌더 ZIP을 새 폴더에 다시 풀고 실행하세요.

  5. PDF 선택창을 취소했어요.

    아무 파일도 바뀌지 않습니다. 실행 파일을 다시 더블클릭하고 처음부터 선택하면 됩니다.

  6. 완성 파일을 다시 만들고 싶어요.

    더블클릭 실행 파일을 다시 열면 기존 결과를 지우고 새로 만들지 묻습니다. 다시 만들기를 선택한 뒤 PDF 두 개를 다시 고르세요.

실패하면 빌더 폴더의 kanji-builder.log를 확인하세요.

공개 issue에 전체 로그나 PDF를 올리지 말고 개인 경로를 지운 오류 문구만 적어 주세요.

자주 묻는 질문

기본 덱에는 무엇이 들어 있나요?
어휘, 음성, 실전 문제, 참조표가 들어 있습니다. 일상무따 한자 2,337개는 별도 선택 확장으로 추가할 수 있습니다.
한자 빌더에 PDF를 업로드하나요?
아닙니다. 빌더는 사용자 컴퓨터에서만 실행되며 PDF·이미지·생성 APKG를 외부로 전송하지 않습니다. 처음 실행할 때 빌드 도구와 Python을 받을 때만 프로그램 배포 서버와 패키지 저장소에 접속합니다.
AnkiWeb 사이트에서 APKG를 바로 가져올 수 있나요?
아닙니다. Desktop 또는 공식 모바일 앱에 먼저 가져온 뒤 AnkiWeb로 동기화하세요.
